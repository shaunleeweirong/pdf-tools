The best free PDF tools for lawyers cover signing, merging exhibits, protecting confidential files, and filling court forms, without a subscription or account.

Working with PDFs is unavoidable in legal practice. The problem is that most tools cost money, require signing up, or send your files to a remote server. The options below don't. Everything runs in your browser, so client documents stay on your device.

## Why file privacy matters here

The [ABA Model Rules of Professional Conduct Rule 1.6](https://www.americanbar.org/groups/professional_responsibility/publications/model_rules_of_professional_conduct/rule_1_6_confidentiality_of_information/) requires lawyers to make reasonable efforts to prevent unauthorized disclosure of client information. That's not a blanket argument against cloud tools, but it is a reason to know where your files go. Browser-based tools process everything locally. Upload-based tools send your files to a server, where they may be stored or logged.

For anything sensitive, the browser-side approach is the safer default.

## Signing documents

The [Sign PDF tool](/sign-pdf) lets you draw a signature and place it on any page. No account, no plug-in, no upload needed. You draw directly on a canvas and the signature embeds in the document.

One thing to keep in mind: drawing a signature is not the same as creating a compliant electronic signature for all document types. For internal routing and informal agreements, a drawn signature works fine. For contracts with regulatory requirements, check whether you need a service that generates an audit trail. [Electronic signature laws vary by country](https://en.wikipedia.org/wiki/Electronic_signature#Legislation_in_different_countries), and the validity of a given method depends on the applicable statute.

## Merging exhibits and attachments

Combining a contract with its schedules, attaching exhibits to a brief, stapling a cover letter to supporting documents. The [Merge PDF tool](/merge-pdf) handles all of this in the browser.

One important detail: merging strips interactive form fields from the output. If you're combining a filled court form with other documents, use [Flatten PDF](/flatten-pdf) first. Flattening bakes the field values into the page as permanent content, so nothing gets lost when the files are merged. You can confirm the tool still shows the values you entered before flattening.

## Splitting and extracting pages

Two tools cover different use cases here. [Split PDF](/split-pdf) breaks a document into page ranges, for example pages 1 to 10 as one file and 11 to 25 as another. [Extract Pages](/extract-pages) lets you pick specific non-consecutive pages and save them as a new PDF. Both run in the browser without uploading to a server.

Court e-filing systems sometimes cap file sizes per submission. Splitting a large brief into separately filed sections is often the right fix when you hit that limit.

## Password-protecting confidential files

[Protect PDF](/protect-pdf) adds AES-256 encryption and a password to any PDF in your browser. The file size overhead is minimal, roughly 1 KB regardless of the document's size, so it won't push a file over a filing limit. Wrong passwords are rejected before the file opens.

[Unlock PDF](/unlock-pdf) removes a password you already know, returning the file to within a few bytes of its original size.

## Filling court forms

Many court forms are distributed as fillable PDFs. The [Fill PDF Form tool](/fill-form) detects the form fields and lets you type values directly. When you're done, download the filled PDF.

Before sending the filled form anywhere, run it through [Flatten PDF](/flatten-pdf) to make the values permanent. This prevents anyone from accidentally clearing a field, and it's the required step before merging the form with other documents (see the section on merging above).

## Adding a CONFIDENTIAL or DRAFT watermark

[Watermark PDF](/watermark-pdf) stamps text across every page. You set the text, opacity, and position. It's the fastest way to mark a working draft, flag a document as attorney-client privileged, or label anything that shouldn't be circulated in its current form.

## Adding page numbers for court submissions

Many federal and state courts require paginated filings, and some specify exact formats. [Add Page Numbers](/add-page-numbers) inserts numbers in your choice of format and position. If you're filing in the [federal court e-filing system (CM/ECF)](https://www.uscourts.gov/court-records/electronic-filing-pacer), check your district's local rules for the required position and starting page number before generating the final file.

## What not to do: compressing text-heavy documents

Avoid compressing contracts, briefs, or any PDF that's mostly text. Browser-based compression works by rasterizing every page into a JPEG image. For a scanned document or an image deck, that reduces file size significantly. For a text document, it does the opposite: a 23.5 KB text report became 1.4 MB after compression at Medium quality, a roughly 60x increase in size.

If you need to shrink a legal document for a filing size limit, the better approaches are splitting it into separately filed parts or extracting only the pages that need to go together.

## How to prepare a brief for court e-filing

1. Draft each section of the filing as a separate PDF.
2. Fill out any court forms using [Fill PDF Form](/fill-form).
3. Flatten all filled forms with [Flatten PDF](/flatten-pdf) so field values are permanent.
4. Merge everything into one file using [Merge PDF](/merge-pdf).
5. Add sequential page numbers using [Add Page Numbers](/add-page-numbers).
6. Check the page count and file size against your court's local rules.
7. If the file is over the size limit, use [Split PDF](/split-pdf) to file sections separately.

The whole process runs in the browser. Nothing gets sent to a remote server.
