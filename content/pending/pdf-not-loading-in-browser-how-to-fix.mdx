PDF not loading in browser is one of those problems that looks like it could be anything, and often is. The good news: most cases come down to one of five causes, and you can rule them out in order without touching any settings.

## Why PDFs fail to load in a browser

Browser PDF viewing is handled by a built-in viewer, not a plugin you installed. When that viewer chokes, you typically see one of three symptoms: a "Failed to load PDF document" error, a blank white page, or the browser just downloading the file instead of showing it.

The usual suspects:

- A browser extension is blocking the viewer
- The browser is set to download PDFs instead of displaying them
- The file is too large for the browser's memory limit
- The PDF is password-protected and the viewer can't proceed
- The PDF file is genuinely corrupted

Start at the top and work down. The first test takes 30 seconds and rules out the most common cause.

## Fix 1: Open the PDF in incognito mode

Incognito mode (Chrome, Edge) and Private Window (Firefox) disable most extensions. If your PDF loads fine in private mode but fails in a normal tab, an extension is to blame.

1. Press **Ctrl+Shift+N** on Windows or **Cmd+Shift+N** on Mac to open incognito in Chrome or Edge.
2. In Firefox, press **Ctrl+Shift+P** (or **Cmd+Shift+P** on Mac).
3. Paste the PDF URL and open it.

If it works in private mode, go to your extensions list and disable them one at a time. Ad blockers (uBlock Origin, AdBlock Plus) and privacy extensions (Privacy Badger, Ghostery) are common culprits. Re-enable them one by one until you find the one that breaks it, then check that extension's settings for a PDF-related rule.

## Fix 2: Check your PDF viewer settings

Chrome can be configured to download PDFs rather than display them inline. If that setting is on, clicking a PDF link triggers a silent download rather than a visible error, which can look identical to a "not loading" problem.

To check in Chrome:

1. Open **Settings** (three-dot menu, top right).
2. Go to **Privacy and security > Site settings > Additional content settings > PDF documents**.
3. Make sure **Open PDFs in Chrome** is selected, not **Download PDFs**.

Edge has the same toggle at **Settings > Cookies and site permissions > PDF documents**.

In Firefox, go to **Settings > General > Applications**, find "Portable Document Format (PDF)" in the list, and set the action to **Preview in Firefox**. Firefox's PDF viewer is built on [PDF.js](https://mozilla.github.io/pdf.js/), an open-source renderer maintained by Mozilla.

## Fix 3: Clear your browser cache

A cached copy of a PDF that was downloaded mid-stream can cause repeated failures. Clearing the cache forces a fresh download.

In Chrome: go to **Settings > Privacy and security > Clear browsing data**, tick "Cached images and files", and click **Clear data**. You don't need to clear cookies for this.

A faster option: with the PDF tab open, hold **Shift** and click the reload button (or press **Ctrl+Shift+R** on Windows / **Cmd+Shift+R** on Mac) to force a hard reload of that tab only.

## Fix 4: Update your browser

Browser PDF renderers are updated regularly. An old version may fail on PDFs that use newer features or have an unusual structure.

[Chrome updates itself automatically](https://support.google.com/chrome/answer/95414), but you may have postponed an update. Click the three-dot menu in Chrome; if there's an "Update Google Chrome" option at the top of the menu, click it. After updating, try the PDF again.

## Fix 5: Try a different browser

Each major browser uses a different PDF engine, so a file that fails in one may work fine in another:

- Chrome and Edge use their own built-in renderers.
- Firefox uses PDF.js.
- Safari on Mac uses macOS's native PDF support.

If switching browsers works, that confirms the issue is with the specific viewer, not the file. For a one-off document, this is the quickest workaround.

## Fix 6: The PDF may be password-protected

A password-protected PDF will show a blank or error screen in browser viewers that haven't received the correct password. Some viewers display a clear password prompt; others fail silently.

Download the file and open it in a desktop app. If you see a password field, that's your answer. You'll need the password from whoever sent the file.

If you own the PDF and want to remove a password you already know, the [Unlock PDF tool](/unlock-pdf) runs entirely in your browser and handles this without uploading your file to a server.

## Fix 7: The file may be too large

Browsers have memory limits for rendering PDFs. A very large file, especially a multi-page scan or photo document, can exceed those limits and return a "failed to load" error even when the file itself is valid. Download it and open it locally to confirm, since desktop PDF readers handle much larger files.

If the PDF is an image-heavy document (scanned pages, photo decks), compressing it first can bring it under the browser's limit. The [Compress PDF tool](/compress-pdf) reduces file size by rasterizing pages to JPEG, and it works well for this type of content. For text-based PDFs (contracts, reports, invoices), compression won't help: rasterizing vector text produces a larger file than the original, not a smaller one. In that case, download the file and use a desktop reader.

## Fix 8: Download and open locally

This sidesteps the browser viewer entirely. Right-click the PDF link and choose **Save link as...**, then open the downloaded file in any desktop PDF reader. Good free options include:

- **Adobe Acrobat Reader** (Windows, Mac)
- **Preview** (Mac, built in)
- **Microsoft Edge** file viewer (Windows, built in)
- **Foxit PDF Reader** (Windows, Mac, Linux)

If the PDF opens fine locally, the problem was limited to your browser's viewer and the fixes above should resolve it. If it fails on your desktop too, the file is corrupted and you'll need a fresh copy.

## How to fix a corrupted PDF

When a file is genuinely corrupted, the options are:

1. **Re-download from the source.** Corrupted downloads happen when a connection drops mid-transfer. Try again on a stable connection.
2. **Ask the sender to resend.** If the file came via email or a file-sharing link, ask for a new export or a direct link from cloud storage.
3. **Try a different PDF app.** Some apps recover slightly damaged files that others can't. Adobe Acrobat Reader, Foxit, and Preview on Mac each use different recovery logic.

If you're the document's author and still have the original source (a Word file, Google Doc, or InDesign file), re-exporting as PDF usually produces a clean copy.

---

Most PDF loading failures in browsers sort themselves out with incognito mode or a cache clear. The file-level problems (corruption, password protection, oversized scans) are easy to distinguish from browser problems because they fail consistently across apps, not just in one tab.
