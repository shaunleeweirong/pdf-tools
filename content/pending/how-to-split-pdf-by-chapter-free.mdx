The quickest way to split a PDF by chapter is to identify the page range for each chapter, then use a free in-browser [Split PDF](/split-pdf) tool to extract those pages into separate files. No account needed, and the original file stays untouched.

This guide walks through the whole process: finding the right page numbers, splitting by range, and what to do when a PDF has no table of contents.

## What "splitting by chapter" actually means

Most PDF books, dissertations, and manuals store chapter breaks in two ways:

1. **Bookmarks (outline/table of contents)**: The author added clickable navigation entries that note where each chapter begins. Some specialized tools can read these and auto-split at each bookmark.
2. **Page ranges only**: The PDF has no embedded bookmarks, so you need to figure out the page numbers manually and split by range.

The bookmark approach sounds easier, but it only works when the original PDF was exported with bookmarks intact. Many scanned books, compressed documents, and older PDFs lose their bookmark structure during conversion. Page-range splitting works on every PDF, regardless of how it was created.

## How to find which pages belong to each chapter

Before you split anything, you need the exact page numbers. Here is how to get them in two minutes:

1. Open the PDF in any reader (your browser's built-in viewer works fine).
2. Check the table of contents page near the front. Most print books and reports list chapter names alongside page numbers.
3. If the table of contents page numbers don't match what the reader shows (common in scanned books where page 1 of the scan is not page 1 of the book), scroll to the first page of each chapter and note the number the reader displays at the bottom.
4. Write down each chapter's start page and the page just before the next chapter begins. For example: Chapter 1 is pages 12 to 34, Chapter 2 is pages 35 to 67, and so on.

Keep this list open in a notes app while you split. You'll move through the chapters quickly.

## How to split a PDF by chapter using the free Split PDF tool

The [Split PDF](/split-pdf) tool extracts any page range from your file into a separate PDF. It runs entirely in your browser, so nothing is sent to a server.

1. Go to [Split PDF](/split-pdf) and drop your file onto the tool.
2. Enter the page range for the first chapter, for example "12-34".
3. Click **Split** and download the resulting PDF.
4. Reload the tool (or click **Start over**), re-upload your file, and repeat for the next chapter.

The file size of each output roughly matches its share of the original pages. Splitting does not compress or re-render anything, so image and text quality are identical to the source.

If you only need one specific chapter from a long document, the [Extract Pages](/extract-pages) tool does the same job in one step: pick the pages you want, and the tool packages them into a new PDF without touching the rest.

## What if I want to split a book into all its chapters at once?

The Split PDF tool handles one range per run, which is fine for most people who only need two or three chapters. If you have a textbook with 20 chapters and want them all at once, the cleanest approach depends on your operating system:

- **Mac**: Open the PDF in Preview, then drag individual page groups from the sidebar into separate Finder windows. Preview lets you select a range of page thumbnails and drag them to the desktop to create a new PDF instantly, all offline.
- **Windows**: The built-in print-to-PDF approach works: open the PDF, choose Print, set it to "Microsoft Print to PDF", and enter a page range. Repeat for each chapter.
- **Any platform**: Tools like [PDFsam Basic](https://pdfsam.org/) (free, open source, desktop app) let you define multiple page ranges in one session and export them all as separate files. This is the most efficient option for a large batch.

For most everyday tasks, splitting two or three chapters with the browser tool is faster than downloading and installing software.

## How to split if your PDF has bookmarks

Some PDFs, especially those exported from Word documents, InDesign, or modern publishing tools, carry a proper [bookmark structure](https://en.wikipedia.org/wiki/PDF#Interactive_features) that acts as a navigable outline. If your PDF has this, you have an additional option:

Open the PDF in Adobe Acrobat Reader (free) and check the bookmark panel on the left sidebar. If you see chapter entries there, the PDF has an outline. Third-party tools like Sejda (free tier available) and DeftPDF (free, no sign-up) can detect these bookmarks and split at each one automatically.

That said, bookmark-based splitting still requires the file to have well-formed bookmarks, which many real-world PDFs don't. When in doubt, the manual page-range method works every time.

## Splitting a scanned PDF by chapter

Scanned PDFs (pages photographed or photocopied and converted to PDF) rarely have bookmarks. The page-range approach is your only reliable option. One extra thing to watch for: the page count shown by a reader on a scanned book often includes cover pages, blank pages, and front matter, which shifts the numbers relative to what the printed page says.

To avoid confusion, scroll to a known chapter heading (say "Chapter 3") and note what page number your reader shows. Use that reader page number when setting the range in the split tool, not the printed page number inside the document.

## How to handle a PDF with Roman numeral front matter

Academic papers and formal reports often number the introduction and table of contents with Roman numerals (i, ii, iii...) and switch to regular numbers at the main body. PDF readers typically display whichever page label the document uses, which can create gaps in what you see.

The safest approach: count from the first physical page of the file (the very first page the reader shows) as page 1, regardless of what label it carries. So if the main content starts on the 12th physical page, enter "12" in the split tool even if that page is printed as "1" inside the document.

## A few things to keep in mind

- **Splitting does not compress**. The output file is the same quality as the input. If you need a smaller file, run the extracted chapter through the [Compress PDF](/compress-pdf) tool afterward, but only if the chapter is image-heavy. The compressor rasterizes pages to JPEG, which makes text-only PDFs much larger, not smaller. Use it only for chapters full of scanned images or photos.
- **Forms and annotations**: If the source PDF has fillable form fields, those fields are standard PDF features and survive a split. However, if you later merge those pages into another document, the fields may be lost. Flatten any filled forms before merging to lock in the values as visible page content.
- **Copyright**: Splitting a PDF you own is fine. Distributing individual chapters of a copyrighted book raises separate questions under copyright law. The [U.S. Copyright Office fair use guide](https://www.copyright.gov/fair-use/) covers the basics if you're unsure about your specific use.
