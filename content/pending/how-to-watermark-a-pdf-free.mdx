## What is a PDF watermark?

A watermark is text (or sometimes an image) printed across every page of a document, usually at an angle and in a semi-transparent style. According to the [PDF specification ISO 32000](https://www.iso.org/standard/75839.html), watermarks are part of the page content itself rather than a floating overlay. That makes them harder to strip out than an annotation or sticky note.

Common uses:

- Marking a document as **DRAFT** while it's still being revised
- Stamping **CONFIDENTIAL** on documents you're sharing internally but don't want forwarded
- Adding **SAMPLE** to preview copies shared before payment
- Including your company name or copyright notice on every page
- Marking outdated versions as **VOID**

## What text should you use for the watermark?

The right label depends on what you're communicating:

- **DRAFT** tells the reader the document is not final and may still change. Use this during reviews and before a document has been approved.
- **CONFIDENTIAL** signals the document shouldn't be forwarded or shared without permission. Common for HR documents, financial statements, and legal drafts.
- **DO NOT COPY** and **SAMPLE** are common on proposals and preview documents shared with prospective clients.
- A company name or website address is useful when sharing documents externally so every page identifies the source, even if pages get separated.
- **VOID** marks invalidated versions of contracts or financial documents to prevent old copies from being acted on.

Opacity matters too. A very solid watermark makes the underlying text harder to read. A very faint one might be missed entirely. A transparency setting somewhere around 30 to 50 percent keeps the document content readable while making the watermark clearly visible.

This also matters for documents covered by NDAs or data handling agreements, where sending files to external services might itself create a compliance question.

## Does adding a watermark change the PDF file size?

Adding text across each page embeds a small amount of additional drawing instructions inside the PDF. For a typical document, the effect on file size is minor. If you're sending the watermarked file by email, both Gmail and Outlook.com cap attachments at [25 MB](https://support.google.com/mail/answer/6584), and Base64 encoding adds roughly 33% to any attachment, making the practical ceiling around 18 MB. A text watermark alone is unlikely to push a file over those limits, but check the final file size before sending if you're working with a large document.

## Can a watermark be added to a scanned PDF?

Yes. A scanned PDF is typically a set of page images wrapped inside a PDF file. The watermark tool stamps text over each page the same way it would with a text-based document. The underlying scan is not altered; the watermark text is drawn on top of it.

The result looks the same as watermarking a regular text document: your label appears across every page.

## Can the watermark be removed?

A text watermark built into the page content of a PDF is harder to remove than an annotation layer. Most everyday PDF viewers don't offer a way to remove it at all.

That said, a determined person with a professional PDF editor could attempt to overwrite or obscure it. Watermarking is a practical deterrent and a clear signal of intent, not a technical access control.
