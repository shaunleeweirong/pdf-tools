The best free PDF tools for accountants handle merging, signing, protecting, and splitting without a subscription, an install, or an account. The tools on this page cover the tasks that come up every week in accounting work, and most of them run entirely in your browser.

## What PDF tasks come up most in accounting work?

Accountants manage PDFs for almost everything: combining bank statements and client deliverables into one package, signing engagement letters, locking down confidential files before emailing them, pulling specific pages from a large audit document, and occasionally dealing with a scanned tax return that's too large to attach anywhere.

Most of these tasks don't need Adobe Acrobat. They don't even need installed software. Here's what actually helps, and where each tool fits.

## Merging financial documents for clients and auditors

Combining a cover letter, financial statements, and supporting schedules into a single PDF is probably the most common PDF task in accounting. The [Merge PDF tool](/merge-pdf) handles it in your browser: add the files, drag to set the order, download the result.

One thing worth knowing: merging doesn't inflate the output. Three files totalling 971.9 KB merged into a 970.5 KB file. The combined document came in slightly under the sum of its parts because shared PDF structure is written once. If you're worried about pushing a client package over an email limit by combining files, the total stays almost exactly what the individual files add up to.

There's one important catch. If you merge a filled-in tax form or signed authorization form directly, the form fields are stripped. The pages look fine to the eye, but the underlying form structure disappears. The fix is to flatten the form first using the [Flatten PDF tool](/flatten-pdf): that bakes the filled values permanently into the page so nothing is lost when you combine documents. This matters most when you're merging a completed engagement letter or an IRS e-file authorization with a cover package.

## When to compress a scanned PDF (and when not to)

This is where accountants run into trouble. The instinct is to reach for a compressor when any PDF is too large to email, but that only works if the file is image-heavy.

The [Compress PDF tool](/compress-pdf) works by rasterizing every page to a JPEG image. For scanned documents, photographs, or bank statements that arrived as image scans, that process shrinks the file significantly. A six-page image deck compressed from 913.4 KB down to 315.3 KB at Medium quality.

For text-based documents (typed invoices, balance sheets, financial reports generated from accounting software), the same process makes things much worse. A 20-page text report grew from 23.5 KB to 1.4 MB after compression. The tool converts crisp, tiny vector text into a photograph of that text, and photographs of text are large.

If you're dealing with a bloated text-based PDF, the problem is usually embedded fonts, revision history baked in by your accounting software, or an oversized logo. Compressing won't help. Splitting out only the pages you need to send, or asking the source application to export a cleaner PDF, will.

**Use the compressor only when the file is a scan or a photo-heavy report.** For invoices, balance sheets, contracts, and most documents produced by accounting software, it'll make the file larger.

## Protecting confidential client files with a password

The [Protect PDF tool](/protect-pdf) applies [AES-256 encryption](https://en.wikipedia.org/wiki/Advanced_Encryption_Standard), the same cipher used in financial services, directly in your browser. The file grows by roughly 1 KB regardless of size, so it won't matter for email limits. When you send a protected PDF, the recipient needs the password you set to open it.

That's the right workflow for client financial statements, tax returns containing social security numbers, or any document with personally identifiable information. Password-protecting PDFs is one practical layer in [protecting personal data under data protection law](https://ico.org.uk/for-organisations/uk-gdpr-guidance-and-resources/security/encryption/encryption-and-data-protection-law/).

If a client sends you a password-protected file that you own and need to edit, the Unlock PDF tool removes the password once you enter it. The file returns to within a hundred bytes of its original size.

## Signing engagement letters and authorization forms

The [Sign PDF tool](/sign-pdf) lets you draw a signature and place it anywhere on a page. You draw once, position it, download the signed file. No account, no subscription, no app.

For client signatures, the same flow works in reverse: send the PDF, the client opens the tool, signs, and returns the file. This kind of drawn signature is practical for most engagement letters and internal authorization forms, though it's worth knowing it's a different thing from legally certified e-signatures under frameworks like the [EU eIDAS regulation](https://digital-strategy.ec.europa.eu/en/policies/eidas-regulation) or the US ESIGN Act, which are relevant if you need a court-admissible audit trail for high-stakes agreements.

## Filling out PDF forms

Many government forms, client intake documents, and standard accounting templates arrive as fillable PDFs. The [Fill PDF Form tool](/fill-form) detects the fields and lets you type into them. Download the completed document when you're done.

If you need the filled values to survive a later merge, run the form through [Flatten PDF](/flatten-pdf) before combining it with other files. That turns the field data into permanent page content.

## Splitting large documents for individual clients

Audit files, tax packages, and year-end reports often arrive as one massive PDF covering multiple entities or tax years. The [Split PDF tool](/split-pdf) extracts specific page ranges. You pull out one client's section and leave the rest untouched.

This is also the right tool when you need to share specific pages from a multi-entity report without sending the entire document.
