You can split a PDF on Mac for free without installing anything extra. macOS ships with Preview, which handles most splitting jobs in a few clicks. For more complex splits, like dividing one file into several specific chunks at once, a free in-browser tool fills the gap without uploading your file anywhere.

## Method 1: Drag pages to the desktop in Preview

This is the quickest approach for pulling out a handful of pages. No downloads, no accounts.

1. Open your PDF in Preview (double-click it in Finder).
2. Show the page thumbnail panel: **View > Thumbnails** or press Shift+Cmd+2.
3. Select the pages you want. Click the first page, then Shift-click the last if they're adjacent. To grab non-adjacent pages, Cmd-click each one individually.
4. Drag the selected thumbnails from the sidebar onto your Desktop.

Preview creates a new PDF containing only those pages. Your original file is not changed.

This method is great for pulling one chapter or a specific section out of a larger document. If you need to create several separate chunks from the same file, you'd repeat the process for each one, which gets repetitive for more than two or three pieces.

## Method 2: Use Preview's Print dialog to save a page range

If you know the exact page numbers you need, the Print dialog is often faster than selecting thumbnails by hand.

1. Open the PDF in Preview.
2. Press **Cmd+P** to open the Print panel.
3. Under Pages, choose "From" and type your start and end page numbers. For example, enter 5 to 12 to extract that range.
4. Click the **PDF** button in the bottom-left corner and choose **Save as PDF**.
5. Pick a filename and location, then save.

Repeat this for each range you need. Two or three chunks is straightforward; more than that starts to feel like work.

You can use the same approach directly in Safari or Chrome. Open the PDF in the browser, press Cmd+P, set the page range, and choose Save as PDF. The result is the same.

[Apple's Preview user guide](https://support.apple.com/guide/preview/welcome/mac) covers the full set of PDF tools Preview offers if you want to explore further.

## Splitting a PDF into individual pages

To separate every page into its own file using Preview:

1. Open the PDF and show the thumbnail panel.
2. Press **Cmd+A** to select all pages at once.
3. Drag the whole selection to your Desktop.

Preview saves each page as a separate numbered PDF. This is useful for scanned documents where each page is a standalone record that needs to be filed or shared independently.

## What about Automator?

macOS includes Automator, a workflow tool built into the system. You can build a workflow that splits a PDF, but Automator only supports splitting into individual pages, not custom ranges. For most real situations, Preview or a dedicated tool is more useful.

## Does splitting a PDF affect quality?

No. The [PDF format](https://en.wikipedia.org/wiki/PDF) stores pages as independent objects within the file, so extracting some pages doesn't touch the others and doesn't re-encode anything. Text stays sharp, images stay at their original resolution, and the size of your new PDF will be roughly proportional to the pages it contains.

One thing to check: if your original PDF has interactive form fields, those fields carry over into the split files. If you've filled in the form and want the values permanently embedded in the page before you share it, run the result through the [Flatten PDF tool](/flatten-pdf) first. Flattening bakes the field values into the page content so they can't be accidentally changed or lost.

## Putting it back together

If you split a PDF into parts to send separately and later need to combine them, the [Merge PDF tool](/merge-pdf) joins them back in any order you choose. You can also do this inside Preview: open one PDF, show its thumbnail panel, then drag pages from another PDF's thumbnail panel into the sidebar of the first.
