If your PDF file is not uploading to a website, the problem almost always comes down to one of three things: the file is too large, it has a password or encryption, or it's corrupted. All three have quick fixes. Here's how to figure out which one applies to your file.

## Read the error message first

The error text is your fastest clue. Common messages and what they mean:

- **"File too large" or "exceeds maximum size":** the PDF is over the site's limit. Compress or split it.
- **"Invalid file," "not a valid PDF," or "unsupported format":** the file is corrupted, has non-standard headers, or is not actually a PDF despite the extension.
- **"Encrypted," "password-protected," or "secured document":** the site cannot read the file because it's locked. Remove the encryption before uploading.
- **The upload spins indefinitely with no error:** usually a network or browser problem, not a file problem.

If there's no message at all and the upload silently fails, start with file size and work through the list below.

## Fix 1: Reduce the file size

Most sites publish their upload limit in the help section or near the upload button. Common numbers:

| Platform | Typical limit |
|---|---|
| Gmail / Outlook.com | 25 MB |
| Google Drive (direct upload) | 5 TB per file |
| LinkedIn resume | 5 MB |
| Google Classroom | 50 MB per attachment |
| Government portals | 5 to 10 MB |
| DocuSign | 25 MB per file |

The right fix depends on what's inside your PDF.

**Image-heavy or scanned PDFs** (photographs, signed documents shot on a phone, scanned pages): use the free [Compress PDF tool](/compress-pdf). It runs in your browser, your file stays on your device, and it can cut the size substantially. In testing, a 6-page image deck dropped from 913.4 KB to 315.3 KB at Medium quality, a 65.5% reduction.

**Text-only PDFs** (reports, contracts, invoices, typed forms): skip compression. Because the tool rasterizes every page to JPEG, a text PDF that was 23.5 KB grew to 1,400.8 KB after one compression pass. That's roughly 60 times larger. For text documents, use [Split PDF](/split-pdf) to break the file into smaller sections, or share a download link from Google Drive or Dropbox.

Not sure which type you have? Open the PDF and try to click and highlight a word. If you can select text, it's a text PDF. If clicking selects the whole page like a photo, it's a scan.

## Fix 2: Remove the password or encryption

[PDF files can carry two kinds of protection](https://en.wikipedia.org/wiki/PDF): an open password (you must enter it just to view the file) and permissions restrictions (you can view the file but copying, printing, or editing is blocked). Many upload portals reject both types because they can't read or process an encrypted file server-side, even if you can open it locally without any prompt.

To check whether your PDF is protected, open it in Adobe Reader or your system's default PDF viewer and go to File > Properties > Security. The "Security Method" field tells you what's on the file. "No Security" means it's open; anything else means it's encrypted.

To remove the protection, use the free [Unlock PDF tool](/unlock-pdf) if you know the password. After clearing the encryption, try the upload again with the clean copy.

You can also remove permissions restrictions without a dedicated tool: open the PDF in your viewer and print it to a new PDF file. On Mac, go to File > Print, then click the PDF menu at the bottom-left and choose "Save as PDF." On Windows, go to File > Print and pick "Microsoft Print to PDF." This re-exports the content without carrying over any security settings.

## Fix 3: Repair or replace a corrupted file

If a PDF was downloaded over a bad connection and the transfer cut out partway, the file lands on disk with a broken internal structure. It still has a .pdf extension, but the upload portal will reject it.

Test it by opening the file in your PDF viewer. If it fails to open, shows a "file is damaged" message, or cuts off partway through, download it again from the original source and start over.

If the file opens fine locally but gets rejected as invalid, re-save it. Open it in your PDF viewer and print it to a new PDF file (same steps as the section above). This rebuilds the file from scratch and fixes most structural issues that confuse upload validators.

## Fix 4: Try a different browser

File uploads fail in some browsers and work in others more often than people expect. If the upload hangs without any error message, or fails only in one browser:

1. Try Chrome or Firefox, which handle large file uploads more reliably than older browsers.
2. Open a private or incognito window to rule out cached data and credentials.
3. Disable browser extensions one at a time, especially ad blockers and privacy tools. Some block multipart form requests, which is how most file uploads work internally.
4. Clear your browser cache, then try again.

## Fix 5: Move the file out of synced folders

Some platforms and browsers have trouble with files stored in cloud-synced folders (OneDrive, iCloud Drive, Dropbox) that are not fully downloaded locally. The folder shows the file, but when you click it, the browser grabs an incomplete version.

Copy the PDF to your Desktop or Documents folder, confirm it opens correctly there, then try uploading from that location.

## Fix 6: Check for a page count limit, not just file size

Some portals cap submissions by page count rather than, or in addition to, file size. Government immigration portals, court filing systems, and academic submission portals often do this. If that's your situation, use [Split PDF](/split-pdf) to separate the document into the required page ranges and submit each part separately.

## Fix 7: Re-save the file to fix format rejection

Some PDF editors and export tools produce files with non-standard headers that upload validators reject even when the content looks fine locally. If every other step has failed but the file opens correctly, open it in your PDF viewer and print it to a new PDF. The rebuilt file resolves most format-rejection errors because it's generated cleanly from scratch.
