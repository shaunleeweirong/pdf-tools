Inverting PDF colors for dark mode reading is free and takes about a minute. The main decision is whether you want a permanent change to the file or just a dark view on your own screen, because those two things require different approaches.

## What does inverting PDF colors actually do?

Inversion flips every color value to its opposite. White (RGB 255, 255, 255) becomes black. Black becomes white. Dark gray becomes light gray. For a typical document with black text on a white background, the result is white text on a dark page.

People do this for a few different reasons:

- Reading at night without a bright screen hurting their eyes
- Reducing eye strain during long reading sessions
- Printing on dark or tinted paper
- Accessibility needs that make light text on dark backgrounds easier to read

One thing to know upfront: full inversion also flips photos and colored diagrams into a negative. If your PDF has images, that matters. More on this below.

## How to invert PDF colors in Chrome (no extension needed)

Chrome has a built-in flag that applies a dark filter to PDFs and web pages. Here's how to enable it:

1. Open a new Chrome tab and type `chrome://flags` in the address bar.
2. In the search box, type "Auto Dark Mode for Web Contents."
3. Use the dropdown to set it to Enabled.
4. Click the Relaunch button that appears at the bottom.

After Chrome restarts, any PDF you open, from the web or from your local drive, will appear with a dark background and light text. No sign-up, no extension. [Chrome's official help for PDF settings](https://support.google.com/chrome/answer/6213030) covers the other PDF options if you want to adjust behavior further.

This is a viewing filter only. The file is not modified, and the dark appearance stays only while Chrome is set this way.

## How to invert PDF colors permanently (change the actual file)

If you need the dark appearance to show up in every reader, on every device, without any settings, you need a tool that rewrites the PDF. Several in-browser tools handle this without sending your file to a server. They use [WebAssembly](https://webassembly.org/), a standard that lets browsers run compiled code locally, so the color processing happens in your browser tab rather than on a remote server.

Here's the general process for any browser-based inversion tool:

1. Search for "invert PDF colors no upload" to find current tools.
2. Drop your PDF onto the page.
3. Select dark mode or full inversion (some tools also offer sepia or grayscale).
4. Download the resulting PDF.

The output file will look dark in Chrome, Acrobat, Apple Books, and every other PDF viewer, with no settings required on the reader's side.

**File size note:** these tools rasterize each page, turning text and vector elements into JPEG images so the color values can be changed. This makes the output larger than the original, especially for text-heavy documents. Once you have your inverted file, run it through the [Compress PDF tool](/compress-pdf) to reduce the size. Since the output is image-based (each page is now a JPEG), the compressor works well on it.

## Adobe Acrobat Reader: invert text without touching images

Acrobat Reader's accessibility settings let you change the page background and text color without affecting photos or graphics.

1. Open Preferences (Edit menu on Windows, Acrobat Reader menu on Mac).
2. Go to Accessibility.
3. Check "Replace Document Colors."
4. Choose "Use Custom Color" and set the page background to dark gray or black and the text/line color to white or light yellow.
5. Click OK.

The document view changes to your custom colors, but images stay in their original colors. This is the right method for mixed documents where you want a dark background but still need to see photos clearly. It only affects Acrobat on your machine and does not change the file.

## How to invert PDF colors on iPhone and Android

**iPhone.** Go to Settings, Accessibility, Display and Text Size, and turn on [Smart Invert](https://support.apple.com/guide/iphone/smart-invert-colors-iphebc5cdde7/ios). iOS inverts colors across the screen but skips photos and most app UI elements. PDF pages go dark while embedded images remain in their original colors. This is a display-level filter; the PDF file is not changed.

Most iOS PDF reader apps also have a built-in night or dark mode option. Adobe Acrobat Mobile and PDF Expert both have this in their reading settings.

**Android.** Most Android devices include a Color Inversion option in Settings under Accessibility. Enabling it inverts the full screen, including any open PDF. Like iOS Smart Invert, this is a system-level filter and leaves your files alone.

For app-level dark mode, Adobe Acrobat Mobile and WPS Office Reader both have night mode settings that work without modifying the file.

## What actually happens to images when you invert a PDF

For PDFs that are entirely text, like contracts, reports, or academic papers, inversion is clean. The result reads clearly and looks good.

For PDFs with photos or colorful charts, full inversion turns every image into a photographic negative. A color chart with blue bars gets orange bars. A portrait becomes a ghost. Whether this is acceptable depends on the document. You have two realistic options:

- Accept the inverted images and move on.
- Use Acrobat Reader's "Replace Document Colors" setting (described above), which gives you a dark background with readable text while keeping images intact.

There's no free tool that selectively inverts the background color while fully preserving photo colors in the output file. That level of control requires professional layer-aware editing software.

## Combining your inverted PDF with other documents

If you've created a dark-mode version of one document and want to combine it with other files, use the [Merge PDF tool](/merge-pdf). It combines PDFs without inflating the total file size.

One thing to watch: merging strips interactive form fields. If any of your source files has a filled-out form, flatten it first using the [Flatten PDF tool](/flatten-pdf) so the values are preserved as visible page content rather than lost when the fields are removed.
