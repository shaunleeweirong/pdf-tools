You can edit a scanned PDF free online in two ways: add new text on top of the scan using a browser editor (no OCR needed, works in seconds), or use Google Docs to convert the scanned image to real editable text at no cost. Which approach to use depends on what you're trying to do.

## Why scanned PDFs are hard to edit

A scanned PDF is not a text file. It's an image, usually a photograph taken by a scanner or phone camera, saved inside a PDF wrapper. When you open it, what you see on screen is pixels, not characters. There's no text layer for a PDF editor to grab onto.

That's why clicking "edit" in most PDF apps does nothing on a scanned page. The editor finds no selectable text because there isn't any. It's the same reason you can't copy and paste text from a scanned page the way you can from a typed document.

This is where [Optical Character Recognition (OCR)](https://en.wikipedia.org/wiki/Optical_character_recognition) comes in. OCR software looks at the image, identifies shapes that look like letters, and builds a text layer. Once that layer exists, the PDF behaves like a normal typed document.

## Two free approaches, and when to use each

Before picking a tool, figure out what you actually need:

- **You need to add content on top** (fill in a field, write a note, correct something with a text box): skip OCR. Add text directly with a PDF overlay editor. Faster, no conversion step, no accuracy risk.
- **You need to change existing scanned words, copy text, or make the document searchable**: use OCR first, then edit.

Both approaches are free.

One thing to keep in mind: if the original scanned text is wrong and you want to fix it, a text box overlay won't remove or cover the old text cleanly. For that, OCR is the right tool.

## How to edit scanned text for free using Google Docs

[Google Docs has built-in OCR](https://support.google.com/drive/answer/176692) for PDFs uploaded to Google Drive. It's free, requires only a Google account, and works surprisingly well on clean scans. Here's the process:

1. Open [Google Drive](https://drive.google.com).
2. Click "New" and upload your scanned PDF.
3. Once uploaded, right-click the file in Drive.
4. Choose "Open with" and select "Google Docs."
5. Google Docs opens a new document with the scanned text converted to editable characters. The original scanned image appears below.
6. Edit the text in the document.
7. When done, go to File > Download > PDF Document (.pdf) to save it back as a PDF.

The result is a real text document, fully searchable and editable. The quality depends heavily on the scan. A clean, high-contrast, 300 DPI scan of printed text converts with very high accuracy. A blurry or low-light scan may introduce errors, so read through the output before sending it anywhere important.

If you need to go the other direction and make a scanned PDF searchable without turning it into a Google Doc first, see our guide on [making a scanned PDF searchable](/blog/how-to-make-a-scanned-pdf-searchable-free).

## What to do when OCR accuracy is low

No free OCR tool is perfect. When conversion accuracy matters, these steps help:

- **Start with the highest quality scan you can get.** If you have the physical document, re-scan at 300 DPI or higher. Black-and-white mode often works better than color for text pages.
- **Check for common OCR errors.** The letters l, 1, and I are frequently confused. So are 0 and O. Numbers embedded in text often get mangled.
- **Fix errors manually.** In Google Docs you can find and replace, which speeds up correcting a repeated OCR mistake across the whole document.
- **Don't edit the Google Doc version and call it final without a proofread.** OCR is good enough to edit from, not always good enough to publish without checking.

## Can I edit a scanned PDF on my phone?

Yes, with a browser-based tool. On iOS or Android, open Safari or Chrome and visit our [Edit PDF tool](/edit-pdf). Upload the PDF from your files app. The text tool works on mobile just like on desktop: tap to place a text box, type, and download. For large scans, a phone browser may be slower, but it gets the job done.

For full OCR on mobile, the Google Drive app on iOS and Android supports the same "Open with Google Docs" workflow described above. Find your file in the Drive app, tap the three-dot menu, and select "Open with Google Docs."

## What happens to file size after OCR?

Running OCR through Google Docs and downloading back to PDF sometimes changes the file size. The original scanned image is typically preserved alongside the new text layer, which can make the file larger. If the resulting PDF is too large to send or upload, run it through our [Compress PDF tool](/compress-pdf) afterward. That tool works best on image-heavy files, which a scanned PDF is.

## A note on handwritten documents

OCR on handwriting is a different problem from OCR on printed text. General-purpose tools like Google Docs handle printed fonts well but struggle with cursive or irregular handwriting. If you're working with handwritten documents, the overlay approach (adding typed text in a text box near the handwriting) is often more practical than OCR.

There are specialized handwriting recognition tools, but none of them are free at any useful level of accuracy for scanned documents today.
