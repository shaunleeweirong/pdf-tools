The best free PDF Candy alternatives are browser-based tools that run with no hourly cap, no sign-up, and no file ever sent to a server. PDF Candy's free tier lets you use its 90+ tools, but restricts you to one task per hour, and every file passes through its servers before you get the result back. The options below have neither constraint.

## What limits PDF Candy's free tier?

PDF Candy is a well-built product and genuinely free to try. The friction comes from one specific restriction:

**One task per hour.** Run a task on the free tier and you'll wait 60 minutes before you can run another. Merge a PDF and then want to compress the result? You're done for the hour. The paid plan removes this: subscriptions run about [$6 per month or $48 per year](https://pdfcandy.com/), with a $99 lifetime option.

**Files travel to PDF Candy's servers.** Every file you process goes to PDF Candy's infrastructure (hosted in the EU and USA), gets processed there, and is deleted within two hours. For most tasks that's fine. For legal contracts, tax returns, medical records, or anything professionally sensitive, it's worth knowing that your file left your device.

What PDF Candy does right: no sign-up is required for basic tasks, the interface is clean, and the tool selection is massive. If you need one thing every couple of hours, it works fine.

## What "browser-based processing" actually means

When a PDF tool processes files in your browser, your document never leaves your device. The tool loads into a browser tab, then uses [WebAssembly](https://webassembly.org/) and JavaScript to run the PDF operations locally. The output file is created on your machine and downloaded directly.

Practical results:

- No hourly cap (your device does the compute, not theirs)
- No account needed (nothing to authenticate against)
- No server to upload to (files with sensitive content stay private by design)
- Works offline once the page has loaded

The tradeoff: some tasks are genuinely hard to run in a browser. OCR (text recognition from scanned pages) and PDF-to-Word conversion both need substantial processing that runs better server-side. PDF Candy handles both; browser-based tools generally don't.

## Tools that cover what people use PDF Candy for

The tools on this site cover the tasks most people run on PDF Candy, with no hourly cap, no account, and no upload.

**Merge PDFs**

Combine any number of files into one, drag them into the order you want, download. The [Merge PDF tool](/merge-pdf) runs entirely in your browser. One thing to know: merging strips interactive form fields from the PDF. If you've filled out a form and need to merge it with another document, use the [Flatten PDF tool](/flatten-pdf) first to bake the values into the page. Otherwise the fields, and the data in them, will be lost.

**Compress a PDF**

The [Compress PDF tool](/compress-pdf) works by rasterizing each page to a JPEG image. That makes it effective on scanned documents and image-heavy PDFs. In testing, a 913.4 KB deck of image pages dropped to 315.3 KB at Medium quality and 175.6 KB at High. On a text-only PDF, the same process makes the file bigger, not smaller, because vector text is compact and a photograph of that text is not. If your PDF is a report, invoice, or contract with no photos, don't compress it. Split out pages you don't need, or zip the file instead.

**Split a PDF**

Pull out specific pages or ranges with the [Split PDF tool](/split-pdf). Useful for sending one section of a large report, or for reducing file size when you only need part of a document.

**Rotate pages**

Fix a sideways scan or a page printed in the wrong orientation with the [Rotate PDF tool](/rotate-pdf). Rotation only changes an orientation flag, so file size stays the same.

**Password protect or unlock**

The [Protect PDF tool](/protect-pdf) encrypts your file with AES-256 using qpdf. The size overhead is about 1 KB regardless of the file's original size, so adding a password won't push you over an email limit. The [Unlock PDF tool](/unlock-pdf) removes a known password from a file so you can merge, split, or share it without restriction.

**Convert images to PDF, or PDF to images**

The [Images to PDF tool](/jpg-to-pdf) turns JPG and PNG files into a PDF, one image per page. The [PDF to JPG tool](/pdf-to-jpg) does the reverse. Both run in your browser.

**Sign, watermark, and organize**

[Sign PDF](/sign-pdf) lets you draw a signature and place it on a page. [Watermark PDF](/watermark-pdf) stamps text across every page. [Organize PDF](/organize-pdf) lets you reorder or remove pages visually before downloading.

You can verify any of these are genuinely local: open the tool, disconnect your internet connection, and run it. A truly browser-based tool still works offline because no server was ever involved.

## Where PDF Candy is still the better choice

Recommending a replacement for every task would be easy and wrong. PDF Candy does several things well that browser-based tools handle poorly.

**OCR.** Converting a scanned image-only PDF into searchable, copy-able text requires a large model and compute that most browsers can't run efficiently. If you need an archive of scanned documents made searchable, PDF Candy or a similar server-based tool will do it better.

**Format conversion.** Faithful PDF-to-Word, PDF-to-Excel, and PDF-to-PowerPoint conversion is hard and still mostly a server-side job. PDF Candy covers these; the tools on this site don't attempt them.

**Large files on slow devices.** A several-hundred-megabyte PDF can exhaust the memory a browser tab can access, particularly on an older phone or laptop. A server-based tool has no such constraint.

**Heavy daily use needing OCR or conversion.** If you're processing dozens of documents a day and need format conversion, PDF Candy's paid plan, or a desktop app like PDFgear (free for Windows and Mac), makes more sense than a browser tab.

For everyday tasks, merge, split, rotate, compress image PDFs, convert images to PDF, sign, watermark, password-protect, the browser-based tools above are free, unlimited, and keep your files on your device. For OCR and format conversion, PDF Candy is the right call.

## Is it safe for confidential files?

Browser-based tools are the strongest privacy option, not because of a policy, but because of how they work. When your PDF never leaves your device, there's no server-side copy to be stored, logged, or compromised. Tax returns, signed contracts, and medical records that stay in a browser tab are simply not on any third party's infrastructure.

PDF Candy is transparent about its practices: files are encrypted in transit and at rest using AES-256, hosted on EU and USA servers, and deleted within two hours. That's a reasonable policy. But it's still a policy, and it still requires trusting their infrastructure. With an in-browser tool, there's no infrastructure to trust.

Yes. Because they run in a browser tab, they work on any device with a modern browser: Chrome, Firefox, Safari, or Edge on Mac, Windows, Linux, Chromebook, Android, and iOS. There's nothing to download or install.
