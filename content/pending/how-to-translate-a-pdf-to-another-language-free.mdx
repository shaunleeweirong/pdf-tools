The fastest free ways to translate a PDF to another language are [Google Translate's document upload](https://translate.google.com/) (133+ languages, no sign-up required) and [DeepL](https://www.deepl.com/translator) (better fluency for European languages). Both take under a minute for a short document. For scanned PDFs, where text is stored as an image rather than selectable characters, there's an extra step covered below.

## How to translate a PDF with Google Translate

Google Translate handles PDF uploads directly and it's free with no account needed.

1. Go to [translate.google.com](https://translate.google.com/) and click the **Documents** tab.
2. Click **Browse your computer** and select your PDF, or drag and drop it onto the page.
3. Set the source language (or leave it on "Detect language") and choose your target language.
4. Click **Translate**.
5. Once the translation finishes, click **Download translation**.

The translated PDF will have the text replaced in place. File size is capped at roughly 10 MB. If your document is larger than that, [split it into smaller files first](/split-pdf) and upload only the pages you actually need.

One thing to keep in mind: Google Translate can't read text that's stored as an image. If you open the PDF and can't select the text with your cursor, it's a scanned document. Jump to the scanned PDF section below.

## How to translate a PDF with DeepL for free

DeepL was trained on high-quality translated texts, and for European language pairs it typically produces more natural-sounding results than Google Translate.

1. Go to [deepl.com/translator](https://www.deepl.com/translator).
2. Click **Translate files** on the left panel.
3. Drag your PDF onto the upload area, or click to browse for it.
4. Choose the target language from the dropdown.
5. Wait for the translation to finish, then click **Download**.

The free tier limits how many pages you can translate per month. DeepL supports 31 languages as of 2026, versus 133+ for Google Translate. If your target language isn't in DeepL's list, Google Translate is the better option. For French, Spanish, German, Portuguese, Italian, Dutch, and Polish documents, DeepL is worth trying first.

## How to translate a PDF using Google Drive

This method needs no additional tools and is already available to anyone with a Google account. It's also a good option for scanned PDFs (more on that below).

1. Upload your PDF to [Google Drive](https://drive.google.com/).
2. Right-click the file and choose **Open with > Google Docs**. Google Docs will convert the PDF to editable text, running OCR automatically if the file is a scan.
3. In the opened document, go to **Tools > Translate document**.
4. Pick the target language and click **Translate**.
5. A new Google Doc opens with the translated text. Download it as a PDF via **File > Download > PDF Document**.

The layout won't match the original precisely because Google Docs treats the content as flowing text rather than fixed-position elements. For short documents, research papers, or contracts where content matters more than design, that's usually fine.

## How to translate a scanned PDF

A scanned PDF is essentially a photograph of a page. There's no text layer for a translator to read, which is why uploading a scan to Google Translate often returns a blank result or fails silently.

The fix is to extract the text with OCR (optical character recognition) first. The Google Drive method above handles this automatically when you open the PDF with Google Docs. For most cleanly scanned documents, this produces good results.

If the automatic OCR doesn't work well (poor scan quality, unusual fonts, or handwriting), a dedicated OCR tool can do a cleaner extraction. Once you have the text, you can paste it into Google Translate or DeepL directly.

## Why formatting changes when you translate a PDF

[PDF](https://en.wikipedia.org/wiki/PDF) is designed for fixed layout: every word, image, and text box is pinned to exact coordinates on the page. When a translator swaps English text for German, words get longer on average. There's no automatic reflow to expand text boxes or adjust columns, so text overflows, tables break apart, and paragraphs run into each other.

This is a structural limitation of the PDF format, not a flaw in the translation tool. If maintaining the original layout is important, the best approach is to translate the source file (Word, Google Docs, PowerPoint) before converting to PDF. Formats that use flowing text handle word-length changes gracefully because the text box boundaries are flexible.

## Google Translate vs DeepL: which is better?

| | Google Translate | DeepL |
|---|---|---|
| Languages | 133+ | 31 |
| Best for | Any language pair, quick results | European languages, better fluency |
| File size limit | ~10 MB | ~5 MB (free) |
| Sign-up required | No | No |
| Monthly limit | None | Limited pages on free tier |

For a quick translation in any language, Google Translate is the easier choice. For French, Spanish, German, Italian, or Portuguese documents where natural phrasing matters, DeepL tends to read better. Neither tool handles complex multi-column layouts perfectly.

## Tips for better PDF translation results

**Translate shorter sections.** A 200-page book is hard for any free tool to process reliably. Use a [PDF splitter](/split-pdf) to pull out the chapter or section you need, then translate that alone. Smaller files give more consistent results.

**Start from the original PDF.** If you've run the file through a compression tool that rasterizes pages (converting text to images), the translator won't be able to read the text. Always translate from the unmodified original.

**Double-check important documents.** Machine translation handles general language well but struggles with legal terminology, medical phrasing, and technical jargon. For any document that will be used officially, have a native speaker review the output before relying on it.

**Use the source file when you have it.** If someone sent you a Word file that was saved as a PDF, ask for the original. Translating a Word document and then saving it as a PDF produces a cleaner result than translating the PDF directly.
