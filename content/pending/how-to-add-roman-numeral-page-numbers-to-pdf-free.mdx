Adding roman numeral page numbers to a PDF is free and takes about two minutes using a browser-based tool, no sign-up required. The catch is that most free tools apply one numbering format across the whole document, so mixing roman numerals for front matter with Arabic numbers for the body requires splitting the file first.

This guide covers which tools actually support roman numeral formats, a step-by-step walkthrough, and the exact workflow for getting the mixed numbering that thesis and dissertation submissions typically demand.

## Why PDFs use roman numerals for page numbers

Roman numerals mark the [front matter](https://en.wikipedia.org/wiki/Book_design#Front_matter) of a formal document. Front matter is everything before Chapter 1: the title page, abstract, table of contents, list of figures or tables, and acknowledgments or a preface. Using a different number style makes it obvious at a glance which pages belong to the introductory material.

This convention goes back centuries in book publishing and academic printing. Universities and publishers follow it because page counts in citations and library records use the roman numeral sequence to distinguish introductory content from the main work.

The standard arrangement is:
- Title page: counted as page i, but no number appears on the page
- Abstract: page ii (the first page that shows a number)
- Table of contents, list of figures, acknowledgments: iii, iv, v...
- Chapter 1: restarts at Arabic numeral 1

## Which free tools support roman numeral page numbers

Not every free PDF tool offers this feature. Standard page number tools insert Arabic numerals only. Here are the tools that support roman numeral format with no cost and no login:

## How to add roman numeral page numbers using PDF24

PDF24 is the most straightforward free option for this. Here is the process:

1. Open tools.pdf24.org and choose the "Add page numbers" tool.
2. Upload your PDF file.
3. Under the **Format** setting, choose Roman numerals (uppercase or lowercase, depending on your requirement).
4. Set **Start at** to the number that should appear on the first visible page. If your title page shows no number and the abstract should show "ii", set Start at to 2 and begin numbering from page 2.
5. Pick a position. Bottom center is the most common placement for academic submissions.
6. Click to create the PDF and download it.

For a standard thesis front matter, pick lowercase roman numerals. Most university formatting guides specify lowercase.

## How to mix roman numerals and Arabic numbers in one PDF

This is the question that trips up most people. You want pages 1 to 8 (front matter) in roman numerals and pages 9 onward (body chapters) in Arabic numbers starting at 1. Since most free tools number the whole document in one format, you need to split the file first.

Here is the full workflow:

1. **Split the PDF into two sections.** Use our [Split PDF tool](/split-pdf): upload the file, extract the front matter pages as one file and the body pages as another.
2. **Number the front matter section** using PDF24 with roman numerals. Set Start at to 2 if the title page (page 1 of this section) should show no number.
3. **Number the body section** with Arabic numerals starting at 1, using PDF24 or any other page number tool.
4. **Merge the two numbered files** back into one using our [Merge PDF tool](/merge-pdf). Upload the front matter file first, then the body file, in the correct order.

The result is a single PDF with roman numeral front matter and Arabic body chapters. The entire process takes under ten minutes for a typical thesis.

## What university formatting guides actually require

Most graduate schools follow the same basic pattern, though details vary:

**Title page:** Counted as page i in the roman numeral sequence, but no number is displayed on the page itself. Some institutions count the copyright page the same way.

**Front matter pages:** Lowercase roman numerals (ii, iii, iv...). This covers the abstract or executive summary, table of contents, list of figures, list of tables, acknowledgments, and any preface or dedication.

**Chapter 1 onward:** Arabic numerals starting at 1. This includes the main body chapters, the reference list or bibliography, and appendices.

A few institutions number appendices differently, using a letter-number combination like A-1, A-2 for Appendix A pages. Always check your institution's own graduate school formatting manual rather than relying on general advice, because these details matter at submission time.

The [University of Michigan Library's dissertation formatting guide](https://guides.lib.umich.edu/c.php?g=1114879&p=8128998) is a thorough reference if you want to see a common standard laid out in full. The Missouri Graduate School's formatting requirements are another frequently cited example.

## How to start roman numeral numbering from a specific page

The "Start at" or "Starting number" setting controls which number appears on the first visible page. Configuring it correctly depends on your document structure.

Common scenarios:

- Title page (no number shown) + Abstract (should show ii): Upload the whole front matter section, set the tool to start numbering from page 2, starting value 2.
- Title page (no number) + Copyright page (no number) + Abstract (should show iii): Start numbering from page 3, starting value 3.
- All front matter pages get numbers including the title page: Start numbering from page 1, starting value 1 (for i).

If a tool does not let you skip pages, the split-number-merge workflow above gives you full control. Number only the pages that should receive a number, leaving the title page in a separate unnumbered section.

## Does adding page numbers change the file size?

Not in any meaningful way. Inserting page numbers adds a small amount of PDF markup to each page, but the file size barely moves. A 913 KB file stays close to that after numbering, with a difference of a few kilobytes at most.

If you need to reduce file size before or after adding numbers, our [Compress PDF tool](/compress-pdf) works well on image-heavy PDFs and scanned documents. Text-only PDFs generally do not benefit from compression and can actually get larger if run through a rasterizing compressor, so for a text thesis the best approach is to submit the file as-is rather than compressing it.

## Uppercase or lowercase roman numerals?

Both I and i are used in formal documents. Most thesis formatting guides specify lowercase (i, ii, iii) for front matter. Uppercase roman numerals appear more often in older publishing conventions and some legal documents.

When in doubt, default to lowercase. It is the standard in modern academic formatting, and if your institution specifies uppercase it will say so explicitly in the formatting manual.
