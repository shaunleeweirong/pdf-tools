## Why people add watermarks to PDFs

A watermark is a word or phrase that repeats diagonally across every page of a document. The main reasons people add one:

- Marking a document's status: DRAFT, UNDER REVIEW, or APPROVED
- Protecting content: CONFIDENTIAL, DO NOT COPY, or PROPRIETARY
- Identifying ownership: your name, company, or website
- Preventing misuse: SAMPLE ONLY on anything shared before a deal is done
- Version control: marking which iteration is which when you share multiple copies

According to [ISO 32000](https://www.iso.org/standard/63534.html), the PDF specification, "Watermark" is a recognised annotation subtype, which is why a properly applied watermark survives copying and printing rather than stripping off when someone saves a new copy.

## Choosing watermark text that actually reads well

Short, uppercase text in a diagonal orientation reads clearly at any page size. Full sentences get too cramped and lose legibility on smaller pages. Here are common combinations:

| Goal | Text to use |
|---|---|
| Legal protection | CONFIDENTIAL |
| Work in progress | DRAFT |
| Preview copy | SAMPLE |
| Shared under embargo | DO NOT DISTRIBUTE |
| Proof of authorship | Your name or company name |
| Internal use only | FOR INTERNAL USE ONLY |

Avoid punctuation that might not render consistently across PDF viewers. Letters, numbers, and spaces are the safest bet. If your name is long, initials or a short brand name work better than the full version.

## Can I add an image watermark (like a logo)?

Text watermarks are the easiest option on a phone. Image watermarks, such as a semi-transparent company logo, typically require either a dedicated PDF app or a web service that accepts image uploads alongside the document. [Adobe Acrobat's watermark guide](https://helpx.adobe.com/acrobat/desktop/edit-documents/add-backgrounds-and-watermarks/add-watermarks.html) explains how image watermarks work in their desktop tool if you need that level of control.

If you only need a text mark, browser-based tools like ours handle it well from mobile Safari.

## What if you need to remove a watermark later?

Keep the original. A watermark baked into PDF page content is part of the document now, and removing it means editing each page's drawn content, which most free tools cannot do reliably. The right workflow is:

1. Store the clean original in a dedicated folder.
2. Share only the watermarked copy.
3. When you need an updated version (different text, new date, different label), apply a fresh watermark from the original.

Online services that claim to "remove watermarks" work only in specific cases, typically when the watermark is stored as a separate PDF layer rather than painted into the page. Don't assume removal will be possible.

## When watermarking is not the right tool

A watermark tells people the document's status, but it doesn't actually prevent copying or editing. If you need real access control, a password does that better. Our [Protect PDF tool](/protect-pdf) encrypts the file so it requires a password to open, and you can also restrict printing and copying separately.

If the goal is preventing someone from lifting images or text, a watermark is a deterrent, not a lock. For genuinely sensitive documents, combine a watermark (so the status is visible on every page) with password protection (so only intended recipients can open it).

## Getting the watermarked PDF off your iPhone

After downloading, the file usually lands in your Downloads folder inside the Files app. From there you can:

- AirDrop it to a Mac or another Apple device
- Share it via Mail, Messages, or WhatsApp
- Move it to iCloud Drive, Google Drive, or Dropbox for access on other devices
- Open it directly in another app using the Share sheet

If you regularly watermark documents before sharing, it's worth creating a dedicated folder in Files so you can find both originals and watermarked copies quickly.
