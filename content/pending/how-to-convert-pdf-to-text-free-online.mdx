Converting a PDF to text is free and takes about a minute, but the right method depends on one thing: whether your PDF contains actual text or is just a scanned image of text. Get that distinction right and the rest is easy.

## First: figure out which type of PDF you have

Open your PDF and try clicking and dragging over a single word. If you can highlight individual words, the file has a text layer. These are called native PDFs, and they're produced by Word, Google Docs, Acrobat, or any software that exports to PDF directly.

If clicking and dragging selects the entire page as one block, or does nothing at all, the file is a scanned PDF. Each page is stored as a raster image, not as text. A computer sees pixels, not letters, which is why you can't select or copy anything.

Why does this matter? Native PDFs need no special treatment. Scanned PDFs require [optical character recognition (OCR)](https://en.wikipedia.org/wiki/Optical_character_recognition), a technology that reads images of text and converts them into characters a computer can work with.

## Method 1: Copy and paste (native PDFs, takes 10 seconds)

If your PDF has a text layer:

1. Open the PDF in any PDF viewer or your browser.
2. Press Ctrl+A (Windows) or Cmd+A (Mac) to select all text on the page.
3. Press Ctrl+C or Cmd+C to copy.
4. Paste into any text editor, Google Doc, or Word file.

That's it. No tool, no account, no upload. For longer documents, Ctrl+A selects the visible page in most browsers, so you may need to scroll and repeat page by page.

If you want the full document in one shot, Adobe Acrobat Reader's Edit menu has a "Copy All Text" option. It's free to download and use for reading.

## Method 2: Google Docs OCR (works for both types, completely free)

Google Docs has OCR built in and will convert a scanned PDF to editable text for free. You do not need a paid account for this.

1. Go to [Google Drive](https://drive.google.com) (sign in with any Google account).
2. Click the plus icon and upload your PDF.
3. Right-click the uploaded file and choose "Open with Google Docs."
4. Google Docs opens the PDF and runs OCR automatically. Scanned pages appear as images at the top, with the extracted text below them.
5. Select the text, copy it, or go to File > Download > Plain Text (.txt) to save it as a text file.

Accuracy depends on scan quality. A sharp, high-contrast scan (300 DPI or above) typically produces very clean output. Faxed documents, low-resolution photos, or handwritten pages will have more errors.

One limitation worth knowing: Google Docs OCR works well for single-column text. Multi-column layouts (like newspapers or academic papers) often come out in the wrong order. For those, a dedicated OCR tool handles the column detection better.

## Method 3: Use a free online PDF to text converter

Several tools handle the conversion entirely in their interface without requiring a Google account:

**PDF24** (tools.pdf24.org) is one of the most capable free options. Upload your PDF, choose the "PDF to Text" tool, and download a .txt file. It uses OCR for scanned pages. Files are processed on their servers.

**FreeConvert** (freeconvert.com/pdf-to-text) supports files up to 1 GB and runs OCR on scanned pages. No account is needed.

**ilovepdf** (ilovepdf.com) has a dedicated OCR tool that creates a searchable PDF, which you can then copy from. Good for preserving approximate layout.

Choose whichever fits your privacy preference. If the document contains sensitive information, the Google Docs method (where you control the file in your own Drive) may feel more comfortable than uploading to a third-party tool.

## Why formatting disappears when you convert to text

Plain text files (.txt) have no concept of columns, fonts, tables, or spacing. Everything collapses into a linear stream of characters. That is by design, because plain text is what most apps, scripts, and databases want for processing.

If you need the text to look close to the original PDF, convert to Word format (.docx) rather than plain text. Google Docs lets you do this under File > Download > Microsoft Word. Tools like ilovepdf and PDF24 also offer PDF to Word conversion, which preserves more structure.

## When these methods do not work

A few situations where the above methods struggle:

**Handwritten text.** Google Docs OCR handles print clearly, but handwriting recognition is unreliable at best. There is no reliably free solution for handwritten documents; dedicated handwriting OCR services exist but are mostly paid.

**Very low resolution scans.** If the scan was made at below 150 DPI, or is blurry, OCR accuracy drops significantly. Rescanning at 300 DPI before converting is worth the effort if you have access to the original document.

**Right-to-left and complex script languages.** Arabic, Hebrew, and some Asian scripts need OCR engines trained on those languages. Google Docs supports many languages; check the settings before assuming it will work.

**Encrypted PDFs.** If the PDF is password-protected, you'll need to remove the restriction before any tool can access the text. You can remove a known password with our [PDF password remover](/unlock-pdf), then proceed with the conversion.

The [Open Preservation Foundation's guide to scanned vs native PDFs](https://openpreservation.org/blogs/scanned-vs-native-pdfs-how-to-differentiate-them/) has a good deeper explanation of how PDF file types differ technically, if you want to understand what's happening under the hood.
