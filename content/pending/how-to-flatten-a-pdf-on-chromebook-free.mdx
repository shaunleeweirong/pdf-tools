Flattening a PDF on Chromebook is straightforward with the right tool. The [Flatten PDF tool](/flatten-pdf) runs entirely in Chrome, so there is nothing to install. Drop your file in, and the flattened version is ready to download in seconds. No account, no upload to a server.

## What does flattening a PDF actually do?

A PDF can hold two kinds of content: the visible page itself (text, images, graphics) and an interactive layer on top of it (form fields, text boxes, checkboxes, annotations, digital signatures). When you flatten a PDF, those interactive elements are merged permanently into the page. The document looks the same, but readers can no longer click into a form field or edit an annotation.

The [PDF specification (ISO 32000)](https://pdfa.org/resource/pdf-specification-archive/) defines fillable forms through a structure called AcroForms. Flattening removes that structure. What you are left with is a static document that prints, displays, and archives consistently across any device or viewer.

## When should you flatten a PDF on your Chromebook?

**Before filing with a court or government portal.** Many US federal courts require flattened PDFs for electronic filing because active form fields can cause the court's e-filing system to reject or misprocess a document. The [Western District of Kentucky Bankruptcy Court](https://www.kywb.uscourts.gov/how-flatten-pdf-files), along with a number of other federal courts, publishes explicit instructions telling filers to flatten before uploading. If you are submitting a completed form to any official portal, flatten it first.

**Before merging.** Combining a filled-in form with other documents can strip the interactive fields and pull the typed values out with them. Flatten first, then merge, and the content stays locked in the page. See the section below on merging for more detail.

**Before emailing or sharing.** A flattened PDF prevents the recipient from accidentally changing the content. This matters for contracts, completed applications, invoices, and any document where you want the reader to see the values exactly as you entered them.

**Before printing.** Some printers handle interactive PDFs inconsistently, especially older printers or shared office equipment. Removing the interactive layer eliminates that variable.

## How to flatten a PDF on Chromebook with the Flatten PDF tool

The [Flatten PDF tool](/flatten-pdf) processes your file in the browser and returns a static PDF with all form fields and annotations merged into the page content.

1. Open [Flatten PDF](/flatten-pdf) in Chrome on your Chromebook.
2. Click the upload area or drag your PDF file into it.
3. The tool processes the file automatically. For most documents this takes just a few seconds.
4. Click Download to save the flattened PDF to your Chromebook.

Because the tool runs locally, your file data stays on your device and is not sent to any external server.

## How to flatten a PDF on Chromebook using Print to PDF

Chrome's built-in Print to PDF can flatten many PDFs without any extra tool:

1. Open the PDF in Chrome. You can do this by dragging the file onto a Chrome tab, or by right-clicking the file in the Files app and choosing "Open with Chrome."
2. Press **Ctrl + P** to open the print dialog.
3. In the Destination dropdown, choose **Save as PDF**. Do not select a real printer.
4. Click **Save** and pick a location in the Files app.

This works because Chrome renders the PDF visually and then generates a new PDF from that rendering. The result typically bakes form fields into the page.

The limitation: Print to PDF does not always handle every type of interactive element. JavaScript-driven fields, certain signature widgets, and layered annotations sometimes survive or render incorrectly. For a filled government form or a legal document, the dedicated [Flatten PDF tool](/flatten-pdf) is the safer path.

## Should you flatten before merging PDFs?

Yes, if any of your source files contain filled forms.

When you combine multiple PDFs with [Merge PDF](/merge-pdf), the tool copies page content from each file into a single output. It does not carry over interactive form fields. That means if you merge a filled-in form before flattening it, the AcroForm layer is stripped in the process.

Whether the typed values remain visible in the merged output depends on how the form was built. Some forms display field values as visible text that survives the merge; others do not. To avoid any uncertainty, flatten every filled form before you merge. That way the values are painted permanently into the page and will appear correctly regardless of how the merge handles the interactive layer.

The safe order is: fill the form, save it, flatten it, then merge.

## Save a copy before you flatten

Flattening is not reversible from the output file. Once the interactive layer is gone, you cannot recover it from the flattened version. Before flattening, keep the original filled PDF somewhere you can find it. On a Chromebook, the Files app's Downloads folder works fine for quick storage. If you expect to update the form again later, save the original to Google Drive so it is accessible from any device.
