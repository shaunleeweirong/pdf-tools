Merging password-protected PDF files is a two-step job: remove the password from each protected file first, then combine them. Both steps are free, run entirely in your browser, and don't require an account or any software to install.

## Why Password-Protected PDFs Can't Be Merged Directly

A PDF with password protection isn't just locked at the surface. The [PDF standard (ISO 32000)](https://pdfa.org/resource/pdf-specification-index/) defines encryption that scrambles the file's internal structure. A merge tool that wants to pull pages from two PDFs needs to read both files at a structural level, and an encrypted file doesn't expose that structure without the key.

There are two types of PDF passwords, and both cause the same problem:

**Open password (document password):** The file won't open at all without this password. It's the most obvious kind of protection. Any tool that tries to combine this file will hit a wall immediately.

**Permissions password (owner password):** The file opens for reading, but specific actions like editing, printing, and combining are blocked. This one catches people by surprise because the file looks accessible. You can read it in a viewer, but a merge tool still can't do anything with it.

Both types will stop a merge from completing. The fix is the same in each case: remove the password first.

## Step 1: Remove the Password From Each Protected File

Open the [Unlock PDF tool](/unlock-pdf), drop in a password-protected file, and enter the password when prompted. The tool processes your file using [qpdf](https://github.com/qpdf/qpdf), an open-source PDF library, and everything runs locally in your browser. Nothing is sent to a server. Click Download to save the decrypted copy.

Repeat this for each protected file in your batch. If you're combining four PDFs and three of them are locked, all three need to be decrypted before you move on.

A quick way to identify which files are protected: open each one in Chrome or Firefox. If it asks for a password, it has an open password. If it opens but right-clicking and choosing "Copy" does nothing, or a print dialog shows fewer options than usual, it has a permissions password. Both are handled by the Unlock PDF tool.

## Step 2: Merge All the Decrypted Files

Once every protected file has been decrypted, go to the [Merge PDF tool](/merge-pdf). Drop in all the files you want to combine, including any that were never protected. Drag to reorder them if the page sequence matters, then click Merge and download the result.

The whole process for a batch of 3 to 5 typical-sized files takes under two minutes.

## Does Merging Change the File Size?

Not in any meaningful way. When we merged three test files totalling 971.9 KB, the output came back at 970.5 KB, a 0.1% reduction. Merging copies pages from each source document without re-rendering or re-encoding anything, so you won't gain or lose much.

If the merged file ends up too large for email or an upload limit, and the document is image-heavy (scans, photos, image decks), you can run it through the [Compress PDF tool](/compress-pdf) afterward. Note that compression rasterizes every page to JPEG, so it works well on image-heavy documents but will actually make text documents larger. For a text-only merged file that's too big, splitting or zipping is a better option.

## Flatten Filled Forms Before Merging

This step trips up a lot of people. If any of your PDFs are filled-in forms, forms with text you've typed into the fields, flatten them before you add them to the merge.

Our merge tool combines pages, not the interactive layer that sits on top of them. During the merge, the interactive form fields are stripped from the output. Page content (text, images, anything drawn on the page itself) survives intact, but the form fields and their values do not carry over.

Flattening converts form fields into ordinary page content, painting the filled values directly onto the page. After flattening, the values are permanent and will survive any subsequent operation, including merging.

Use the [Flatten PDF tool](/flatten-pdf) on any filled form. The steps for a filled, protected form look like this:

1. Remove the password from the form using the Unlock PDF tool.
2. Flatten the decrypted form using the Flatten PDF tool.
3. Add the flattened file to your merge batch along with the other files.

If you skip step 2 and merge a filled form directly, the merge will complete, but the form fields and their values may not appear in the combined document.

## What If You Don't Know the Password?

The Unlock PDF tool requires the correct password to work. It can't guess or bypass encryption, and that's by design. Most modern PDFs use [AES-256 encryption](https://en.wikipedia.org/wiki/Advanced_Encryption_Standard), which is computationally infeasible to break by trial and error.

If you forgot a password you set yourself, check your password manager or any secure notes you made when you protected the file. If the document came from another person or organization, you'll need to contact them to get either the password or an unprotected version of the file.

Be cautious with online tools that promise to remove an unknown password. They typically only work on files protected with older, weaker encryption schemes or extremely short passwords. A modern, strong password won't be affected.

## Merging Many Files at Once

You don't need to merge two files, then add a third, then a fourth. The Merge PDF tool accepts as many files as you need in a single session. Once all your files are decrypted, drop them all in at once, arrange the order, and merge once. Chaining merges individually would produce the same result but takes more steps.

If you're working with a recurring batch of files that are regularly password-protected, it's worth asking whoever creates them whether they can provide unprotected versions directly, or at least share a consistent password. That saves the per-file decryption step every time.
