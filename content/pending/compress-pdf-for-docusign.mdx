Compressing a PDF for DocuSign is quick when you know which kind of file you have. Scanned documents and image-heavy PDFs compress well in your browser, for free. Clean, text-based contracts do not, and compressing them makes the file larger.

## What is DocuSign's file size limit?

DocuSign accepts files up to 50 MB per document, but their [official support documentation](https://support.docusign.com/s/document-item?language=en_US&bundleId=gbo1643332197980&topicId=akk1578456465691.html) recommends keeping uploads under 5 MB for reliable performance. Large files can time out on slower connections before processing completes.

There is also a 5 MB ceiling for completed documents. When all parties have signed, DocuSign emails a confirmation with the finished PDF attached. If the signed document is over 5 MB, the attachment is replaced with a download link. That works fine, but if recipients expect the document directly in their inbox, you will want to start with a smaller file.

In practice, most text contracts sit well under 1 MB and never cause problems. The files that hit limits are scanned paper documents, multi-page photo IDs, and reports with embedded high-resolution images.

## When compression actually helps

If your PDF contains scanned pages or full-page images, compression will cut the file size substantially. Our [Compress PDF tool](/compress-pdf) works entirely in your browser. It rasterizes each page to JPEG at the quality level you choose, then wraps the images back into a PDF.

Real numbers from our own testing: a 6-page image deck that started at 913.4 KB came out at 315.3 KB at Medium quality (a 65.5% reduction) and 175.6 KB at High compression (an 80.8% reduction). If your file has a similar profile, scanned pages and embedded images, you can expect results in that range.

Which level to pick for DocuSign uploads:

- **Medium** works for most scanned contracts. Text stays readable and you will usually land well under 5 MB.
- **High** (maximum compression, smallest output file) is useful if Medium still leaves you over the limit. Text gets a bit softer but stays readable on screen and when printed.
- **Low** barely moves the needle on file size. Skip it for upload purposes.

One rule: do not run compression twice. Feeding the output back into the compressor makes the file bigger. In our testing, a file already compressed to 315.3 KB at Medium grew to 598.9 KB after a second Medium pass. If Medium is not enough, go back to your original file and choose High.

## When you should NOT compress

If your PDF is a clean, text-based document generated by Word, Google Docs, or any PDF printer, a browser-based compressor will make it substantially larger.

These tools work by converting each page to a JPEG image. Text stored as vector glyphs is tiny; text stored as a photograph of those glyphs is not. In our testing, a 20-page text report grew from 23.5 KB to 1.4 MB after a Medium compression pass. Uploading that to DocuSign would make things worse, not better.

For a text-based contract that is unusually large (common causes: embedded fonts, revision history, or an oversized logo), try printing to PDF instead. Open the file, choose File, then Print, then select your system PDF printer. This rebuilds the file cleanly and strips most of the bloating metadata without rasterizing the text.

## How to compress a PDF for DocuSign, step by step

1. Open your PDF and look at a page. Does it look like typed text or a photograph? If it looks like a scan or photo, compression will help.
2. Go to the [Compress PDF tool](/compress-pdf).
3. Drop your file onto the tool.
4. Select **Medium** compression. If the resulting file is still over 5 MB, go back to your original and select **High**.
5. Download the compressed file and confirm the file size.
6. Upload to DocuSign as you normally would.

No account is needed. The file never leaves your browser as the compression runs locally on your device.

## Always compress before uploading, not after

Once all parties have signed, DocuSign writes a [digital certificate](https://pdfa.org/pdf-signature-validation/) into the PDF. It ties the document content to the signers' identities. Modifying the file after that, including compressing it, breaks that link. DocuSign and standards-compliant PDF readers will flag the document as tampered.

If you already have a signed PDF that is too large to forward or store, use DocuSign's provided download link to share it with recipients. If you need a smaller signed copy and everyone is willing to sign again, compress the original before sending a new envelope.

## What to do when compression is not enough

If compressing does not get the file small enough, or if your PDF is text-based and compression makes it worse, try one of these:

**Split the document.** Use our [Split PDF tool](/split-pdf) to divide a long file into sections. DocuSign allows multiple documents per envelope, so you can upload each section separately and all signers can work through them in one session.

**Check whether merging is the problem.** If you combined several files before uploading, merging itself adds almost no file size. In our testing, three files totaling 971.9 KB merged to 970.5 KB. If the combined file is too large, the issue is in the source documents, not the merge step.

**Re-export from the source.** If you created the PDF from a Word or Google Docs file, export it again with lower image quality settings, or remove any embedded high-resolution photos before exporting.
