## How to print specific pages from a PDF in any browser

Printing specific pages from a PDF is free and built into every major browser. You don't need Adobe Acrobat, and you don't need to install anything.

Open the PDF in your browser, Chrome, Edge, Firefox, or Safari, then press **Ctrl + P** on Windows or **Cmd + P** on Mac. In the print dialog, find the **Pages** field and change it from "All" to "Custom" (the wording varies a little by browser). Type your page range and click Print.

That's the whole thing. No accounts, no uploads, no software downloads.

## What to type in the Pages field

The page range syntax is consistent across Chrome, Edge, Firefox, and most print dialogs:

- **One page**: type `3` to print only page 3.
- **A range**: type `3-7` to print pages 3 through 7.
- **Non-consecutive pages**: type `2, 5, 11` to print three specific pages.
- **Combinations**: type `1, 3-5, 12` to print page 1, pages 3 to 5, and page 12.

This is the same syntax [Adobe Acrobat's print dialog](https://helpx.adobe.com/acrobat/kb/print-selected-pages-acrobat-reader.html) uses, so it works the same way whether you're in a browser or in Acrobat Reader.

## How to print specific pages in Chrome or Edge

Chrome and Edge are the two most common browsers for viewing PDFs, and both handle page ranges the same way.

1. Open the PDF in Chrome or Edge. Drag it onto a browser tab, or right-click the file and choose "Open with" then your browser.
2. Press **Ctrl + P** on Windows or **Cmd + P** on Mac.
3. In the print dialog, look for the **Pages** section.
4. Change the dropdown or toggle from "All" to **"Custom"**.
5. Type your page range in the input box. For example: `2, 4-6, 9`.
6. Click **Print**.

If you're saving to a PDF file rather than a physical printer, set the destination to **"Save as PDF"** and you'll get a new PDF containing only those pages.

## How to print specific pages on Mac with Preview

Mac includes a built-in PDF viewer called Preview that lets you select pages visually before printing, which is useful when you're not sure of the exact page numbers.

1. Open the PDF in Preview. It opens by default when you double-click a PDF file on macOS.
2. If the sidebar isn't visible, go to **View > Thumbnails**.
3. Click the first page you want to print.
4. Hold **Cmd** and click each additional page for non-consecutive selection. Hold **Shift** to select a contiguous range.
5. Go to **File > Print** or press **Cmd + P**.
6. In the print dialog, choose **"Selected pages in sidebar"** from the Pages menu.
7. Click **Print**.

You can see exactly what you're selecting before it goes to the printer, so this visual approach works well for longer documents.

## How to print selected pages on Windows without installing software

Windows doesn't have a dedicated PDF viewer as capable as macOS Preview, but every browser handles page-range printing without any setup.

If your PDF is saved on your computer, right-click it and choose **"Open with"**, then select Chrome, Edge, or Firefox. Press **Ctrl + P** and type your page range in the Pages field.

Edge is pre-installed on Windows 10 and 11, so you don't need to add anything. Its print dialog includes a clear "Custom pages" option. If your PDF opens automatically in Edge, press **Ctrl + P** and you're one step away.

## How to print only odd or even pages

Some printers let you print double-sided manually: print all odd-numbered pages on one side, then flip the stack and run even-numbered pages through. You can do this using a typed range.

- For odd pages in a 10-page document: `1, 3, 5, 7, 9`
- For even pages: `2, 4, 6, 8, 10`

Chrome's print dialog also includes **"Odd pages only"** and **"Even pages only"** options under "More settings", which is handy for longer documents where typing out each number by hand would take a while.

## What if you want to save specific pages, not just print them?

If you need to pull certain pages out as a separate PDF file, to email, share, or archive, the browser print dialog isn't the right tool. Printing to "Save as PDF" works but is clunky for anything more complex.

The [Extract Pages tool](/extract-pages) lets you pick specific pages from a PDF and download them as a new file. It runs entirely in your browser, nothing gets sent to a server, and there's no sign-up.

The [Split PDF tool](/split-pdf) is better when you want to divide a document into several files by page range, saving each section separately.

## When extracting pages makes more sense than the print dialog

The browser print dialog is fine when you're printing to paper or saving a quick copy for yourself. But two situations call for extraction instead.

First, when someone else needs only those pages. Sending a 3-page excerpt is cleaner than forwarding a 40-page report and asking a colleague to read only pages 18, 23, and 31. Extraction gives you a file sized around those pages, without the rest of the document.

Second, when privacy matters. Extracting the relevant pages before sharing means the recipient never sees the surrounding content. If you're pulling a summary from a confidential report, extraction is the better move.

For everyday printing, though, the browser dialog handles it in seconds.
