Flattening a PDF on Mac converts all form fields, annotations, and signatures into fixed page content so they can't be changed. You can do it for free using the [Flatten PDF tool](/flatten-pdf) in any browser, no install required, or with the Print to PDF option in Mac's built-in Preview app. Neither method needs Adobe Acrobat.

## What does flattening a PDF actually do?

A [PDF](https://en.wikipedia.org/wiki/PDF) stores two kinds of content side by side: the base page content (text, images, shapes) and an interactive layer on top. That interactive layer holds form fields, checkboxes, radio buttons, signatures, highlights, sticky notes, and drawn shapes. Both layers appear together when you open the file.

Flattening merges them into one static layer.

After flattening:

- Text you typed into a form field becomes regular text painted onto the page
- A signature becomes a graphic embedded in the page
- Highlights and sticky notes become part of the visual layer
- No field, annotation, or marking can be changed

Every PDF viewer on every device and operating system renders a flat PDF the same way, because there's no separate interactive layer for apps to interpret differently. That consistency is the point.

## Why would you flatten a PDF on Mac?

**Before sending a filled form.** PDF form fields can display differently depending on which app or browser opens the file. A recipient who opens your form in Chrome or Edge might see blank fields even though you filled them in. Flatten before sending and the values are locked into the page permanently.

**Before merging documents.** Merging a PDF that has form fields removes the form field structure from the output. Flatten the forms first so the filled content stays in the combined document. The [Merge PDF tool](/merge-pdf) combines files, but form field data doesn't carry through a merge, so flattening is the safe step to take beforehand.

**To lock annotations permanently.** Highlights, drawn shapes, and sticky notes added in Preview or any other app can be edited or deleted by whoever opens the file. Flattening bakes them into the page so they can't be touched.

**Before printing.** Some print drivers handle interactive PDF layers inconsistently. A flat PDF prints exactly as it looks on screen, with no surprises.

**For long-term storage.** Flattened PDFs are stable. There's no interactive layer that depends on a particular viewer to display correctly, which matters for documents kept for years.

## Method 1: Use the free Flatten PDF tool (no install, no account)

The [Flatten PDF tool](/flatten-pdf) is free and works in Safari, Chrome, Firefox, or any modern browser on Mac. You don't need to install anything or create an account.

1. Open the [Flatten PDF tool](/flatten-pdf).
2. Click to select your PDF, or drag the file onto the tool.
3. The tool processes the file and flattens all form fields and annotations.
4. Download the flattened PDF.

The result is a standard PDF where all the interactive elements have been merged into the page. Open it in any viewer and you'll see the same thing.

This method is the most reliable for PDFs with complex form fields, multiple annotation types, or Acrobat-created content, because it handles the PDF structure directly rather than re-rendering through a print driver.

## Method 2: Mac Preview's Print to PDF

[Preview](https://support.apple.com/guide/preview/welcome/mac) doesn't have a dedicated Flatten command, but printing to a new PDF gives a similar result for most files.

1. Open your PDF in Preview.
2. Press Command + P to open the Print dialog.
3. Click the PDF drop-down at the bottom left of the window.
4. Choose "Save as PDF."
5. Give the file a name and click Save.

The saved file won't contain interactive form fields. Preview re-renders the page through its print engine, and the output is a flat PDF in most cases.

The trade-off: Preview's rendering of some annotation types doesn't always match exactly what you see on screen, and some Acrobat-specific form fields or widget types may not come through correctly. Check the result before sending anything where accuracy matters. For straightforward forms, it works fine.

## Does flattening a PDF reduce the file size?

No. This is a common mix-up worth clearing up.

Flattening changes the *structure* of a PDF by removing the interactive layer and baking it into the page content. It doesn't compress images, strip embedded fonts, or remove metadata. File size after flattening is usually very close to the original.

To actually make a file smaller, use a separate compression tool. The [Compress PDF tool](/compress-pdf) works well for PDFs that contain scanned pages or images. One thing to know: it rasterizes every page to JPEG, which makes text-only PDFs noticeably larger. Use compression on image-heavy files, not on contracts, invoices, or text reports.

## Flattening vs. password protection

They solve different problems and are easy to confuse.

Flattening removes interactivity so nobody can edit form fields or annotations. The file is still readable by anyone.

Password protection (the [Protect PDF](/protect-pdf) tool) encrypts the file so it requires a password to open or edit. It doesn't affect whether form fields are editable by someone who does have the password.

You can do both. Flatten first to lock the form data, then protect to control who can open the file. But they're independent steps.

## When you should not flatten

Flatten only when you're done with the form. Once you flatten, the form fields are gone. You can't tab through them, change values, or use the file as a fillable form again.

Keep an unflattened copy of any form you might need to update or reuse. Flatten only the version you're sending, printing, or archiving. If you flatten the only copy you have, getting the data back means retyping everything.

This also applies to annotations: once you flatten, comments and sticky notes are no longer separate objects you can select or delete. They're part of the page. Keep the original if there's any chance you'll want to revise the markups.
