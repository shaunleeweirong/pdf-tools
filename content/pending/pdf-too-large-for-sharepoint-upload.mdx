Your PDF is too large to upload to SharePoint, and you need it there now. In most cases you can fix this in a couple of minutes. The right approach depends on what's inside the file, so read the section below that matches your situation before you start.

## Why SharePoint Is Blocking Your PDF

SharePoint doesn't use a single universal file size limit. The threshold that's stopping you depends on which version of SharePoint you're using and how your IT team has configured it.

**SharePoint Online (Microsoft 365 cloud)** allows individual files [up to 250 GB](https://learn.microsoft.com/en-us/office365/servicedescriptions/sharepoint-online-service-description/sharepoint-online-limits). A PDF almost never hits that ceiling. If you're blocked on the cloud version, your organization has almost certainly set a lower cap, or you're running into a different restriction listed below.

**SharePoint Server (on-premises)** is different. Its default maximum upload size is 50 MB. Many IT teams leave that default in place for years, so if your company runs its own SharePoint installation, a 60 MB PDF will fail every time until an admin raises the limit in Central Administration.

**The WebClient service on Windows.** When you access SharePoint through File Explorer via a mapped drive, Windows applies its own limit through the WebClient service. The default is 50 MB. This is a client-side restriction that has nothing to do with what SharePoint itself allows, and it trips people up constantly because the error message doesn't make it obvious where the limit is coming from.

**Organization-set policies.** IT administrators can restrict upload sizes for specific libraries, sites, or the entire tenant. Some departments cap uploads at 25 MB or 100 MB. If your colleagues can't upload large files either, this is likely the cause. You'll need to ask your admin to raise the limit, or reduce the file yourself.

**List attachments vs. document libraries.** Files attached to SharePoint list items have tighter limits than files in document libraries. If you're adding a PDF as an attachment to a list item, check whether the same file uploads fine to a document library instead.

## The Most Important Question Before You Do Anything

Open the PDF and think about what's inside. This determines which fix will work.

**Image-heavy PDF?** Scanned documents, photo portfolios, exported presentations, and anything that started as images will respond well to compression. The tool re-encodes the images at a smaller size.

**Text-heavy PDF?** Contracts, reports, invoices, and typed documents will get bigger if you try to compress them. Our [Compress PDF](/compress-pdf) tool works by rasterizing each page to a JPEG image. For an image that's already a photograph, that's an efficient encoding. For text stored as vector glyphs, converting to a JPEG photograph is far less efficient. A 20-page text report that started at 23.5 KB grew to 1.4 MB after compression. Don't compress a text-heavy PDF expecting it to shrink.

If you're unsure, look at the file size versus the page count. A 10-page PDF that's 30 MB almost certainly contains scanned images. A 10-page PDF that's 500 KB is probably text-based.

## How to Compress an Image-Heavy PDF for SharePoint

1. Go to the [Compress PDF](/compress-pdf) tool.
2. Upload your PDF. The file is processed in your browser and doesn't get sent to a server.
3. Choose a compression level:
   - **Medium** is a good starting point. On a 913 KB image-heavy document, medium compression brings it down to about 315 KB, a 65% reduction.
   - **High (smallest size)** reduces the same document to around 175 KB, an 80% reduction. Text will be slightly softer, which is usually acceptable for documents you're reading on screen rather than printing.
   - **Low (best quality)** reduces the file by around 23%. Use this when image clarity matters and size is less of a concern.
4. Download the result and try the SharePoint upload again.

One thing to avoid: don't run the compression twice if the first result is still too large. A second pass at the same level makes the output about 90% bigger, because the tool re-rasterizes an already-rasterized file. Go back to the original and pick High instead.

## Fixing a Text-Heavy PDF That's Over the Limit

If your document is mostly text, compression is the wrong tool. Your options are:

**Split the PDF.** Use the [Split PDF](/split-pdf) tool to break the document into smaller files by page range. A 100-page report split into two 50-page sections uploads cleanly, and you can store both files in the same SharePoint folder with clear naming. This approach preserves the exact original quality because no re-encoding happens.

**Zip the file.** Zip compression is much better at shrinking text data than image-based PDF compression. Right-click the file on Windows or macOS and compress it to a .zip. A text-heavy PDF often drops 20 to 40% in a zip archive. The recipient downloads and extracts it, which takes one extra step but preserves everything perfectly.

**Remove what you don't need.** If the PDF has appendices, blank pages, or large image inserts that aren't essential for this upload, removing those pages first is faster than compressing the whole document.

## Getting Your IT Admin Involved

If you've compressed or split the file and still can't get under your organization's threshold, the fix has to come from the admin side. What they can do:

- Raise the maximum upload size for a SharePoint Server web application via Central Administration.
- Adjust the WebClient file size registry value on Windows clients, or push a Group Policy update.
- Create a document library with a higher limit for specific use cases.
- Grant a temporary exception for oversized uploads.

Before going that route, try uploading through the OneDrive desktop sync app rather than the browser. The sync client bypasses the WebClient limit entirely and connects directly to SharePoint, so if the WebClient service is your specific blocker, the app solves it without any IT involvement.

## Quick Reference

| What's in the PDF | Best fix |
|---|---|
| Scanned pages, photographs | Compress at Medium or High |
| Mixed content (text plus images) | Compress; if still large, split |
| Text-only (contracts, reports) | Split or zip |
| Size still over org limit after compressing | Contact IT admin, or try OneDrive app |

The common mistake is applying compression to everything and wondering why a text document got larger. Match the tool to the content type and you'll save the time of a failed attempt.
