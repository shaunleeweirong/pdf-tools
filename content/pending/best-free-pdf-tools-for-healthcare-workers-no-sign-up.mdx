The best free PDF tools for healthcare workers run entirely in your browser, requiring no account and no server upload. You can merge patient records, compress scanned documents, sign consent forms, fill out intake forms, and password-protect sensitive files without handing any data to a third party.

That privacy property matters more in healthcare than in most other fields. When you drop a file into a cloud service, you're relying on that service's retention and access policies. With browser-based tools, your file loads into memory in your browser tab, gets processed by JavaScript running on your own machine, and comes back as a download. Nothing travels to a server.

## Combining Multiple Documents

A lot of healthcare paperwork arrives as separate files: a referral letter here, a lab result there, a consent form from a different system. The [Merge PDF](/merge-pdf) tool lets you combine them into one document in any order you choose.

Merging does not inflate file size. When you combine files, the output comes in at roughly the same total as the individual parts added together, so you won't push a combined record over an email attachment limit just by merging it.

One thing to know before you merge: if any of your source files contain interactive form fields, those fields do not carry over. The page content stays, but the fields are lost. If you have a filled patient intake form and need to merge it with other documents, run it through [Flatten PDF](/flatten-pdf) first. Flattening converts the typed values into static page graphics, so they survive the merge.

## Compressing Scanned Records

Scanned clinical documents can run large, especially multi-page files with color pages or images from diagnostic equipment. The [Compress PDF](/compress-pdf) tool reduces file size by rasterizing each page to JPEG, which works well for scans and image-heavy files.

One important caveat specific to medical documents: do not use the compressor on text-based PDFs such as typed lab reports, discharge summaries, or typed correspondence. Because the tool converts every page to an image, a document consisting of text will come out dramatically larger than it went in. A 20-page text report measured at 23.5 KB grew to 1.4 MB after compression. For those files, splitting off unnecessary pages or zipping before email attachment is the right approach.

If you compress a scanned record and the result is still too large, go back to the original and try the High (smallest) setting. Running a second compression pass on an already-compressed file makes things worse: the file gets larger, not smaller, because re-encoding an already-compressed JPEG adds data.

## Signing Consent Forms and Authorizations

Consent forms, records release authorizations, and treatment agreements all need signatures. The [Sign PDF](/sign-pdf) tool lets you draw a signature directly on screen and place it anywhere on the document, then download the signed file. No upload, no storage.

For forms with typed fields, the [Fill PDF Form](/fill-form) tool detects interactive fields and lets you type into them. Once you've completed the form, download it. If you're sending the filled form to someone else or attaching it to a merged record, flatten it first so the field values are baked into the page.

## Password-Protecting Sensitive Files

If you need to send a patient document by email and want it encrypted, the [Protect PDF](/protect-pdf) tool encrypts the file with [AES-256](https://en.wikipedia.org/wiki/Advanced_Encryption_Standard) directly in your browser. The process runs locally, so the file is never uploaded. Encryption adds roughly 1 KB of overhead regardless of file size, so there's no meaningful effect on whether the file fits an attachment limit.

Send the password through a separate channel from the file itself. A password-protected PDF sent in the same email as the password offers limited protection.

To open a file someone sent you with a password you know, the [Unlock PDF](/unlock-pdf) tool removes the password so you can work with the file normally.

## Splitting and Extracting Pages

Large patient files sometimes need to be broken apart. A referral might need only the most recent three pages from a longer record, or you might need to separate a combined file into individual documents for different recipients.

The [Split PDF](/split-pdf) tool extracts page ranges into separate files. The [Extract Pages](/extract-pages) tool lets you pick exactly which pages you want and saves them as a new PDF. Both run in the browser with no account required.

## Why No Account Matters in Healthcare

Most online PDF services require you to create an account before doing anything useful. That means accepting terms of service, handing over an email address, and trusting that service's security practices with whatever files you process.

For general documents, that's a reasonable trade-off. For patient files, it raises questions: Where does the file go when you upload it? How long is it retained? Who has access? These are not hypothetical concerns. The [HIPAA Privacy Rule](https://www.hhs.gov/hipaa/for-professionals/privacy/index.html) from the U.S. Department of Health and Human Services requires covered entities and their business associates to protect individually identifiable health information. When a file never leaves your device, those questions don't apply.

Browser-based tools aren't HIPAA business associates in the legal sense, and they can't substitute for your organization's formal compliance program. But "the file never left my machine" is a defensible position in a way that "I uploaded it to a third-party service" is not. Talk to your organization's privacy officer about which tools are approved for clinical use.
