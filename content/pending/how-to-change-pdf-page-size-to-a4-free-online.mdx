You can change a PDF's page size to A4 for free in any browser, with no software to install. The three most reliable methods are printing to PDF from the browser, opening the file in Google Docs, or using a free online resize tool. Pick whichever matches your situation.

## Why Your PDF Might Not Be A4

[A4 is the paper size defined by ISO 216](https://www.adobe.com/uk/creativecloud/design/discover/a4-format.html), the international standard used across Europe, Australia, and most of Asia. Its dimensions are 210 x 297 mm (8.27 x 11.69 inches). US Letter, the default in North America, is 216 x 279 mm, which is slightly wider and noticeably shorter.

A PDF picks up the page size from whatever tool created it. A spreadsheet exported from Excel on a US machine will probably be Letter. A scan from a consumer flatbed scanner often uses whatever default the app chose. A file received from another country might be A4 already. You can usually check the page size in your PDF reader under Document Properties.

The mismatch matters most when printing or uploading to a portal. If your printer tray holds A4 paper and the PDF is Letter, you get a band of white space at the bottom of each printed page, or the printer scales the content down. Some academic portals and government filing systems reject uploads that do not match a specific page size.

## Method 1: Print to PDF in Your Browser (Quickest)

Chrome, Firefox, and Edge all let you "print" a PDF to a new PDF file with a different page size. Nothing is uploaded anywhere.

1. Open the PDF in your browser. In Chrome or Edge, drag the file into a new tab.
2. Press `Ctrl+P` on Windows or Linux, or `Cmd+P` on Mac, to open the print dialog.
3. Set the **Destination** to **Save as PDF** (Chrome/Edge) or **Microsoft Print to PDF** (Windows).
4. Look for **More settings** or **Paper size** and select **A4**.
5. Click **Save** and pick a location on your computer.

The browser renders each page at A4 dimensions and scales the content to fit. Because A4 and Letter have different aspect ratios, the scaling is not perfectly uniform on all sides, but for most documents the result looks fine. Check a few pages before submitting anything formal.

**Best for**: a single Letter document that you need to submit to a European or international recipient.

## Method 2: Google Docs (Good for Text-Heavy Files)

Google Docs can open a PDF, convert it to an editable document, let you switch the page size, then export back to PDF. The conversion re-flows text, so this works best for documents that are mostly text and simple tables.

1. Go to [Google Drive](https://drive.google.com) and upload the PDF.
2. Right-click the uploaded file and choose **Open with Google Docs**. Wait for the conversion to finish.
3. In the Docs menu bar, go to **File > Page setup**.
4. Change **Paper size** to **A4** and click **OK**.
5. Go to **File > Download > PDF Document (.pdf)**.

Complex layouts with multiple columns, embedded charts, or precise spacing will shift during the PDF-to-Docs conversion step. For those files, Method 1 or Method 3 will give a cleaner result.

**Best for**: text-heavy documents where you also want to edit the content before saving as A4.

## Method 3: A Free Online Resize Tool (Most Predictable)

If you need to preserve the original layout precisely and print-to-PDF gives you an awkward result, a dedicated resize tool is more reliable. These tools change the page dimension metadata and scale content proportionally, without re-flowing text.

Look for one that:
- Offers A4 as a preset so you do not have to type raw millimetre values.
- Has a "scale content to fit" option so nothing gets cropped.
- Runs in the browser (check the description or privacy policy if your file is sensitive).

The steps are similar across most tools:

1. Upload your PDF.
2. Choose **A4** from the page size list.
3. Select whether to scale content to fit the new size.
4. Click resize and download the result.

Some tools process files server-side and delete them after a set time. If the PDF contains sensitive information, check the tool's privacy policy before uploading, or use the print-to-PDF method, which keeps everything on your device.

## How to Make All Pages the Same Size

A common problem with multi-page PDFs is mixed page sizes: a scanned cover page at A4, a body section exported from PowerPoint at 16:9 widescreen, and an appendix saved from a US Letter template. These print unevenly and look inconsistent when viewed on screen.

Running the whole file through a resize tool with "apply to all pages" selected is the cleanest fix. Each page gets scaled to A4 individually from its own original dimensions, so a wide-format page and a portrait-format page will both become A4 but may still look proportionally different from each other.

If the real problem is just oversized margins rather than a different declared page size, the [Crop PDF tool](/crop-pdf) can trim white space from all pages at once. This changes the visible page area but does not change the declared dimensions to 210 x 297 mm. Use the resize route if the declared dimensions need to match A4 exactly.

## Combining A4 Pages from Multiple Documents

Once your pages are all A4, you might need to combine them into a single file. The [Merge PDF tool](/merge-pdf) joins multiple PDFs without altering their page dimensions. If every input file is A4, the merged output will be uniformly A4 throughout.

Merging adds almost no overhead to the final file size. Three A4 PDFs adding up to 970 KB in produce a merged file of around 970 KB out. Nothing is re-rendered, so no quality is lost.

One thing to be aware of: if any of your source PDFs contain fillable form fields, merging will strip those fields. Fill out and flatten any interactive forms before merging. The [Flatten PDF tool](/flatten-pdf) handles this step.

## Does Changing Page Size Distort the Content?

It depends on which method you use and how different the two sizes are.

**Print to PDF and online resize with scaling**: content is scaled to fit the new dimensions. A4 and Letter differ by about 6 mm in width and 18 mm in height, so the scaling factor is small. For text documents, the result is indistinguishable from the original at normal reading sizes. For raster images embedded at exactly screen resolution, there may be very slight softening.

**Resize without scaling**: the page becomes A4 but content stays at its original position. This usually just changes where the margins fall. If the original content extended close to the edge of a Letter page, resizing to the narrower A4 without scaling can clip the right margin.

For most office documents and academic submissions, print-to-PDF with A4 selected is all you need. Spend two minutes checking the output before submitting, and you will catch any edge cases before they become a problem.
