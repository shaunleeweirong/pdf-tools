The best free Chrome extensions for PDF work are ones that don't push you toward a sign-up wall every time you need to save a file. This guide covers which extensions are genuinely worth installing, which ones keep your files on your device, and when a browser-based tool beats any extension.

## Does Chrome already handle PDFs built-in?

Before you install anything, try opening a PDF in Chrome's built-in viewer. [Since Chrome 126](https://support.google.com/chrome/answer/14920024), the browser includes basic PDF annotation tools with no extension required: you can highlight text, add sticky notes and text boxes, draw with an ink pen, rotate pages, and fill in simple form fields.

If all you need is to annotate a PDF while reading it in a browser tab, you might not need an extension at all. What the built-in viewer cannot do: compress, merge, split, convert images to PDF, or sign a document with a drawn signature. For those jobs, you need an extension or a dedicated tool.

## The free Chrome PDF extensions worth installing

### PDF & Web Highlighter

This extension works on both PDFs loaded from the web and local files you open from your desktop. No account is needed to start using it. It has over 200,000 downloads on the [Chrome Web Store](https://chromewebstore.google.com/) and a 4.83 out of 5 rating from nearly 5,000 reviews. Highlights and notes are stored inside the extension rather than written back into the PDF file, so you don't produce a modified document just by annotating.

Good for: marking up research papers, articles, or reports while reading without touching the original file.

Not for: producing an annotated copy to send to someone else, since the annotations don't travel with the file.

### Enhanced PDF Viewer

Built on [Mozilla's open-source PDF.js engine](https://mozilla.github.io/pdf.js/), the same renderer Firefox uses, this extension replaces Chrome's default viewer with one that adds dark mode, text-to-speech, a presentation mode, and additional annotation options. All rendering happens locally, so files stay on your device. There is no account requirement and no daily processing limit.

Good for: people who read a lot of PDFs and want dark mode or screen-reader-friendly features baked into the viewer itself.

### Convert: Web to PDF

For saving articles, invoices, receipts, or web pages as PDFs, this extension produces the file locally from the current browser tab. There are no watermarks, no daily conversion limits, and no sign-up. You can control margins, page orientation, and whether to include background colors and images.

Good for: saving web content as a clean, offline-readable PDF.

### SafetyPDF

SafetyPDF is a local PDF compressor. It runs entirely within your browser, so the document never leaves your device. For image-heavy PDFs such as scanned pages or photo decks, local compression can bring the file size down enough to email or upload. That said, PDF compression works by rasterizing page content to JPEG. For pages that are mostly photos or scanned images, that helps. For pages that are mostly text, it makes things worse, because vector text is tiny and a JPEG photograph of the same text is much larger.

Good for: compressing scanned documents or image-heavy slides before attaching them to an email.

Not for: text-only PDFs such as reports, contracts, or invoices.

## Which extensions actually keep files on your device?

Many review posts skip this. "Free" does not mean "local." A number of popular PDF extensions upload your document to a remote server to process it, and data retention policies vary. Before installing anything, open the extension's listing on the Chrome Web Store, scroll to the Privacy section, and look for explicit language about whether files are uploaded or stored.

Extensions that process files locally (no server upload):
- Chrome's built-in viewer and annotation tools
- Enhanced PDF Viewer (PDF.js)
- SafetyPDF
- Offline PDF Merger and Compressor

Extensions that route files through remote servers (check each product's data policy):
- iLovePDF Chrome extension
- SmallPDF Chrome extension (free tier limited to 2 documents per day; requires sign-in for more)
- Most all-in-one editors with a broad feature set

## When a browser-based tool is faster than any extension

Extensions are convenient, but most Chrome PDF extensions handle a narrow set of tasks. Merging many files at once, splitting a PDF by a specific page range, converting a batch of images into a single PDF, or signing a document with a drawn signature often pushes extensions to their limit. For those jobs, a dedicated browser-based tool is usually quicker to use and more reliable.

Browser-based tools also have one structural advantage over extensions: they work in any browser, not just Chrome. You don't have to install anything.

Here is where our tools at this site fit in:

**Merging PDF files.** The [Merge PDF tool](/merge-pdf) combines multiple files without inflating the output size. In testing, three files totaling 971.9 KB merged into an output of 970.5 KB. One thing worth knowing: merging strips interactive form fields, so if you're combining a filled form with a cover letter or other documents, run the [Flatten PDF tool](/flatten-pdf) on the form first to bake the values into the page permanently.

**Compressing image-heavy PDFs.** The [Compress PDF tool](/compress-pdf) works best on scanned documents and image-heavy files. A 6-page image deck dropped from 913.4 KB to 315.3 KB at Medium quality. Don't use it on text-only documents; rasterizing vector text to JPEG makes those files much larger, not smaller.

**Converting images to a PDF.** The [JPG to PDF tool](/jpg-to-pdf) takes JPEGs and PNGs and assembles them into a single PDF, one image per page. Useful for phone photos, scanned pages, or screenshots you want to combine.

**Signing a document.** The [Sign PDF tool](/sign-pdf) lets you draw a signature and place it on any page, with no printing or scanning involved.

**Exporting PDF pages as images.** The [PDF to JPG tool](/pdf-to-jpg) exports each page of a PDF as a separate image file, which is useful when you need a single page as a graphic.
