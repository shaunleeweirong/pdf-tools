You can compress a PDF to 500KB for free using the [Compress PDF tool](/compress-pdf). It runs entirely in your browser, nothing is uploaded, and no account is required. Most image-heavy files finish in under a minute.

That said, not every PDF type responds the same way to compression. Read the section below on which PDFs will actually shrink before you start. Running the wrong type through the compressor can make it much larger.

## Step-by-step: compress a PDF to 500KB

1. Open the [Compress PDF tool](/compress-pdf).
2. Click **Select PDF** or drag your file into the drop zone.
3. Choose **Medium** compression.
4. Click **Compress** and wait a few seconds.
5. Check the output file size shown in the download prompt.
6. If the result is still over 500KB, save your original file and repeat from step 1 using **High** compression.
7. Download and submit your compressed file.

Medium is a reasonable starting point. In testing with an image-heavy PDF (913.4 KB), Medium brought the file down to 315.3 KB. High compression on the same file produced 175.6 KB. Real results depend on what's inside your PDF, but image-heavy documents typically compress well.

## Why forms set a 500KB upload limit

Government portals, exam boards, and HR systems set strict file size caps for practical reasons. A platform processing millions of applications simultaneously needs predictable infrastructure constraints. The 500KB limit is common on Indian competitive exam portals (UPSC, SSC, NTA), visa and immigration applications, university admissions platforms, and many corporate job boards.

The limit isn't a reflection of how much information your document contains. It's an infrastructure policy. Your document doesn't need to be small by default; you just need to meet the requirement before you upload.

## Which PDFs compress below 500KB, and which don't

This is the most important thing to understand before you start. The compressor works by converting every page to a [JPEG](https://en.wikipedia.org/wiki/JPEG) image at a lower quality setting. That process helps some PDFs significantly and makes others much larger.

**Scanned documents and image-heavy PDFs compress well.** If your PDF was created by scanning paper, or if the pages contain photographs or high-resolution graphics, most of the file weight lives in those image streams. Compressing them produces real size reductions. In our tests, an image-heavy PDF at 913.4 KB dropped to 315.3 KB at Medium and 175.6 KB at High.

**Text-only PDFs behave the opposite.** A PDF built from a word processor or design app stores text as compact vector instructions. Rasterizing those pages into JPEG images turns efficient vectors into large raster data. A 20-page text report that was 23.5 KB grew to 1.4 MB after Medium compression, roughly 60 times larger. This isn't a bug; it's how rasterization works. The tool even notes on the compress page that it rasterizes pages.

**How to tell which type you have.** Open the file and zoom in to about 200 to 300 percent. If text stays sharp and crisp, it's stored as vectors and compression will hurt it. If the pages look like photographs, or if the text is slightly fuzzy even at 100 percent zoom, the file is image-based and will compress well.

If your PDF is a typed contract, a spreadsheet export, a digital invoice, or any document created entirely in software without scanning, this compressor won't get it under 500KB. You'll need a different approach.

## What to do if the file is still over 500KB

**Use High compression from the original.** If Medium didn't reach your target, don't compress the Medium output again. Go back to your original file and run it at High. For our test file, High produced 175.6 KB versus 315.3 KB at Medium. The quality is lower, but for typical form submissions the content remains readable.

**Split the document.** The [Split PDF tool](/split-pdf) lets you divide the file into sections. If the portal accepts multiple uploads, a 20-page document can become two 10-page files, each well under the limit.

**Remove pages you don't need.** If the document has blank pages, appendices, or sections the form doesn't ask for, removing them before compressing reduces your starting size. You can do this with the Delete Pages tool, which doesn't affect quality.

**Consider the file type.** Some portals accept images alongside PDFs. If you're submitting a single-page scan, saving it as a JPEG directly can sometimes reach a smaller file size than a compressed PDF wrapper around the same image. Check the portal requirements first, since many specify PDF only.

## Why you shouldn't compress a PDF twice

A common piece of advice is to run a second compression pass to squeeze the file down further. It doesn't work.

Once a page has been rasterized into a JPEG and embedded into a PDF, the compressor scales the page slightly and re-encodes an already-compressed image. The result is a larger file, not a smaller one. We tested this: running an already-compressed 315.3 KB file through Medium compression a second time produced a 598.9 KB output. Almost double the size.

Running a second pass at High instead of Medium clawed back a minor 5.6%, bringing the file from 315.3 KB to 297.8 KB. That's a small improvement with a noticeable quality hit. It's not worth it.

The right approach is to compress once from the original at the level you need. If Medium isn't enough, restart from the original at High.

## Your file stays on your device

A common concern with online tools is what happens to your document. The [PDF format](https://en.wikipedia.org/wiki/PDF) describes how pages, text, and images are stored in a file. The Compress PDF tool reads and rewrites that structure using code that runs locally in your browser. Your file never leaves your device.

This matters for sensitive documents. Scanned ID cards, tax forms, medical records, and personal certificates all stay on your machine throughout the process. Nothing is sent to a server, and there's nothing to delete after the fact because nothing was stored remotely in the first place.
