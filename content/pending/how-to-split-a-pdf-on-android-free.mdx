You can split a PDF on Android for free without installing a single app. Open Chrome (or any modern mobile browser), use a browser-based split tool, pick your pages, and download the result. No account, no waiting room, no app store.

## Do you actually need an app to split a PDF on Android?

No. The idea that you need a dedicated app is outdated. Android's [Chrome browser](https://play.google.com/store/apps/details?id=com.android.chrome) is capable enough to run web tools that split PDFs entirely in the browser, using the same JavaScript engine that powers desktop-class apps. The file stays on your device the whole time.

The two main approaches are:

1. **A browser-based split tool** (recommended for most people)
2. **Chrome's built-in print trick** (works for simple splits, no extra site needed)

Both are free. Which one to use depends on what you're trying to do.

## Method 1: Use a browser-based split tool (no app needed)

This is the most flexible option. It lets you pick specific page ranges, extract individual pages, or break a document at any point you choose.

**Steps:**

1. Open Chrome (or Firefox, Samsung Internet, or another modern browser) on your Android.
2. Go to the [Split PDF tool](/split-pdf).
3. Tap **Select file** and pick the PDF from your storage (or Downloads folder).
4. Choose how to split: by page range, extract specific pages, or split every page into its own file.
5. Tap the split button and wait for it to finish.
6. Tap **Download** to save the result to your phone.

The tool runs in your browser. Your file is processed locally and is not sent to a remote server. Once you download the output, you can close the tab.

## Method 2: Chrome's built-in print trick

Chrome for Android has a "Save as PDF" option in its print dialog. You can use it to save only the pages you want from any PDF, without any third-party tool at all.

**Steps:**

1. Open the PDF in Chrome (tap the file or open it from Google Drive, Gmail, or your file manager).
2. Tap the three-dot menu (top right), then tap **Print**.
3. Tap the **Destination** dropdown and choose **Save as PDF**.
4. In the **Pages** field, type the range you want: for example, `1-5` for pages one through five, or `2,4,7` for specific individual pages.
5. Tap the PDF icon (save button) and save the file.

This produces a new PDF containing only the pages you specified. It's the simplest option if you just want to cut a file in two or save one chapter from a long document.

**Limitation:** Chrome's print trick does not always preserve the full visual fidelity of every PDF. For most documents it works fine, but if you notice the text looking slightly different or fonts changing, use a proper split tool instead.

## When to use each method

| Situation | Best method |
|---|---|
| Extract a specific chapter or page range | Either method works |
| Split into many parts at once | Browser tool |
| No internet connection available | Chrome print trick (works offline once the PDF is open) |
| File has complex formatting or embedded fonts | Browser tool |
| Quick one-off split, no account wanted | Either |

## How to find the PDF you want to split

On Android, PDFs often end up in different places depending on how you received them.

- **Email attachment:** Open the email in Gmail, tap the attachment thumbnail, then tap the share icon to open it in Chrome or your file manager.
- **WhatsApp or other messaging app:** Long-press the file, tap Share or Save to Downloads, then locate it in your Downloads folder.
- **Google Drive:** Open the Drive app, find the file, tap the three-dot menu next to it, and choose Open with, then pick Chrome or the split tool's upload button.

Once you know where the file is, the split itself takes under a minute.

## What "splitting" actually does to a PDF

A PDF is a container format defined by [ISO 32000](https://en.wikipedia.org/wiki/PDF), the standard that governs how pages, fonts, images, and interactive elements are stored. When you split a PDF, you're not changing the content on any page. You're creating a new file that references only some of those pages. Fonts and images embedded in the file stay intact within the relevant pages.

One thing to know: if your PDF has fillable form fields and you've filled them in, check that the fields survive the split before discarding the original. Some split tools handle interactive elements differently. If you filled a form and need to preserve it exactly, flatten it first with a [flatten tool](/organize-pdf) before splitting, so the values are painted into the page permanently.

## Other things people ask about splitting PDFs on Android

**Can I split a password-protected PDF on Android?**
You'll need to remove the password first. The PDF format requires the password to access the content before any tool can read the pages. Use a PDF password-removal tool to strip the password, then split the file normally.

**Will splitting a PDF reduce its file size?**
Yes, in proportion to the pages removed. If you have a 10-page document that's 10 MB and you extract 3 pages, the result will be roughly 3 MB. The exact ratio varies by how much content is on each page and how many shared resources (like embedded fonts) the remaining pages use.

**Can I split a PDF in Google Drive on Android?**
Google Drive lets you view PDFs but does not have a built-in split feature. You'd need to open the file in a browser-based tool or use the Chrome print trick described above.
