Cropping PDF pages on Windows is free and takes under a minute once you know which tool to use. The [Crop PDF tool](/crop-pdf) runs in your browser on Windows 10 and Windows 11, so there's nothing to install and no account to create.

## What does cropping a PDF actually mean?

When you crop a PDF, you're adjusting the visible area of each page. Picture a photo mat frame: the underlying photograph is still the same size, but the mat covers the edges. Cropping a PDF works the same way. It sets a new boundary for what's shown on screen and in print, but the content outside that boundary usually remains inside the file.

This distinction matters for two reasons.

First, cropping is not the same as [redacting](https://en.wikipedia.org/wiki/Redaction). If you crop out a name, a signature, or a phone number, that content is often still present in the PDF data and can be recovered. For genuinely removing sensitive information, use a dedicated redaction tool that permanently deletes the content rather than just hiding it.

Second, cropping rarely makes a PDF file noticeably smaller. Because the hidden content stays in the file, the byte count barely changes. If you need to bring a file under an email or upload limit, [Compress PDF](/compress-pdf) is the right tool, though only if the document contains images rather than plain text.

That said, cropping has real and useful jobs: cleaning up scanned pages with oversized white borders, tidying margins before printing, or making mixed-size pages look consistent when you combine PDFs.

## Does Windows 10 or 11 have a built-in PDF crop tool?

No. Windows can open [PDF files](https://en.wikipedia.org/wiki/PDF) in Microsoft Edge and most browsers, but none of them include a crop feature. Edge lets you annotate and print, but adjusting page boundaries is not on the menu.

Some people work around this with the Windows Snipping Tool (Windows + Shift + S): take a screenshot of the page area you want to keep, paste it into Paint, then print to PDF. That technically crops the image, but it converts the entire page to a flat picture in the process. Text becomes unselectable, search stops working inside the file, and zoom quality drops. It's a last resort, not a clean solution.

A browser-based crop tool is faster and produces a proper PDF output rather than an image.

## How to crop PDF pages on Windows for free

The [Crop PDF tool](/crop-pdf) works in any browser on Windows 10 or 11. Here's how to use it:

1. Open Chrome, Edge, Firefox, or any other browser.
2. Go to [Crop PDF](/crop-pdf).
3. Click the upload area or drag your PDF file onto the page.
4. Use the margin controls to set how much to trim from each side: top, bottom, left, and right.
5. Check the page thumbnail to see exactly what will be cut before you commit.
6. Click the download button. The cropped PDF saves to your computer.

Your file is processed entirely in the browser. It never gets sent to a server, which matters when you're working with contracts, medical records, tax forms, or anything you'd rather keep private.

## Trimming all margins vs. trimming one side

Most cropping tasks fit one of two patterns.

**Trimming all margins evenly**: Useful for scanned documents where the scanner added a thick white border around each page. Set the same value on all four sides and the page content takes up more of the space without moving.

**Trimming one side only**: Useful when a header or timestamp is printed close to one edge and you want to remove it from view. Set the other three sides to zero and only cut the edge you need.

If you need different crops on different pages, the cleanest workflow is: split the PDF into sections using the [Split PDF tool](/split-pdf), crop each section separately with [Crop PDF](/crop-pdf), then rejoin the sections with [Merge PDF](/merge-pdf).

## When you should not crop a PDF

Cropping is not the right tool for every job. Three situations where it will not give you what you want:

**You want to reduce the file size.** Cropping hides content but does not remove it, so the file stays about the same size. Use [Compress PDF](/compress-pdf) on image-heavy PDFs to actually reduce bytes. Avoid running the compressor on text-only documents, because it rasterizes every page and makes text PDFs significantly larger.

**You want to remove sensitive content permanently.** Cropped content is hidden, not gone. Anyone who opens the PDF in a tool that ignores the crop boundary can still see what you trimmed. Use a redaction tool for anything that genuinely needs to be deleted from the file.

**You want text to reflow into a new layout.** Cropping moves the page boundary; it does not reflow paragraphs or change how text sits on the page. If you want text to fill a smaller area, you need to edit the document in its original format before converting to PDF.

## Does cropping reduce PDF file size?

Usually only by a tiny amount, if at all. PDF crop operations typically work by updating the CropBox entry in each page's metadata, a change that adds or removes just a handful of bytes. The image and text data for the trimmed area usually stays in the file untouched.

If a small size reduction does occur, it is because the tool is writing a new, slightly optimized PDF rather than because trimming removed significant data.

For meaningful file size reduction before emailing or uploading, [Compress PDF](/compress-pdf) is the right step, as long as the document is image-heavy. Text documents are the exception: the compressor converts pages to JPEG images, which makes a short text report dramatically larger, not smaller.

## Alternatives to the browser-based approach

If you prefer a desktop application, free Windows options include PDF24, PDF Shaper Free, and Sejda Desktop. All of them install locally and include crop features. The trade-off is that you need to download and maintain the software, and the files do touch the application's code even if they stay on your machine.

For most people doing occasional cropping on Windows, a browser-based tool is simpler. No install, no update prompts, and you can use it on any Windows computer without carrying software around.
