A corrupted PDF won't open, or opens to blank pages and scrambled text. The good news is that you can often fix or recover it for free, and you don't need Acrobat to do it.

Before reaching for a repair tool, it helps to figure out what kind of damage you're dealing with. That tells you which method to try first.

## Why PDFs get corrupted

A PDF is a structured file. It has a header, a body, a cross-reference table (which maps where each object sits in the file), and a trailer. If any of those pieces are missing or broken, a reader can't parse the file and will report that it's damaged.

The most common reasons this happens:

**Incomplete download.** The file transfer stopped before the file finished writing. The result looks like a PDF but is missing its tail, and no reader can open a file with no trailer.

**Bad file transfer.** Moving files across USB sticks, old external drives, or unreliable cloud storage can flip bits if the hardware has an error or the connection dropped mid-copy.

**System crash.** If the app that saved the PDF shut down mid-write, because of a power cut or a force-quit, the file ends abruptly. What's on disk is whatever was written before the crash.

**Storage failure.** A failing drive or a nearly-full disk can corrupt any file. PDFs are no more vulnerable than other formats, but they fail in a distinctive way because their structure has to be intact to parse at all.

**Email mangling.** Some older mail systems alter binary attachments. This is rare now, but it still happens with certain enterprise mail gateways.

## Step 1: Re-download the file

If you received the PDF by download or email, this is where to start. The file on the server is almost certainly fine. Delete your copy and download it again. If someone emailed it to you, ask them to resend or drop it in a shared folder. This fixes the problem in the majority of cases where the download was cut off.

## Step 2: Use a free online PDF repair tool

For files that won't open at all, an online repair tool is your best option. These tools try to rebuild the PDF's internal structure from whatever bytes survived.

Two free options, no sign-up required:

- [iLovePDF Repair](https://www.ilovepdf.com/repair-pdf): upload the file and iLovePDF tries to reconstruct the cross-reference table and recover page content.
- [Sejda PDF Repair](https://www.sejda.com/repair-pdf): takes a similar approach, with clear feedback on what the tool found and whether recovery worked.

Neither tool guarantees a result. If the damage is too severe or the file was cut off early, there may not be enough data left to work with. But both are honest about failure and won't return a blank file and pretend it's fixed.

## Step 3: Extract the readable pages from a partially-open PDF

Some "corrupted" PDFs are only partly damaged. They open, but specific pages are blank, or the reader errors out partway through. In that case you don't need to repair the whole file. You just need to get the good pages out.

Use the free [Extract Pages tool](/extract-pages) to pull the pages that look correct into a clean new PDF. Pick what works, skip what doesn't. The tool runs entirely in your browser, so your file doesn't leave your device.

If you can see which pages are causing problems, the [Split PDF tool](/split-pdf) can also help. Break the file into smaller chunks to identify exactly where the damage is, then work with the sections that open cleanly.

After extracting the readable pages, use [Merge PDF](/merge-pdf) if you need to combine them with pages recovered from elsewhere, such as an older version of the document.

## Step 4: Convert pages to images to rescue invisible content

Some PDFs appear to open but display blank pages or invisible text. This is different from a structurally broken file. It usually means the text layer is corrupt or missing, but the rendered page content is still there.

A PDF reader tries to parse the text objects and gives up when they're broken. But an image renderer doesn't care about the text layer. It just paints what's on the page.

The [PDF to JPG tool](/pdf-to-jpg) renders each page as a JPEG rather than parsing its text layer. This often recovers content that shows up blank in Acrobat. You'll end up with images rather than a searchable PDF, but for a document you need to read or print, that's usually enough.

If you need the content as editable text, take the JPGs you recovered and open them in [Google Docs](https://support.google.com/docs/answer/179855): upload the image, right-click it in Drive, and choose "Open with Google Docs." Google's OCR will pull out the text.

## Step 5: Go back to the original source

If you created the PDF from Word, Google Docs, or another app, go back to that source file and export a fresh PDF. Re-exporting sidesteps the damage entirely. The source file is rarely affected when a PDF export goes wrong.

If the original is in your email sent folder, in version history, or in an auto-save, that's your cleanest recovery path.

## When a PDF can't be repaired

Not every damaged PDF can be saved. If the file was only partially downloaded, the missing data simply doesn't exist on your device. No repair tool can reconstruct content that was never written.

Signs that repair is unlikely to work:

- The file is only a few kilobytes, but it should be much larger. The download was cut off very early.
- Every repair tool returns the same error or an empty file.
- The file came from a failing drive that has since stopped working.

In those cases, your options are the original source, a backup, or asking whoever sent it to resend. A repair tool can only work with the bytes that are actually there.

One thing worth checking before you give up: make sure you're not dealing with a password-protected PDF rather than a corrupted one. They produce similar-sounding errors in some readers. If the file opens but immediately asks for a password you don't have, that's a different problem with a different fix.
