You can edit a PDF on a Chromebook for free without installing a single app. The fastest method is an online [Edit PDF](/edit-pdf) tool, which runs entirely in your Chrome tab and lets you change existing text, add new text, and place boxes on any page.

ChromeOS is built around the browser. That makes any web-based PDF tool a natural fit, and it works on every Chromebook, including school-managed devices where installing apps or extensions isn't allowed.

## What ChromeOS's built-in Gallery app can and can't do

Every Chromebook ships with the Gallery app, which opens PDFs by default. It handles a solid range of tasks without any extra tools:

- Highlight and annotate text
- Add text callouts and sticky notes
- Fill in interactive form fields
- Sign documents with a drawn signature

The one thing it can't do is edit the existing text in a PDF. If you need to fix a typo, update a name, or change a number that's already in the document, the Gallery app won't let you. You'll need a browser-based editor for that.

## How to edit a PDF on Chromebook using a browser tool

A browser-based editor is the most reliable option for actual text editing on a Chromebook. Here's how to do it with the [Edit PDF tool](/edit-pdf):

1. Open Chrome and go to the Edit PDF tool.
2. Drop your PDF onto the page or click to upload it.
3. Click on any text you want to change. A cursor appears so you can type, delete, or rephrase.
4. To add new text elsewhere on the page, select the text tool and click where you want it.
5. To add a label, note, or box, use the shape or text box options.
6. When you're done, click Download to save your edited PDF.

The whole process runs in your browser tab. There's no account required and nothing to install.

This approach also works on school-issued or work-managed Chromebooks. Because the tool opens in a regular Chrome tab rather than an installed app, device management policies that block app installs don't affect it.

## Can you edit a PDF in Google Docs on a Chromebook?

You can, though the results vary depending on what the PDF looks like. Here are the steps:

1. Upload the PDF to [Google Drive](https://drive.google.com).
2. Right-click the file and choose "Open with Google Docs."
3. Google Docs converts the PDF content into an editable document.
4. Make your changes.
5. Go to File, then Download, then "PDF Document (.pdf)" to save it back as a PDF.

This works well for simple text-heavy documents. The problems start with anything that uses designed layouts: multi-column text, tables, precise image placement, forms with specific alignment, or any PDF generated from a slide deck or brochure. Formatting often shifts, sometimes significantly, which means you can spend more time fixing the layout than fixing the actual content.

If preserving the original layout matters, go straight to a browser-based editor. If the content is mostly plain text and the layout doesn't matter much, Google Docs is a reasonable option.

## When the Gallery app is the right choice

The Gallery app is fast, it's already there, and for a lot of PDF tasks it's all you need. Use it when:

- You want to highlight passages in a reading or study document
- You need to fill in a job application or government form with interactive fields
- You need to sign a document before emailing it
- You want to add a quick note or annotation for someone else

Open any PDF in your Files app and it'll load in Gallery. The annotation toolbar appears at the top.

## How to fill out a PDF form on Chromebook

Filling a form is different from editing one. If the PDF has interactive fields that you can click and type into, the Gallery app handles most of them. Click a field, type your answer, repeat, then use the Share or Download option to save.

If a form has fields that the Gallery app misses, or if you want to check that all the fields are captured before submitting, the [Fill PDF Form](/fill-form) tool in your browser handles them more reliably. Drop the file in, fill every visible field, and download the completed copy.

## Signing a PDF on Chromebook

After editing or filling a form, you might also need to sign it. The [Sign PDF](/sign-pdf) tool lets you draw a signature using your trackpad or a touchscreen, then drag it to wherever it belongs on the page. The whole thing takes under a minute.

## Scanned PDFs: a quick note

Not every PDF can have its text edited, even with the best tool. A scanned PDF is a photograph of a page, not a document with real text inside it. [Optical character recognition (OCR)](https://en.wikipedia.org/wiki/Optical_character_recognition) is needed to convert those images into text that an editor can change.

If you click on text and nothing happens, the file is likely a scanned image. Most free browser tools don't include OCR. For a scanned PDF, you'd need a dedicated OCR service first, then open the output in a PDF editor to make your changes.
