JPG and PDF solve different problems, and choosing the wrong one creates headaches you don't need. The short answer: use PDF for documents, use JPG for photos you're sharing as images. But the details matter, so here's a clear breakdown.

## What JPG and PDF are actually for

JPG (or JPEG, same format) was designed for photographs. It compresses images by [discarding fine detail the human eye barely notices](https://jpeg.org/jpeg/), which keeps file sizes small. Every pixel in the file is part of one flat image. There's no concept of text, fonts, links, or layers.

PDF was designed to carry documents. It's a [container format from Adobe, now an open ISO standard (ISO 32000)](https://www.iso.org/standard/75839.html), that can hold text, fonts, vector graphics, images, form fields, annotations, and metadata all in one file. When you open a PDF, you get selectable text, clickable links, and a layout that looks the same on every device.

The simplest mental model: a JPG is a photograph of information, a PDF is the information.

## When to use JPG

JPG is the right call when the thing you're sharing is a photo and you want to keep the file small. It's good for product images on a website, photos shared over messaging apps, screenshots used as quick visual references, and images embedded in presentations or documents.

It's also the better choice when the recipient needs to open the file in a photo editor or post it to social media, because image platforms expect image files.

One thing to be aware of: every time a JPG is resaved, it re-compresses and loses a bit more quality. For anything you'll revisit and edit, keep the original in a lossless format (like PNG or TIFF) and export to JPG only when you're done.

## When to use PDF

Use PDF any time the document has text, a structured layout, or multiple pages. That covers a lot of ground:

- Resumes and CVs
- Contracts, agreements, and legal documents
- Invoices and receipts
- Reports, slide decks, and whitepapers
- Forms you need to fill in or sign
- Anything you intend to print from a specific paper size

PDF keeps fonts and layout intact. If you send a Word document and the recipient doesn't have the same fonts installed, the formatting can fall apart. A PDF looks identical everywhere.

PDF also supports interactive features. You can fill form fields, add digital signatures, include clickable links, and add comments without touching the visual layer of the document.

## File size: which is smaller?

It depends on what's inside.

A photo saved as a JPG is almost always smaller than the same photo embedded in a PDF, because the PDF wraps the image in page structure, metadata, and a colour space definition on top of the actual image data.

A text document is a different story. A 20-page text PDF can be 23 KB or less, because text stored as vector glyphs is tiny. Take a screenshot of those same pages and save it as a JPG, and you've got a large, blurry image file.

The comparison only makes sense when you're choosing a format for the same content. For photos, JPG is smaller. For text documents, PDF is almost always smaller.

That's great for image-heavy PDFs (a 913.4 KB image deck compressed down to 315.3 KB at Medium setting in our tests), but it makes text-only PDFs much larger. A 23.5 KB text report ballooned to 1.4 MB when run through the compressor. If your PDF is mostly text, splitting it or sharing it as-is will usually keep the file smaller.

## JPG vs PDF for resumes and job applications

Use PDF for your resume, full stop.

[Applicant tracking systems (ATS)](https://en.wikipedia.org/wiki/Applicant_tracking_system) parse the text in your resume to match it against job requirements. A JPG is a flat image, so the software can't extract any text from it. Your contact details, experience, and skills become invisible to automated screening.

PDF preserves your layout and remains readable by both humans and software. Some platforms (Indeed, Workday, Greenhouse) may ask for a specific format, but when given a choice, PDF is the safe default.

## JPG vs PDF for printing

PDF is the better choice for printing documents. It stores page dimensions, margins, fonts, and colour profiles so the printer receives exactly what was designed. The output matches the file.

JPG prints fine for photos, but for a document, print quality depends on whether the JPG has enough pixels for the paper size. A JPG that looks sharp on screen can print blurry at A4 or letter size if it wasn't captured at a high enough resolution.

If you have a JPG you need to print as a document, convert it to PDF first. Use the [Images to PDF tool](/jpg-to-pdf) to wrap the image in a PDF, which also lets you set the paper size correctly before printing.

## A quick guide to deciding

| You have | You need to | Use |
|---|---|---|
| A photo | Share it on the web or by message | JPG |
| A photo | Print it or archive it | JPG (or PNG for lossless) |
| A text document | Email it or submit it | PDF |
| A resume | Apply for a job | PDF |
| A form | Fill it in | PDF |
| A PDF page | Post it to social media | Convert to JPG |
| Several JPGs | Submit them as one document | Convert to PDF |

The default when in doubt: if it has text, use PDF.
