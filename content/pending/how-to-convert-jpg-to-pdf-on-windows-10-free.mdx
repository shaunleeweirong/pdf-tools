Converting a JPG to PDF on Windows 10 is free and takes under a minute. Windows ships with a built-in virtual printer called Microsoft Print to PDF that handles single images with no extra software. For combining multiple photos into one document or for keeping your files off a remote server, a browser-based tool gives you more control.

## Does Windows 10 have a built-in JPG to PDF converter?

It does. [Microsoft Print to PDF](https://support.microsoft.com/en-us/windows/microsoft-print-to-pdf-d2756d1b-1f60-bb49-4e3d-4e15e5dac6aa) is a virtual printer included in Windows 10 (and Windows 11) that saves whatever you'd normally print to a PDF file instead. Because it's already installed, there's nothing to download, no account to create, and no cost.

The Photos app, which is also built into Windows, gives you a clean interface for the same Print to PDF option. Both paths work offline, so you don't need an internet connection.

## How to convert a JPG to PDF using Microsoft Print to PDF

1. Double-click your JPG to open it in the Windows Photos app.
2. Press **Ctrl+P** to open the Print dialog.
3. Under "Printer," select **Microsoft Print to PDF**.
4. Choose a paper size. Letter or A4 fits most use cases.
5. Adjust scale if you want the image to fill the page (look for a "Fit page" checkbox or use the scale slider).
6. Click **Print**, then choose a folder and file name, and click **Save**.

The file is a standard PDF. Any PDF reader, browser, or device can open it.

**Note on margins.** By default, Windows adds white margins and scales the image down slightly. If you need the image to fill the page with no white borders, look for a margin or "Fit to printable area" option in the Print dialog. The exact label varies by Windows version.

## How to combine multiple JPGs into one PDF on Windows 10

The built-in method handles multiple images too. Here's how:

1. Open **File Explorer** and navigate to the folder with your images.
2. Select all the JPGs you want. Hold **Shift** to select a range, or hold **Ctrl** and click individual files.
3. Right-click any selected image and choose **Print**.
4. Select **Microsoft Print to PDF** as the printer.
5. The Print dialog shows a preview. You can choose "Full page photo" (one image per page) or a contact sheet layout.
6. Click **Print** and save the file.

**The page-order gotcha.** When you select multiple files in File Explorer, Windows sorts them by name. If your files are named img_2847.jpg, img_2848.jpg, and so on, the order follows the file name sort, which usually works out. If the images have unrelated names, rename them with a numbered prefix first (001_cover.jpg, 002_page.jpg) before selecting, or the page order in the PDF may not match what you intended.

## Will converting JPG to PDF affect image quality?

It depends on the method. Print to PDF samples the image at the DPI setting you choose in the Print dialog (usually 150 to 300 DPI). At 300 DPI, a standard A4 page can hold roughly 2480 x 3508 pixels of detail, which is more than enough for most photos. The resampling is mild and the output looks identical to the original at normal zoom.

A browser-based converter that embeds the original JPEG data works differently. The [PDF format](https://en.wikipedia.org/wiki/PDF) can store a JPEG image as a compressed stream directly, which is part of the ISO 32000 specification. When a tool embeds rather than re-encodes, the image inside the PDF is byte-for-byte identical to the source file. File size ends up close to the original JPG plus a small wrapper.

Short answer: for viewing on screen or printing at home, Print to PDF is fine. If you need maximum fidelity or you're sending files to a printer or publisher, a tool that embeds the original JPEG is the safer choice.
