The best free PDF reader for Windows with no sign-up is **SumatraPDF**, if fast, no-frills reading is all you need. If you need to highlight, fill forms, or sign documents, Foxit PDF Reader covers those features for free without an account. And if you'd rather install nothing at all, Microsoft Edge is already on every Windows 10 and 11 machine.

Here's how six free readers compare, all usable with no account.

| Reader | Install size | Highlights | Forms | Best for |
|--------|-------------|-----------|-------|----------|
| SumatraPDF | ~6 MB | No | No | Speed, low RAM |
| Microsoft Edge | Pre-installed | Basic | Basic | Zero setup |
| Foxit PDF Reader | ~190 MB | Yes | Yes | Full features |
| PDF-XChange Editor | ~140 MB | Yes | Yes | OCR, heavy markup |
| Adobe Acrobat Reader | ~240 MB | Yes | Yes | Compatibility |
| Chrome / Firefox | Pre-installed (if present) | No | Basic | Quick browser reads |

## SumatraPDF: the fastest reader on Windows

[SumatraPDF](https://www.sumatrapdfreader.org/free-pdf-reader) is a small, open-source PDF viewer that's been a Windows staple for over 15 years. The installer is about 6 MB, it opens PDFs in under a second, and it runs no background services or auto-updaters when you're not using it.

No account is ever required. You can download and run it immediately, or use it in portable mode from a USB drive if you don't want to install anything on the machine.

The trade-off is that SumatraPDF is strictly a reader. There's no highlighter, no sticky notes, and no way to fill out a form or sign a document. It also doesn't support JavaScript-heavy PDFs. But for opening a PDF fast to read it, SumatraPDF is the answer. It also reads EPUB, MOBI, DjVu, CHM, and comic book formats, which makes it useful beyond PDFs.

## Microsoft Edge: already on your machine

Windows 10 and 11 ship with Microsoft Edge, and Edge opens PDFs natively. Drag any PDF file onto an open Edge window and it loads without any extra steps. You can highlight text, use a stylus for inking, have the page read aloud with Read Aloud, and fill basic form fields.

Edge won't handle complex annotations or digital signatures, but for the average "I just need to read this file" situation, it's the path of least resistance. Nothing to download, nothing to sign up for.

If Edge isn't your browser of choice, Google Chrome and Firefox both have built-in PDF viewers that work the same way.

## Foxit PDF Reader: highlights, forms, and signatures for free

[Foxit PDF Reader](https://www.foxit.com/pdf-reader/) is the most capable free reader on this list for anyone who needs to do more than just read. You can highlight and annotate text, add sticky notes, fill out interactive PDF forms, and add a signature. All of that is free, with no account required.

Foxit also has a Safe Reading mode that automatically disables JavaScript in PDFs downloaded from the web. That's worth knowing if you regularly open files from email attachments or unfamiliar sources, since [malicious JavaScript embedded in PDFs is a known attack vector](https://en.wikipedia.org/wiki/PDF#Security).

The installer is larger than SumatraPDF (around 190 MB), and Foxit will show prompts encouraging you to upgrade to their paid PDF Editor. You can ignore those. The free Reader handles everything most people need from a PDF app.

## PDF-XChange Editor: the most capable free tier

PDF-XChange Editor has a larger interface and a steeper learning curve, but its free tier is the most powerful on this list. You can highlight and annotate, add stamps and comments, use built-in OCR to make scanned PDFs searchable, and compare documents.

One thing to know: the free version stamps a small watermark on pages when you export a file you've made changes to. It does not stamp pages you've only read or annotated without saving. For pure reading with annotations, it's fully free. If you need clean PDF exports from your edits, you'd want the paid version.

## Adobe Acrobat Reader: widest compatibility

[Adobe Acrobat Reader](https://www.adobe.com/acrobat/pdf-reader.html) is the most widely used PDF viewer in the world. No account is needed to read files, though Adobe prompts you to sign in and will remind you about paid features regularly.

The installer is large (around 240 MB), which is a reason some people look for alternatives. But if you're dealing with PDFs that use advanced JavaScript, certified digital signatures, or specific security restrictions, Acrobat Reader handles them more reliably than lighter tools do. For everyday reading, SumatraPDF or Edge is more convenient. For PDFs that behave unexpectedly in other readers, Acrobat Reader is the fallback.

During installation, uncheck the optional software Adobe bundles by default (antivirus trials and toolbars). They're pre-checked and easy to miss.

## Browsers: the no-install option

If you have Chrome, Firefox, or Edge installed and you're not doing annotation work, you already have a PDF reader. All three open PDFs in a built-in viewer and handle basic navigation, zooming, and printing without plugins or sign-ups. Chrome and Edge also handle basic form filling.

For quick reads and one-off files, this is the simplest approach.

## Reader vs. editor: knowing which you need

A PDF reader opens and displays a file. A PDF editor lets you change the content. Most people asking about a free PDF reader actually need a reader that can highlight or fill forms, which Foxit and PDF-XChange cover in their free tiers.

If you need to do things to a PDF before reading it, like reducing the file size, pulling out specific pages, or combining multiple files into one document, those are separate tasks that work best in dedicated tools. The [Compress PDF tool](/compress-pdf) reduces file size in your browser with no account and no upload. [Merge PDF](/merge-pdf) combines files in the same way. [Split PDF](/split-pdf) lets you extract specific pages. None of those require a reader app.

## Which reader should you pick?

- **Fastest startup, minimal footprint**: SumatraPDF.
- **No downloads, already there**: Microsoft Edge (or Chrome / Firefox).
- **Highlights, forms, signing**: Foxit PDF Reader.
- **OCR and advanced markup**: PDF-XChange Editor.
- **Complex PDFs, maximum compatibility**: Adobe Acrobat Reader.

None of them require an account to read files, which is really the only thing that should matter when picking a PDF reader.
