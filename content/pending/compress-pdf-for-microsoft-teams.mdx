Sharing a PDF in Microsoft Teams is usually fast, but sometimes a file stalls on upload or your organization's size policy blocks it. The [Compress PDF tool](/compress-pdf) can fix this when the PDF is full of images or scanned pages. If it's a typed document, compressing it will actually make it bigger, so this post covers both situations.

## What is the actual file size limit in Microsoft Teams?

Teams doesn't store files on its own. Files dropped into a channel go to that team's SharePoint Online site. Files sent in chat go to OneDrive for Business. According to [Microsoft's official limits page](https://learn.microsoft.com/en-us/microsoftteams/limits-specifications-teams), both services cap individual files at 250 GB, which is well beyond any PDF you're likely to have.

So if a PDF won't upload, the limit probably isn't Teams itself. A few things cause upload failures in practice:

- **A custom SharePoint policy**: Many IT departments lower the per-file limit to 50 MB or 250 MB to control storage costs. You won't always get a clear error when this policy kicks in.
- **Teams Free storage cap**: The free version of Teams gives [5 GB of total storage per user](https://support.microsoft.com/en-us/office/where-is-my-microsoft-teams-free-data-stored-415b9795-4005-4143-b5b7-29c2e98260f5). Once that fills up, uploads fail.
- **Education assignment limits**: Teams for Education uses a separate upload path for assignments, and the per-file limit varies by institution.
- **A slow or dropped connection**: Sometimes a large file doesn't fail outright but times out mid-upload. Reducing the file size means less data to transfer and fewer chances for a timeout.

If you're not sure which applies, try uploading a small test file first. If that succeeds, file size is the issue.

## When compression shrinks a PDF

The compress tool works by rasterizing each page to a JPEG. That works well when the PDF is already made of images, because compressing an image-based page is efficient. In our testing, a 6-page image-heavy PDF went from 913.4 KB to 315.3 KB at Medium compression, a reduction of about 65%.

Use compression when your PDF:
- Contains scanned documents, receipts, or photos
- Was exported from PowerPoint or Keynote
- Has large embedded images on most pages

## When compression makes things worse

Applied to a text-based PDF, the same tool has the opposite effect. A 20-page text report grew from 23.5 KB to 1.4 MB after compression, because converting sharp vector text into a JPEG photograph of that text is a very inefficient encoding. Vector text is compact; a photo of text is not.

Don't compress a PDF that is mainly:
- A typed report, contract, or invoice
- A form, filled or blank
- A document exported from Word or Google Docs

If you compress one of these and it comes back far larger, that's the expected result. Use the splitting approach below instead.

## How to compress an image PDF before uploading to Teams

1. Open the [Compress PDF tool](/compress-pdf) in your browser. No account or download needed.
2. Drop your PDF onto the page or click to choose it from your files.
3. Pick **Medium** compression. This gives a meaningful size reduction without visible quality loss for most image and scan PDFs.
4. If the result is still too large, go back to your original file and try **High**. Don't run the compressed copy through a second pass.
5. Download the compressed file, then upload it to Teams as you normally would.

The tool runs entirely inside your browser. Your file is never sent to a server.

## What to do when your PDF is text-based and still too large

Splitting is usually the right fix for a text-heavy PDF. A 150-page report split into three 50-page sections keeps each piece under any reasonable limit, and recipients can open only the part they need.

Use the [Split PDF tool](/split-pdf) to pull out page ranges as separate files. Give each section a clear filename, like `report-part-1.pdf`, `report-part-2.pdf`, so recipients know the order.

There's also a simpler workaround that skips compression entirely: upload the PDF to the **Files** tab in a Teams channel, then paste the link into your message. The file lives in SharePoint where limits are generous, you preserve the original quality, and you can replace the file later without having to re-send anything.

## Should you compress a PDF more than once?

It won't help, and usually hurts. In testing, running a Medium-compressed PDF through a second Medium pass made it 90% bigger, because re-encoding an already-compressed JPEG adds data rather than removing it. A second pass at High recovered only 5.6% of size, which isn't worth the quality trade-off.

If Medium compression isn't enough, start from the original file and run it at High. Never chain compression passes from an already-compressed copy.
