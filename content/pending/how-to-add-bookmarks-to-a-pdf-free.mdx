Adding navigation bookmarks to a PDF is straightforward with free online tools, and you don't need Adobe Acrobat to do it. This guide covers three methods: a no-sign-up online tool, a second option with more control, and a built-in Mac option.

## What PDF bookmarks actually are

Before jumping into steps, it helps to know what a PDF bookmark is. In a PDF reader, bookmarks appear as a clickable panel on the side (sometimes called the outline or navigation panel). Each entry jumps to a specific page when you click it. They're common in long reports, manuals, and ebooks to help readers jump between sections without scrolling.

This is different from a browser bookmark, which saves a web address. And it's different from reading apps that let you "bookmark a page" as a personal placeholder. PDF bookmarks are embedded in the file itself, so anyone opening it in a standard PDF reader can see them.

The [PDF specification (ISO 32000)](https://pdfa.org/resource/iso-32000-2/), maintained by the PDF Association, defines the document outline structure that makes this possible. Bookmarks live in the file's document tree, not in separate metadata.

## Method 1: PDF24 (free, no sign-up, no limits)

PDF24 offers a free bookmarks tool in your browser with no registration required. Files are processed on their servers and deleted automatically afterward.

1. Go to the PDF24 bookmark tool at pdf24.org.
2. Upload your PDF by clicking "Choose file" or dragging it in.
3. The tool shows existing bookmarks on the left and a page preview on the right.
4. Click "Add bookmark" to create an entry. Give it a name and set which page it points to.
5. Drag entries to nest them, creating sub-levels like "Chapter 1 > Section 1.1".
6. Click "Apply changes" and download the updated file.

PDF24 has no page count or file size limit on the free tier, which makes it practical for long documents.

## Method 2: Sejda (free tier, 3 tasks per hour)

Sejda's bookmark editor gives you more control, including the ability to set the zoom level each bookmark opens to. The free tier handles PDFs up to 200 pages and 50 MB, with a limit of 3 tasks per hour.

1. Go to the Sejda PDF bookmarks tool at sejda.com.
2. Upload your file.
3. Use the editor panel to add, rename, or reorder bookmarks. Right-click an entry to change its destination page.
4. Click "Apply changes" to save and download.

Sejda works well for technical documents where readers need to jump between specific subsections.

## Method 3: Mac Preview (personal page markers)

If you're on a Mac, Preview lets you add bookmarks without any third-party tool. There's an important distinction to know: [Preview's bookmarks](https://support.apple.com/guide/preview/bookmark-pdf-pages-prvw1087/mac) are personal reading markers, not the structural outline bookmarks visible in other apps.

To add a bookmark in Preview:

1. Open the PDF in Preview.
2. Go to the page you want to mark.
3. Choose **Tools > Add Bookmark**, or press **Command + D**.
4. A small red ribbon appears in the top-right corner of the page.

To see all your bookmarks, choose **View > Bookmarks**. A sidebar lists every marked page by title. Click any entry to jump there.

These markers persist when you reopen the file in Preview. However, they're stored in Preview's local reading data rather than embedded in the PDF. If you share the file, the recipient won't see them in other readers. For bookmarks that others can see, use PDF24 or Sejda instead.

## Does free Adobe Reader let you add bookmarks?

No. Adobe Acrobat Reader (the free viewer) lets you view existing bookmarks but not create new ones. To add, edit, or delete PDF bookmarks you need Acrobat Pro, which costs around $20 per month. If you'd rather not pay, PDF24 and Sejda do the same job for free.

## Do bookmarks survive when you edit a PDF?

This depends on what you do to the file:

- **Rotating pages or adding page numbers** typically preserves the existing bookmark outline.
- **Merging** is tricky. Many tools copy page content but drop the bookmark outlines from the input files. If you plan to merge documents, add bookmarks to the merged result rather than to each source file. - **Splitting** usually keeps bookmarks that fall within the extracted page range, though this varies by tool.

## How to structure your bookmarks

A flat list works fine for short documents. For longer ones, a hierarchy makes the panel genuinely useful:

- Top-level entries for chapters or major sections
- Second-level entries for subsections
- Third level for sub-subsections, if you need them

Most PDF readers display two or three levels cleanly. Going deeper tends to make the panel hard to read.

Name each bookmark the way a reader would search for that section. "How billing works" is clearer than "Section 4: Billing Module Overview" for most audiences.

## When you don't need bookmarks

Not every PDF needs them. A three-page document doesn't require a navigation panel. A form someone fills out and returns doesn't benefit from bookmarks. They add the most value when:

- The document is ten or more pages
- Readers need to jump between sections rather than read straight through
- The file will serve as a long-term reference and get opened repeatedly
