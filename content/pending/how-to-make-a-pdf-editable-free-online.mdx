Making a PDF editable online is free and takes less than a minute for most documents. The approach depends on what you actually need to do: add text somewhere, fill in existing fields, change wording that's already there, or build a form for others. This guide covers each case.

## What "editable" means depends on your goal

People search for "how to make a PDF editable" for four different reasons, and each needs a different tool:

1. You want to type text somewhere on the page (over a blank line, in a margin, on a signature line).
2. You received a form with clickable fields and want to fill them in.
3. You need to change the actual words already printed in the document.
4. You want to turn a flat document into a form that other people can fill in.

Picking the wrong approach wastes time. A form filler won't help you annotate a flat PDF, and a text-annotation tool won't help you create interactive fields. Start with your actual goal.

## Add text or annotations anywhere: use Edit PDF

The fastest way to put new text anywhere on a PDF page is the free [Edit PDF tool](/edit-pdf). Drop in your file, click where you want to type, and place a text box. You can resize and reposition it, change the font size, and download the result as a normal PDF.

This is the right choice when:

- You have a flat form with printed lines but no interactive fields
- You need to add a note, correction, or label in a specific spot
- You want to place your initials or a short annotation somewhere on the page

The tool also lets you draw boxes, which is useful for covering outdated content before placing new text on top. Everything runs in your browser, so the file never leaves your device.

## Fill in an existing PDF form: use Fill PDF Form

If your PDF already has interactive fields (text boxes, checkboxes, dropdowns), the [Fill PDF Form tool](/fill-form) is faster. It detects the fields the original author built into the document and lets you type directly into them. The input stays aligned inside the correct field, which looks cleaner than free-floating text boxes.

This works well for:

- Job application forms
- Government and official forms
- Contracts or agreements sent to you with fields already set up

If the PDF has no form fields at all, the form filler won't find anything to fill. In that case, go back to Edit PDF and place text boxes manually over the blank lines.

## Change existing text in a PDF: Google Docs

Modifying words that are already in a PDF is harder. The [PDF format](https://www.iso.org/standard/75839.html) (ISO 32000) stores content in a way that is optimised for consistent display, not for editing in place. Unlike a Word document, the text isn't stored as a simple string you can click into and change.

For normal text-based PDFs, Google Docs offers a free workaround that actually works. Go to [Google Drive](https://drive.google.com), upload the PDF, right-click it, and choose "Open with Google Docs". Google converts the file to a Docs document, which you can edit freely, then export back to PDF. The more complex the layout (multi-column, lots of images, unusual fonts), the less precisely it will recreate the original formatting. For simple documents it works very well.

Scanned PDFs are a different case. A scan is an image, not text, so there are no text characters to select or edit. You need [optical character recognition](https://en.wikipedia.org/wiki/Optical_character_recognition) (OCR) to convert the image into text first. Free OCR tools include Adobe Acrobat's online scanner (limited page count) and Google Drive itself, which runs basic OCR when you open a scanned PDF with Google Docs. Accuracy is reasonable for clean, clearly printed documents and lower for handwriting or low-resolution scans.

## Make a PDF fillable for others: add form fields

If you are building a form for other people to fill in, you need to add interactive fields to your document. This is different from filling in a form yourself.

The process in most free tools looks like this:

1. Upload or create your base PDF.
2. Use the field-drawing interface to place text fields, checkboxes, radio buttons, or dropdowns where you want input.
3. Set any rules (required field, date format, character limit).
4. Save and share the PDF.

Free options that handle this include PDF24's fillable form creator and the free tier of Adobe Acrobat online. Both run in the browser without a download. The resulting file opens in any standard PDF reader, including the one built into Chrome, Edge, and macOS, so recipients don't need special software.

One thing to keep in mind: if you later [merge a filled form](/merge-pdf) with another PDF (say, attaching a cover letter), the interactive fields are stripped in the process. The filled values may not survive. To avoid this, use the [Flatten PDF tool](/flatten-pdf) on the filled form before merging. Flattening bakes the entered text permanently into the page as visible content, so it won't disappear when you combine files.

## Why some PDFs resist editing

Not every PDF will cooperate with free editors. There are two main reasons.

First, the document may have permission restrictions set by the author. The PDF format supports flags that prevent printing, copying, or modification. Some editors silently ignore these; others refuse to save the result. If a free tool lets you make changes but won't save them, a locked permission flag is the likely cause.

Second, scanned or image-heavy PDFs have no real text layer. What looks like a paragraph is actually a photograph of a paragraph. No text editor can change an image in the way it would change characters, which is why OCR has to run first.

If you only need to add new information (rather than change existing content), these restrictions often don't matter. Placing a text box with our Edit PDF tool works even on locked PDFs as long as the tool can read the file, because you're adding new content on top, not modifying the original text layer.
