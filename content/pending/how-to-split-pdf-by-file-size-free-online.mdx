Splitting a PDF by file size means dividing a large document into smaller parts, each under a target file size you choose. You can do this free in your browser with the [Split PDF tool](/split-pdf), no software to install and no account required.

## What size limit are you working with?

Before you split, nail down the exact limit so you know what to target per part.

[Gmail and Yahoo cap email attachments at 25 MB](https://support.google.com/mail/answer/6584). Outlook and iCloud cap theirs at 20 MB. Government upload portals, courts, and school platforms (Blackboard, Canvas, Turnitin) often set the bar lower, at 5 to 10 MB per file. When you're not sure of the exact limit, 10 MB per part is a safe default that fits almost everywhere.

If your PDF is 90 MB and you need to send it through Gmail, you'll need at least four parts, each under 25 MB. Knowing the arithmetic up front saves you from splitting twice.

## How to split a PDF to hit a target file size

The [Split PDF tool](/split-pdf) splits a file by page range. Because each page takes a predictable amount of space, you can land on a target file size by choosing the right number of pages per part. Here's the full process:

1. **Check your PDF's file size and page count.** Right-click the file on your desktop and choose Properties on Windows, or Get Info on Mac, to see the size in MB. Open the PDF to confirm the page count.
2. **Estimate pages per part.** Divide the file size by the page count to get an average size per page. Then divide your target part size by that average. For example: a 60 MB PDF with 120 pages averages 0.5 MB per page. Targeting 20 MB per part, aim for about 40 pages each.
3. **Open the Split PDF tool** and upload your file.
4. **Enter the page ranges.** Type the start and end pages for each part: 1 to 40 for part one, 41 to 80 for part two, and so on.
5. **Download each part** and check its file size before sending.
6. **Adjust if needed.** If one part is still over your limit, go back and trim a few pages off that range.

Image-heavy and scan-heavy pages take more space than text-only pages, so you may need tighter page ranges for the visual sections of your document.

## What if a part is still too large after splitting?

The quickest fix is to narrow the page range for that part. Removing 10 pages from a range that is slightly over the limit usually solves it.

If the document is mostly scanned pages or photos, you can also run each part through the [Compress PDF tool](/compress-pdf) to shrink it further. Compression works well on image-heavy files, but it will make text-based documents larger. A 913.4 KB image deck compresses to around 315.3 KB at Medium quality. A text report, by contrast, can balloon from a few dozen kilobytes into several megabytes after compression. Do not compress reports, contracts, or forms.

## When to split vs. when to compress

These two tools solve different problems, and choosing the right one upfront avoids wasted steps.

**Split when:**

- You need to keep all the content and just want several smaller files.
- Your PDF is text-heavy (legal documents, reports, contracts, filled forms).
- Different parts need to go to different recipients.
- You're working with a portal that requires a file upload and won't accept links.

**Compress when:**

- Your PDF contains scanned pages, photographs, or a lot of images.
- You need one single smaller file, not multiple parts.
- The file is modestly over the limit and compression alone can get it under.

A scanned document that's 30 MB and needs to stay under 25 MB is a good candidate for compression first. A 100 MB text report should go straight to splitting.

## How content type affects file size per page

A page of body text stored as text in a PDF takes very little space, often just a few kilobytes. A full-page scanned image can weigh 500 KB or more, depending on scan resolution. This is why two PDFs with identical page counts can vary enormously in size.

[The PDF file format, standardized as ISO 32000 by the International Organization for Standardization](https://en.wikipedia.org/wiki/PDF), stores text, vector graphics, and raster images as separate internal objects. Text objects compress naturally and stay tiny. Raster image objects carry every pixel of the scan. When you split a PDF, each output file reflects exactly whatever mix of content was on those pages.

If you can see that your pages are visually dense, with diagrams, full-page images, or screenshots, budget more space per page. If most pages are mostly text with occasional small logos, you can fit more pages per part.

## The cloud link alternative

If you need the recipient to see a single unbroken document, uploading to cloud storage and sharing a link is often simpler than splitting. Upload to Google Drive or Dropbox, get a view-only link, and paste it into your email. The recipient reads the full file without running into attachment limits.

This works for informal sharing. For formal submissions (court filings, government forms, job applications), many portals require a file upload and won't accept a link. In those cases, split the file into parts and label them clearly: "Application Part 1 of 3", "Application Part 2 of 3", and so on.

If you're merging documents before splitting them, it's worth knowing that the [Merge PDF tool](/merge-pdf) does not inflate file size. Combined output comes in within a fraction of a percent of the sum of the inputs, so merging first and splitting second is a perfectly efficient workflow.
