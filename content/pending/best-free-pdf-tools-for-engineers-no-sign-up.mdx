The best free PDF tools for engineers cover the tasks that come up in every project: merging drawing sets into a single submittal, pulling specific sheets from a large specification book, rotating a CAD export that came out sideways, and converting a drawing page to an image for a report. All the tools below run in your browser with no account required.

## Why engineers live with PDFs

PDF is [the standard exchange format for technical drawings](https://www.adobe.com/in/acrobat/roc/blog/convert-pdf-to-cad-drawing.html) across architecture, engineering, and construction. CAD software produces native DWG, RVT, or DXF files, but virtually every drawing that leaves a project boundary ships as a PDF. It preserves exact geometry and text regardless of what software the recipient runs, keeps proprietary model data out of the file, and works with the annotation markup workflows that are standard in design reviews.

So a typical project folder fills up fast: drawing sheets, calculation reports, geotechnical reports, waterproofing specs, test certificates, RFIs, submittals. Getting that material into the right shape for clients, contractors, or regulators means a steady stream of combining, splitting, rotating, and compressing.

## Combining drawing sets and reports

The most common PDF task for engineers is combining files. A structural submittal might be a drawing set, a geotechnical report, and a waterproofing specification. A client deliverable is often drawings plus a cover letter plus appendices.

The [Merge PDF](/merge-pdf) tool handles this in one step. Upload the files in the order you want, then download the combined document. Everything runs in your browser, so proprietary drawings never pass through a third-party server.

One thing worth knowing: merging does not inflate the output. In our own tests, a set of three files totalling 971.9 KB combined into a single 970.5 KB file. So merging a drawing set with a text report will not push the total over an email limit beyond what the parts already add up to.

There is one catch. Merging strips interactive form fields. If you have a filled-in compliance or inspection form that needs to go into the combined document, flatten it first with the [Flatten PDF](/flatten-pdf) tool. That paints the field values into the page so they survive the merge.

## Compressing engineering PDFs (and when not to)

This is where engineers often get a surprise, so it is worth explaining clearly.

The [Compress PDF](/compress-pdf) tool rasterizes each page to a JPEG image. For drawing exports and scan sets, where pages are already pixel-based, this works well: at Medium quality, a 913 KB image-heavy drawing file shrank to 315 KB in our tests.

For text-only documents, don't use it. Rasterizing a text page converts crisp vector type into a photograph of that type. The result is both larger and no longer machine-readable. A 23.5 KB text report grew to 1.4 MB when run through the compressor. A mostly text document with a small logo grew from 35 KB to 171 KB.

Use compress-pdf on:
- CAD drawing exports where pages are raster images
- Scan sets from site visits or document scanning
- Photo-heavy progress reports

Skip it for:
- Calculation sheets and text reports
- Contracts and specifications
- Any document where text needs to remain selectable or machine-readable

For a large text report, the right approach is to re-export from the source application at a lower image resolution, or to split out the large image attachments rather than compress the whole document.

## Extracting and splitting technical documents

Large specification books, standard detail libraries, and code references can run hundreds of pages. When you need only a handful of sheets, extracting them is faster than sending the whole file.

The [Extract Pages](/extract-pages) tool pulls specific pages into a new PDF. The [Split PDF](/split-pdf) tool breaks a document into defined page ranges. Both are useful for:

- Sending a subcontractor only the sheets that relate to their scope
- Pulling appendices out of a full report for separate distribution
- Breaking a large submittal into separate discipline packages

## Rotating pages in drawing sets

CAD applications sometimes export wide-format drawings at the wrong page orientation. The [Rotate PDF](/rotate-pdf) tool turns pages 90 degrees, 180 degrees, or 270 degrees in one click.

Because rotation only sets an orientation flag and does not re-render page content, the file size is unchanged to within a few bytes. A rotate tool that returns a noticeably different file size is re-rasterizing pages, which would convert text into images.

## Converting drawings to images

Sometimes a drawing needs to be an image rather than a PDF: to embed it in a Word document, drop it into a slide deck, or paste it inline in an email. The [PDF to JPG](/pdf-to-jpg) tool converts each page to a high-resolution JPEG.

This is useful for single-sheet detail drawings, schematic diagrams that need to appear in a written report, and site-visit photos that arrived as a scanned PDF from a contractor.

## Removing and reorganizing pages

Before sending a drawing set to a client, draft sheets, superseded revisions, or internal notes often need to come out. The [Delete Pages](/delete-pages) tool removes one or more pages by number. If you need to reorder sheets as well, [Organize PDF](/organize-pdf) shows a page-thumbnail view where you can drag pages into a different sequence or remove them one by one.

## Privacy: why in-browser matters for engineering work

Drawings often contain dimensions, tolerances, material callouts, and proprietary design details that should not leave your control. All the tools on this site run using [WebAssembly](https://developer.mozilla.org/en-US/docs/WebAssembly) in your browser. Files are processed locally and never uploaded to any server.

If your project has NDA requirements or export-control restrictions, that is worth confirming before choosing any online PDF tool. In-browser processing is the clearest way to keep files on your machine.

For drawings that need long-term archival, the [PDF/A format](https://www.pdfa.org/pdf-a-the-iso-standard-for-long-term-archiving/) is worth knowing about. PDF/A is the ISO-standardized archival variant of PDF, and some government and regulatory submissions require it.
