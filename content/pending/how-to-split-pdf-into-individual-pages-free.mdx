Splitting a PDF into individual pages is something you can do for free in your browser, without installing anything. The [Split PDF](/split-pdf) tool handles this in seconds. Drop in your file, pick the pages, and download the result. No account, no software, no server upload.

## Why split a PDF into individual pages?

Most people do it because they have one document but only need to share part of it. Sending a 30-page report when the recipient only needs page 14 is wasteful, and sometimes inappropriate when the rest contains sensitive information.

Other situations come up often:

- You need to submit a single page of a contract, tax form, or application packet.
- You want to pull one slide from a PDF presentation to attach as a standalone file.
- A scanning session combined several different documents into one file, and you need to separate them.
- A client asked for one specific page, not the whole thing.
- You want to reorganize a document by extracting pieces and merging them in a different order.

Splitting solves all of these without touching the original file.

## How to split a PDF into individual pages free: step by step

This method works in any browser on Mac, Windows, iPhone, or Android.

1. Open the [Split PDF](/split-pdf) tool.
2. Click "Choose file" or drag your PDF onto the page.
3. Enter the page range you want to extract. To get a single page, type just that page number. To pull a range, type something like "3-6".
4. Click the button to split.
5. Download the resulting file.

If you need several individual pages from the same document, repeat the process for each one. It takes about 30 seconds per page.

Your file is read and processed locally in your browser. The original document stays on your computer, untouched.

## What about splitting all pages at once?

Some tools let you split an entire PDF in one go, outputting one file per page automatically. This is handy for a 5-page document. For anything longer, it creates more files than most people want to sort through.

The practical approach: extract just the pages you actually need. Running the tool twice for two pages is faster than downloading 50 files and finding the two you care about.

If you need to keep specific pages from a longer document, the [Extract Pages](/extract-pages) tool lets you pick a set of page numbers and save them together as one new PDF. That is useful when you want pages 2, 7, and 14, for instance, rather than individual separate files.

## How to split a PDF on a Mac for free

Your Mac's built-in Preview app can pull individual pages out of a PDF without installing anything extra.

1. Open your PDF in Preview. If double-clicking opens a different app, right-click the file and choose "Open With > Preview".
2. Go to View > Thumbnails to show the page sidebar (keyboard shortcut: Command-Option-2).
3. Click the thumbnail of the page you want to separate.
4. Drag that thumbnail out of the Preview window and drop it onto your Desktop or a Finder folder.

Preview saves the dragged page as a new PDF automatically. It works well for one or two pages. For pulling out several pages from a long document, a tool built for the job is faster.

Apple has full documentation of [Preview's PDF tools](https://support.apple.com/guide/preview/export-pdfs-prvw14/mac) if you want to explore other export options, including saving page ranges as separate files through File > Export as PDF.

## How to split a PDF on Windows for free

Windows doesn't have a built-in drag-and-drop equivalent to Preview. The fastest free option is the browser-based [Split PDF](/split-pdf) tool above, which works the same on Windows as on any other platform.

If you prefer an offline desktop app, [PDFsam Basic](https://pdfsam.org) is a free, open-source option that runs on Windows, Mac, and Linux. It processes files locally, so nothing is uploaded anywhere. The interface is plain but it handles large documents well.

## Does splitting change the PDF's quality?

No. [PDF files are structured as a collection of self-contained page objects](https://en.wikipedia.org/wiki/PDF), defined by the ISO 32000 standard. When you split a PDF, the tool copies those page objects into a new file, including embedded fonts, images, and any vector graphics. Nothing is re-rendered or re-compressed.

One thing worth knowing: interactive form fields may not carry over if they are stored at the document level rather than within the page itself. If a form's field values have been printed into the page content (as happens after you flatten a form), they survive the split. If the fields are still interactive, they might not appear in the extracted file. For most everyday uses, sending a single page of a report or submitting one section of a form, this won't matter.

## Can I split a PDF that has a password on it?

A password-protected PDF can't be modified until the password is removed. Use the [Unlock PDF](/unlock-pdf) tool to strip the password first, then run the split tool on the clean result.

## Splitting vs. deleting pages: what is the difference?

Splitting and deleting pages are related but they go in opposite directions. When you split a PDF, you pull a page (or range) out and save it as a new document. The source file stays as it is. When you delete pages, you remove them from the existing document and save the shorter version.

If your goal is to send one page, split. If your goal is to trim a document before sharing the whole thing, delete. Both are free with the tools on this site.
