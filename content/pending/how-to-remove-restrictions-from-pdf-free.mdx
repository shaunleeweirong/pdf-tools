You can remove restrictions from a PDF free in your browser in about ten seconds. If the PDF opens fine but printing is greyed out, copying is blocked, or editing is disabled, it has permission restrictions set by whoever created the file. Here's how to clear them.

## Why some PDFs let you open them but block printing or copying

PDF security has two separate mechanisms, and confusing them is very common.

The first is an **open (user) password**: the file is encrypted and you can't view anything without the password. The second is a **permissions (owner) password**: the file is readable by anyone, but the creator flagged specific actions as off-limits. Those flags tell compliant PDF viewers to grey out the print button, block text selection, or disable the editing toolbar.

The [PDF specification (ISO 32000)](https://pdfa.org/pdf-20/) supports a specific set of permission flags: printing (full or low-resolution only), copying text and graphics, editing, filling in form fields, adding annotations, and assembling pages. Any subset of these can be restricted independently.

The key thing to understand: a permissions-only restriction does not encrypt your content the same way an open password does. The file is readable. The viewer is just following a flag. That distinction matters for how you remove it.

If you know the owner (or user) password for the PDF, this is the cleanest and most reliable route:

1. Open the [Unlock PDF tool](/unlock-pdf).

3. Enter the password when prompted.

The tool runs entirely in your browser using [qpdf](https://qpdf.sourceforge.io/), a well-established open-source library for PDF structure manipulation. We measured a 24.6 KB encrypted file coming back at 23.6 KB after removing the password: almost identical in size, no re-rendering, no quality change. The output is a standard PDF with all restriction flags cleared.

If you enter the wrong password, the tool rejects it immediately. Nothing is downloaded and no damaged file is produced.

## How to remove restrictions without a password

If the PDF opens without asking for a password but still blocks printing or copying, there's a browser-based workaround that works in many cases:

1. Open the PDF in Chrome or Microsoft Edge (just drag the file into a tab).
2. Click the print icon (or press Ctrl+P / Cmd+P).
3. Set the destination to **Save as PDF**.
4. Print to a file.

When browsers render a page for printing, they often ignore the permissions flags set in the PDF and produce a flat copy without them. The resulting file usually allows printing and text copying.

The trade-off: this print-based copy is a re-render. Interactive form fields, hyperlinks, and bookmarks typically don't survive. Fonts should stay selectable. If you need a clean, structurally intact copy, and you have the password, use the [Unlock PDF tool](/unlock-pdf) instead.

This method works only when the PDF has **no open password**. If the file requires a password to open, you need that password before any other step is possible.

## What types of restrictions can be removed?

A permissions password can restrict any combination of these actions:

- **Printing** (some PDFs allow low-resolution printing but block full-resolution)
- **Copying** text and images
- **Editing** the document (adding, deleting, or rearranging content)
- **Filling in form fields**
- **Adding comments or annotations**
- **Extracting pages**

When you remove the permissions password, all of these restrictions clear at once. You can't selectively remove only the print restriction while keeping the copy restriction, because they're all stored under the same encryption key.

## Does removing restrictions affect the file?

No, not in any meaningful way. The content, layout, fonts, and images are unchanged. What comes off is the [encryption layer](https://en.wikipedia.org/wiki/PDF#Security_and_signatures) that enforces the permission flags. The file size barely changes because that layer is tiny relative to the document content.

To put real numbers on it: we protected a 23.5 KB PDF (adding a password via AES-256 encryption) and it grew to 24.6 KB. After removing the password, the same file was 23.6 KB. The round trip adds and removes about 1 KB, which is the overhead of the encryption metadata. Nothing in the pages changes.

## Why an in-browser tool is the safer choice

Most PDF tools you'll find through a search ask you to upload your file to their servers. For a document containing sensitive information, that's a real privacy issue. You're handing your document (and possibly its password) to a machine you don't control, and you have no visibility into what happens after.

The [Unlock PDF tool](/unlock-pdf) processes everything locally. The file and the password stay on your device; nothing is sent over the network. If you're working with a contract, a tax document, a payslip, or a medical record, this difference matters.

You can verify it yourself: open your browser's developer tools, go to the Network tab, and run the tool while watching for outbound requests. You'll see none carrying your file.
