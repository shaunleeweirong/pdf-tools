If your PDF won't open in Chrome, the most common cause is either the built-in viewer got disabled, an extension is getting in the way, or cached data is stale. Most of these take under two minutes to fix.

Work through the steps below in order. Most people find the answer in the first two.

## Check Chrome's PDF viewer setting first

Chrome comes with a [built-in PDF viewer](https://support.google.com/chrome/answer/6213030) that handles most files without extra software. It can be turned off, either by you or by an installer you ran, and when it is, Chrome saves the PDF to your Downloads folder instead of displaying it.

To check: type `chrome://settings/content/pdfDocuments` in the address bar and press Enter. You'll see two options: "Open PDFs in Chrome" and "Download PDFs." If "Download PDFs" is selected, switch it to "Open PDFs in Chrome" and reload the PDF.

This one setting fixes the majority of cases where Chrome downloads a PDF instead of showing it.

## Disable the Adobe Acrobat extension

If Chrome opens a PDF tab but shows a blank or white page, the Adobe Acrobat browser extension is the most common cause. When it's installed, it intercepts the PDF before Chrome's viewer can process it and often fails without any visible error.

How to fix it:

1. Go to `chrome://extensions`.
2. Find "Adobe Acrobat" in the list and toggle it off.
3. Reload the PDF.

Chrome's viewer handles the vast majority of PDFs on its own. Unless you need a specific Acrobat feature inside the browser, leave the extension disabled.

## Clear cached images and files

Chrome stores pages and files to load them faster on future visits. If a cached version of a PDF is corrupted or outdated, Chrome keeps serving that broken version.

To clear it:

1. Press `Ctrl+Shift+Delete` on Windows or Linux, or `Cmd+Shift+Delete` on Mac.
2. Set the time range to "All time."
3. Check "Cached images and files." (You can leave cookies unchecked if you'd rather stay logged in everywhere.)
4. Click "Clear data."

After clearing, go back to the PDF and try loading it again. It'll take a moment longer on the first visit since Chrome has to re-download it.

## Test in Incognito mode

Incognito mode disables all extensions by default. If a PDF that fails in your normal window opens fine in Incognito, an extension is causing the problem.

Press `Ctrl+Shift+N` (Windows/Linux) or `Cmd+Shift+N` (Mac) to open an Incognito window, then paste in the PDF link. If it works there, go to `chrome://extensions` and disable your extensions one at a time until you find the one causing the issue.

## Update Chrome

Chrome's PDF renderer gets bug fixes with every release. If you're running an old version, you might be hitting a known problem that's already been patched.

Click the three-dot menu in the top right, then go to Help > About Google Chrome. Chrome checks for updates automatically on that page. If an update is available, install it and restart.

## Turn off hardware acceleration

Some combinations of Chrome versions and graphics drivers cause the PDF viewer to display nothing or crash the tab. Disabling hardware acceleration shifts the rendering work to the CPU, which is slower but avoids the driver compatibility issue.

1. Go to `chrome://settings/system`.
2. Toggle off "Use hardware acceleration when available."
3. Click "Relaunch" to restart Chrome.

Try the PDF again. If it opens now, leave hardware acceleration off, or update your graphics drivers and try turning it back on.

## Reset Chrome to default settings

If you've tried everything above and Chrome still won't cooperate, resetting it to factory defaults can clear whatever broken configuration is causing the problem. This does not delete your bookmarks or saved passwords.

1. Go to `chrome://settings/reset`.
2. Click "Restore settings to their original defaults."
3. Confirm the reset.

After the reset, check that your startup page and search engine settings are still how you want them.

## Check if the PDF file itself is the problem

Everything above assumes Chrome is at fault. But if the same PDF works in another browser and fails only in Chrome, and you've been through the whole list, the file may be corrupted or malformed.

Test it: open the PDF in Microsoft Edge on Windows, or Preview on Mac. If those also show errors or a blank page, the problem is the file, not the browser.

A few ways to recover content from a broken PDF:

- Ask whoever sent it to re-export from the original software. Some tools produce PDFs that don't conform closely to the [ISO 32000 PDF standard](https://www.pdfa.org/resource/iso-32000-pdf/), and browsers are stricter about rejecting those than desktop apps.
- If the PDF partially loads, our [PDF to JPG tool](/pdf-to-jpg) can convert each page to an image so you can at least get the content out.
- If the file is large because it contains scanned pages, our [Compress PDF tool](/compress-pdf) can reduce its size before you try loading it again. This only helps image-heavy files. If your PDF is mostly text, compressing it will make it significantly larger because the compressor rasterizes every page to JPEG.

## Quick checklist

If you want to run through everything fast:

1. Go to `chrome://settings/content/pdfDocuments` and choose "Open PDFs in Chrome."
2. Disable the Adobe Acrobat extension at `chrome://extensions`.
3. Clear cached files with `Ctrl+Shift+Delete` or `Cmd+Shift+Delete`.
4. Open the PDF in an Incognito window to check for extension conflicts.
5. Update Chrome at Help > About Google Chrome.
6. Disable hardware acceleration at `chrome://settings/system`.
7. Reset Chrome settings at `chrome://settings/reset`.

If the PDF still won't open after all of that, the issue is almost certainly with the file rather than Chrome. Re-exporting from the source, or asking the sender for a fresh copy, usually resolves it.
