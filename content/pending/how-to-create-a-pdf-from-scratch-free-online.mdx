The quickest way to create a PDF from scratch for free is to write your document in Google Docs and download it as a PDF in two clicks. No Adobe Acrobat, no subscription, and no new service to sign up for.

That covers most situations. But which method works best depends on what you're building. A typed report is different from a photo collage, which is different from a designed flyer. Below are five reliable options and when to use each one.

## Method 1: Google Docs (free, nothing to install)

Google Docs is the right pick for text-heavy documents: letters, reports, cover letters, contracts, meeting notes, and anything else that's mostly words and tables.

1. Go to [docs.google.com](https://docs.google.com) and open a new blank document. A free Google account is all you need.
2. Write and format your content. Use the toolbar to add headings, bullet lists, tables, or images.
3. Go to **File > Download > PDF Document (.pdf)**.

The file downloads immediately. Google handles the conversion server-side, and the result is a properly formatted PDF. Because PDF follows the [ISO 32000 specification](https://www.iso.org/standard/63534.html), the document renders identically on Windows, Mac, and mobile regardless of what fonts or layouts you used.

If you need to collaborate before exporting, Google Docs lets multiple people edit the same document. Export once everyone's done.

## Method 2: Microsoft Word or LibreOffice

If you have Word installed (or a Microsoft 365 subscription), saving as PDF takes one extra step from a normal save.

1. Write and format your document.
2. Go to **File > Save As**, choose a folder, and set the file type to **PDF**.
3. Click **Save**.

On Windows you can also use **File > Export > Create PDF/XPS**. Both produce the same output. Word preserves fonts, embedded images, and layout exactly as they appear in the document.

No Microsoft subscription? [LibreOffice Writer](https://www.libreoffice.org/) is a free, offline alternative for Windows, Mac, and Linux. Open a blank document, write your content, and use **File > Export as PDF**. The output quality is comparable to Word.

## Method 3: Print to PDF in your browser

Any document or page open in a browser can become a PDF using the built-in print function. No extensions, no third-party tools.

1. Open the content you want to save.
2. Press **Ctrl+P** on Windows or **Cmd+P** on Mac.
3. In the destination dropdown, choose **Save as PDF** (Chrome, Edge, or Firefox) or **Microsoft Print to PDF** (Windows).
4. Set the layout and margins if needed, then click **Save**.

This is built into Chrome, Edge, Firefox, and Safari. It works well for clean documents and spreadsheets. Complex pages with sidebars or heavy CSS sometimes lose formatting, but for Google Sheets, simple web pages, and calendar views the output is clean.

Print to PDF is the fastest method when the content you want already exists somewhere in your browser.

## Method 4: Turn images into a PDF

If your document is made of photos, screenshots, or scanned pages rather than typed text, a word processor isn't the right tool.

The [Images to PDF tool](/jpg-to-pdf) handles this directly: drop in your JPG or PNG files, arrange them in the order you want, and download the PDF. The whole process runs in your browser. Your files never leave your device.

This is the right approach for:
- Phone photos you need to submit as a single document
- Screenshots of receipts, invoices, or reference pages
- Scanned pages you've already saved as image files
- A photo portfolio you want to send as one file

The tool places one image per page. Add as many as you need.

## Method 5: Canva for designed documents

For something more visual than a word-processor document, such as a resume with a custom layout, a flyer, a company one-pager, or an event program, Canva is free and runs in any browser.

1. Go to [canva.com](https://www.canva.com) and start from a blank A4 or US Letter canvas.
2. Add text boxes, images, and graphic elements from the sidebar.
3. Click **Share > Download > PDF Standard** (or **PDF Print** for higher-quality output suitable for printing).

The free plan includes full PDF export. You only need a paid subscription for specific premium template elements, not for the PDF download itself.

## Joining multiple PDFs into one

Sometimes you'll create separate PDFs for different parts of a document and want to combine them at the end. The [Merge PDF tool](/merge-pdf) handles that without any software to install.

Add your files, put them in the order you want, and download the merged PDF. Based on how the tool processes files, the output comes in at roughly the same size as the sum of the parts, so combining them won't push you over an email attachment limit.

One thing to know: merging strips interactive form fields from any PDFs that have them. If you've filled out a form you want to include, flatten it first so the values are embedded into the page as visible content rather than editable fields. The [Flatten PDF tool](/flatten-pdf) does this.

## Which method fits your situation?

| Starting point | Best free method |
|---|---|
| Writing a text document from scratch | Google Docs or Word |
| Converting a LibreOffice document | File > Export as PDF in LibreOffice |
| Saving a webpage or spreadsheet | Print to PDF in your browser |
| Starting from photos or scanned pages | Images to PDF tool |
| Building a designed or visual document | Canva |
| Joining multiple PDFs into one | Merge PDF tool |

Every option above is free. None requires Adobe Acrobat. The method that's fastest for you is whichever one matches what you're starting with.
