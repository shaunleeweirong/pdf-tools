Flattening a PDF without Acrobat takes less than a minute with the right tool. Three free methods work: an in-browser tool, Chrome's print step, and macOS Preview. All three lock form fields and annotations permanently into the page with no paid software, no account, and no subscription.

## What does flattening a PDF actually do?

[PDF form fields and annotations](https://en.wikipedia.org/wiki/PDF#AcroForms) sit in a separate interactive layer on top of the page content. When you flatten a PDF, those layers get merged into the page itself. A text field becomes a picture of the text you typed. A checkbox becomes a drawn mark. Hyperlinks stay visible but become ordinary text.

After flattening, the file opens the same way in any viewer, but nothing can be clicked, filled in, or changed.

## When should you flatten a PDF?

A few situations call for it:

- **Filing forms electronically.** Many court systems and government portals require flattened PDFs. The US Courts' [CM/ECF e-filing system](https://www.uscourts.gov/court-records/electronic-filing-cmecf) requires flattened documents because interactive layers can render unpredictably in document viewers.
- **Sending a filled form to someone.** Flattening prevents the recipient from editing the values you entered.
- **Merging a filled form with other documents.** This one catches people off guard (more on it below).
- **Archiving.** The [PDF/A standard](https://www.pdfa.org/pdfa-faq/) for long-term archiving requires self-contained files with no interactive elements.

## Method 1: Flatten PDF tool (runs in your browser)

The [Flatten PDF tool](/flatten-pdf) handles form fields and annotations. Everything runs in your browser, so the file never leaves your device.

1. Go to the [Flatten PDF tool](/flatten-pdf).
2. Click **Choose file** and pick your PDF, or drag it in.
3. The tool processes the file and shows a download link.
4. Click **Download** to save the flattened version.

Done. Open the downloaded file and you'll see the same content, but every form field is now static.

## Method 2: Chrome's print-to-PDF

Google Chrome can flatten any PDF as a side effect of printing it to a new PDF file. This works on Windows, Mac, and Linux.

1. Drag your PDF into a Chrome tab, or use **File > Open File**.
2. Press **Ctrl+P** on Windows/Linux, or **Cmd+P** on Mac.
3. Set the destination to **Save as PDF**.
4. Click **Save** and give the file a name.

Chrome renders the page at screen resolution and saves the result. Form fields, annotations, and interactive layers don't carry over. The output is a clean, static PDF.

One trade-off: Chrome re-renders at screen resolution, which can slightly soften text at very high zoom. For most documents this is unnoticeable. For print-quality files or detailed graphics, Method 1 keeps the page content intact without re-rendering.

## Method 3: macOS Preview

On a Mac, Preview gives you the same result through the print dialog.

1. Open your PDF in Preview.
2. Press **Cmd+P** to open the print dialog.
3. Click the **PDF** dropdown in the bottom-left corner.
4. Select **Save as PDF** and choose a location.

Preview flattens the file the same way Chrome does. The annotations and fields are gone, and the page content is unchanged. This is the fastest option if you're already on a Mac and your PDF is already open in Preview.

## The merge problem: why flattening first matters

Merging PDFs is a common step when you're putting together an application packet or a report. But there's a catch with filled forms.

When you merge a PDF that has interactive form fields, the fields disappear. It's not a rendering glitch. The values you typed are stored in the AcroForm layer, and merging copies page geometry but not the form data. In our own testing, a document with one filled text field had zero fields after merging:

```
fields BEFORE merge: [ 'applicant.name' ]
fields AFTER merge : []
```

The fix is simple. Flatten the form first, then merge. Flattening paints your typed values permanently onto the page as text, so they survive the merge. The workflow is:

1. Fill out the form.
2. Flatten it with the [Flatten PDF tool](/flatten-pdf).
3. Then combine it with other files using [Merge PDF](/merge-pdf).

## Is this the same as compressing or password-protecting a PDF?

Not quite. These are three different things and they're often confused.

**Flatten** removes interactivity by merging layers into the page. The file has no password. Anyone can open and read it. The content just can't be modified.

**Compress** reduces file size, usually by re-encoding images at lower quality. Our compress tool rasterizes every page to JPEG, which shrinks image-heavy PDFs but makes text-only PDFs significantly larger. Compressing doesn't remove form fields.

**Password protect** prevents someone from opening the file without a password (using our [Protect PDF tool](/protect-pdf)). It doesn't flatten anything. If someone has the password, the fields may still be editable depending on the permission settings.

For handing off a finalized document where the reader should see content but not change it, flattening is the right step.

## Save your original before flattening

Flattening isn't reversible through the same tool. Once form fields are baked into the page, there's no way to extract them again. If you open the flattened file in any PDF editor, you'll see static text, not a field you can click.

Get in the habit of keeping the unflatted version with a clear filename. Something like `contract-filled.pdf` for the working copy and `contract-final.pdf` for the flattened version works well. That way you can always go back and change a value in the original if needed.

The whole process takes about 30 seconds, and all three methods above are free.
