Converting a TIFF file to PDF is free on any computer, and the built-in tools on Mac and Windows do it better than most online converters. Below are the fastest methods, starting with the ones that don't require uploading your file anywhere.

## What is a TIFF file, and why convert it to PDF?

[TIFF](https://en.wikipedia.org/wiki/TIFF) (Tagged Image File Format) stores image data losslessly. Every pixel is preserved exactly as captured, which is why scanners default to it for document digitization, photographers use it for archiving, and print shops request it when they need the cleanest possible source file.

The problem: TIFF files are large. A single scanned page at 300 dpi can run anywhere from 5 MB to 25 MB, and a multi-page scanned document gets unwieldy fast. Most email providers cap attachments at 25 MB, and many upload forms won't accept TIFF at all.

PDF solves this. It's universally readable on every device and operating system, compresses image data more efficiently for most documents, and handles multi-page files with ease. When the goal shifts from "preserve the original" to "share or submit this file," PDF is the right format.

## Convert TIFF to PDF on Mac (Preview, built-in)

Mac ships with Preview, and Preview opens TIFF files directly. Nothing to download, no sign-in, and the whole process takes about ten seconds.

1. Double-click your TIFF file to open it in Preview.
2. Go to **File** > **Export as PDF**.
3. Give the file a name, choose a save location, and click **Save**.

That's the entire process. Preview also handles multi-page TIFFs without any extra steps. Every page in the original TIFF ends up in the PDF, in order.

The conversion is lossless: Preview embeds the image data in the PDF container without re-encoding it. The resulting PDF may be slightly larger than the original TIFF because of container overhead, but you won't see any visual difference.

## Convert TIFF to PDF on Windows (Microsoft Print to PDF)

Windows 10 and Windows 11 include a built-in virtual printer called Microsoft Print to PDF. It converts anything you can print into a PDF, including TIFF images.

1. Open your TIFF file in Windows Photos (double-click it in File Explorer).
2. Press **Ctrl + P** to open the print dialog.
3. Under **Printer**, select **Microsoft Print to PDF**.
4. Click **Print**, enter a file name, and click **Save**.

Windows Photos handles multi-page TIFFs the same way: all pages come through into the PDF. The result is lossless, just like the Mac method.

If Microsoft Print to PDF doesn't appear in your printer list, you can add it through **Settings** > **Bluetooth & devices** > **Printers & scanners** > **Add a printer or scanner**.

## Combine multiple TIFF files into one PDF

If you have several separate TIFF files and want them in a single PDF, the cleanest free approach is a two-step process:

1. Convert each TIFF to a PDF individually using the method above (Preview on Mac, or Microsoft Print to PDF on Windows).
2. Use the free [Merge PDF tool](/merge-pdf) to combine the separate PDFs into one document.

This approach gives you full control over the page order and works on any device. The merge step is fast: our tool joins files in the browser, and the output doesn't get larger than the sum of its parts.

## Convert TIFF to PDF in your browser

If you're on a Chromebook, tablet, or phone without Preview or Print to PDF, browser-based converters are the fallback. Your file goes to an external server for processing, so avoid this route for confidential documents.

One alternative that keeps your file local: if you can open your TIFF in any image editor and save it as a JPG or PNG, you can use our [Images to PDF tool](/jpg-to-pdf). It runs entirely in your browser and processes files without uploading them. Drop in your JPG or PNG images, arrange the pages, and download the PDF.

The tradeoff: [JPEG compression](https://en.wikipedia.org/wiki/JPEG) is lossy. Saving a TIFF as JPG throws away some image data permanently, which isn't ideal for archiving or anything where you need the original fidelity. For typical use cases like sharing a scanned document by email, the quality loss is not noticeable at normal viewing sizes. But if you're converting a high-resolution print file or an archival scan, stick with a lossless method.

## A note on file size after conversion

You might expect the PDF to be smaller than the TIFF, since PDF is described as a more efficient format. That's not always true.

For a single-page photographic image, the TIFF and the PDF are often similar in size. The efficiency gains from PDF come mostly from handling text and vector graphics, not from compressing images more aggressively. A lossless conversion of a TIFF to PDF swaps one container for another without removing image data, so the file size stays in the same range.

If you genuinely need to shrink the file, the options are to use JPEG compression when making the PDF (at the cost of some image quality), or to accept that a lossless format will carry most of the original data. For document scans that are purely image-based, that's the honest reality.
