## Compress PDF in Chrome: what actually works

You can compress a PDF for free directly inside Chrome, with no software to install and no sign-up required. The catch: Chrome itself has no compression button. [Chrome's built-in PDF viewer](https://support.google.com/chrome/answer/6213030) handles opening, scrolling, filling forms, and printing, but size reduction isn't part of it.

The solution is a browser-based tool like the [Compress PDF tool](/compress-pdf). It runs entirely inside your Chrome tab using the same JavaScript engine Chrome uses for everything else. Your file stays on your device and the whole thing takes about a minute.

## How to compress a PDF in Chrome (step by step)

1. Open a new Chrome tab and go to [/compress-pdf](/compress-pdf).
2. Click the upload area or drag your PDF file into it.
3. Choose a compression level. Medium is a good starting point for most image-heavy files.
4. Wait for the compression to finish. For a 6-page image deck this typically takes under two seconds in a modern browser.
5. Click Download to save the compressed file.

That's the whole process. No account, no watermark, no file size limit that requires a paid plan.

## When compression actually shrinks your file

This matters a lot, so don't skip it.

The compressor works by rasterizing each page of your PDF to a JPEG image. That's great news if your pages are already images, such as a scanned document, a photo deck, or a slide presentation exported as a PDF. In those cases, you can see dramatic size reductions.

Measured on a 6-page image deck:

| Compression level | Before | After | Reduction |
|---|---|---|---|
| Low (best quality) | 913.4 KB | 703.5 KB | 23.0% |
| Medium | 913.4 KB | 315.3 KB | 65.5% |
| High (smallest) | 913.4 KB | 175.6 KB | 80.8% |

These numbers come from actual measurements on the running tool, not marketing estimates.

The reverse is true for text-heavy PDFs. A 20-page text report measured at 23.5 KB grew to 1.4 MB after compression at the Medium setting. That's nearly 60 times larger. The reason is that PDFs store text as tiny vector instructions, and rasterizing them to photos uses far more bytes. Never compress a text document, a contract, an invoice, or a form if you want it to get smaller.

## What about the "Print to PDF" trick?

Some people try opening a PDF in Chrome and then using File > Print > Save as PDF. This sometimes reduces the size of web pages saved as PDFs, but it rarely helps (and often hurts) when you start with an existing PDF file. Chrome's print pipeline renders each page at screen resolution and re-encodes it, which tends to produce a file of similar or larger size than the original. It's also a lossy one-way conversion, so you lose document structure like selectable text and hyperlinks.

For actual compression, use the dedicated tool above.

## What if I don't want to upload my file?

You don't have to. The [Compress PDF tool](/compress-pdf) processes everything client-side, which means your file is never uploaded anywhere. The compression happens inside your browser tab. This is different from most Google search results on this topic, which point to services that transfer your file to a server in the cloud.

If you're compressing a document with personal information, bank statements, medical records, or anything else you'd rather keep private, this matters.

## Chrome extensions: are they worth it?

Several Chrome extensions promise PDF compression. A few caveats worth knowing before you install one:

- Most extensions that compress PDFs send your file to an external server. Check the extension's privacy policy if that matters to you.
- Extensions add a permanent presence to your browser and need to be kept updated.
- A web-based tool requires nothing installed, so there's nothing to uninstall or update.

For occasional compression, a browser tool is simpler than an extension. If you compress PDFs many times a day, an extension might fit your workflow better.

## My PDF is still too big after compression

If compression didn't help enough (or made the file bigger because it's mostly text), here are a few other approaches:

- **Reduce the page count.** Removing unnecessary pages before sharing is the most reliable way to shrink a PDF. Use the [Delete Pages tool](/delete-pages) to remove any pages that don't need to be there.
- **Split the PDF.** If you need to send a large PDF via email but can split it into sections, the [Split PDF tool](/split-pdf) lets you do that in the same browser tab.
- **Check what's making it large.** PDFs can be large for several reasons: embedded fonts, high-resolution images baked in during export, hidden revision layers, or attached files. If your PDF is text-only and already small by any reasonable measure but still flagged as too large by a submission form, the limit is usually more restrictive than you think. [Gmail](https://support.google.com/mail/answer/6584) and Outlook both cap attachments at 25 MB, and encoding adds roughly a third on top of the raw file size, so the practical limit for an emailed PDF is around 18 MB.

## Compressing twice doesn't help

One common mistake is running the same PDF through compression a second time, hoping to squeeze out more size. It doesn't work. Running the Medium-compressed output back through compression at the same level nearly doubled the size in testing (from 315.3 KB to 598.9 KB). The JPEG images inside the PDF have already been encoded once, and re-encoding them at the same quality adds data rather than removing it.

If Medium compression isn't enough, start again from the original file and choose High instead. Don't chain multiple passes.

## Summary

Chrome doesn't compress PDFs on its own. The fastest free option is to open a browser-based tool directly in Chrome, drag your file in, pick a compression level, and download. It works well for scanned documents and image-heavy PDFs. For text-only PDFs, skip the compressor and try removing pages or splitting the file instead.
