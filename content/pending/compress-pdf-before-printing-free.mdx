Compressing a PDF before printing makes sense in some situations and actively hurts in others. The short answer: if you're printing directly from your own computer, you almost never need to compress first. If you're sending a large image-heavy PDF to a print shop or uploading it somewhere with a file size limit, compression can help. If the PDF is mostly text, skip compression entirely.

## Why most printers don't care about file size

A printer connected to your computer accepts [PDF](https://en.wikipedia.org/wiki/PDF) data the same way it accepts any other document. There's no practical file size limit for a local print job. A 200 MB PDF prints fine from your MacBook to a desktop printer.

The situations where size actually matters are file transfers: emailing a PDF to a print shop, uploading to an online print service, or sending it through a system with an attachment limit. In those cases, a smaller file moves faster and avoids rejection.

## The test that determines everything

Before you reach for a compression tool, open the PDF and try to select a line of text with your cursor.

- **The text highlights and you can copy it.** The file is a native text document (exported from Word, Google Docs, PowerPoint, or a similar app). Compression will make it bigger, not smaller. Skip it.
- **Nothing highlights, or the whole page selects as one block.** The file is scanned pages or photographic images. Compression will help significantly.

This matters because most free compression tools, including the [Compress PDF tool](/compress-pdf), work by rasterizing: each page is redrawn as a JPEG image. When the page is already a photograph, that process strips away redundant data. When the page is text stored as vector glyphs, replacing it with a JPEG of that text turns a tiny file into a large one.

## What the numbers actually show

We ran three different documents through our compressor in a real browser and recorded the exact output sizes. Here's what we found:

| Document type | Level | Before | After | Change |
|---|---|---|---|---|
| 6-page image deck | High | 913.4 KB | 175.6 KB | 81% smaller |
| 6-page image deck | Medium | 913.4 KB | 315.3 KB | 66% smaller |
| 6-page image deck | Low | 913.4 KB | 703.5 KB | 23% smaller |
| 20-page text report | Medium | 23.5 KB | 1400.8 KB | 60x bigger |
| Text with small logo | Medium | 35.0 KB | 171.2 KB | 5x bigger |

The image deck shrank by two thirds at Medium and by over 80% at High. The text report grew from 23.5 KB to 1.4 MB. That's not a rounding error. It reflects the fundamental difference between how PDF stores text (as vector font instructions) versus how JPEG stores anything (as a pixel grid).

## When compressing before printing makes sense

There are three legitimate scenarios.

**Sending to a print shop.** Many print shops accept files by email or through a web portal, and those channels have size limits. If your document is an image deck or a scanned manual, compressing before you send reduces upload time and avoids bounced emails. Use Medium as a starting point. If you need the sharpest possible output (large format printing, photography books), talk to your printer first and ask whether they'd prefer the original file on a cloud link.

**Uploading to an online print service.** Services like Vistaprint, Moo, or local copy shop portals often cap uploads at 20 MB to 50 MB. Image-heavy files can exceed that. Medium compression usually brings them under any reasonable limit without obvious visual loss on standard paper sizes.

**Casual home printing of a large photo PDF.** If you have a 50-page PDF full of photos you want to print on your home inkjet at standard A4 or letter, Medium compression can make the file easier to work with and doesn't noticeably affect output quality on typical home printers, which top out at 600 DPI anyway.

## When to skip compression

For most everyday printing, you're better off leaving the file alone.

**Text documents.** Contracts, reports, invoices, forms, and anything you can copy text out of will get larger, not smaller, after in-browser compression. If a text PDF is unusually large, the culprit is usually embedded fonts, revision history, or an oversized logo. Those don't shrink through compression.

**Professional print work.** Commercial printers for books, brochures, and marketing materials need high-resolution images, typically [300 DPI or more](https://www.prepressure.com/prepress/technique/resolution). Compressing to a lower DPI before sending will visibly degrade the printed result. Send the original and let the print shop handle the rest.

**When you don't actually need to transfer the file.** If you're just printing from your own computer, there's nothing to gain. Open the PDF, press print, and let the driver handle it.

## How to compress a PDF before printing (step by step)

1. Confirm the PDF is image-heavy (try selecting text, as above).
2. Open the [free Compress PDF tool](/compress-pdf).
3. Drop your file in or click to browse.
4. Choose a level. Medium is the right default for most purposes. High squeezes more but softens fine detail, which can matter on small print in scanned documents.
5. Click Compress and download the result.
6. Check the output size before sending. If it's still over a limit, try High. If it was already a text document and you compressed by mistake, go back to the original.

One thing worth knowing: don't run the same file through twice hoping to squeeze out more. A second pass at Medium nearly doubles the file size again. If Medium wasn't enough, start from the original and choose High.

## What to do if the PDF is text-heavy but still too large

If the file is a text document and you need to get it under a size limit, a few approaches actually work.

**Split it.** Use the [Split PDF tool](/split-pdf) to break the document into smaller chunks and send them separately. This is the most reliable option for a document going to a print shop.

**Print page ranges.** If the goal is printing, not transferring, you don't need to compress at all. Most PDF viewers let you print a range of pages (for example, 1 to 50, then 51 to 100) to avoid memory or timeout issues on older printers.

**Fix the actual cause.** Re-exporting from the original application (Word, Google Docs, InDesign) with optimized settings often produces a file smaller than the compressed version. Google Docs' built-in PDF export, for example, produces compact output by default.

## A note on print quality and DPI

[DPI (dots per inch)](https://en.wikipedia.org/wiki/Dots_per_inch) is what determines sharpness on paper. For home printing on A4 or letter at standard sizes, images at 150 DPI look fine. For professional results, you want 300 DPI. Our Medium compression keeps images at a resolution that prints well on a standard home or office printer. High compression reduces resolution further and is better suited to files that will be read on screen or printed at small sizes.

If you print a compressed PDF and it looks pixelated or blurry, the compression was too aggressive for that document. Go back to the original and either print it directly or use a lower compression level.
