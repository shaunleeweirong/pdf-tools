You can read a PDF aloud free online without installing new software in most cases. Microsoft Edge handles it natively with one right-click, and macOS and iOS both have built-in accessibility features that do the same. Below is every free method, organized by platform, plus what to do when a PDF refuses to speak.

## How to read a PDF aloud in Microsoft Edge

Edge is the easiest option for Windows users because it comes pre-installed and handles PDFs directly. Open your PDF in Edge, right-click anywhere on the page, and select "Read Aloud." A small toolbar appears with play, pause, speed, and voice controls.

The keyboard shortcut is Ctrl + Shift + U on Windows. On Mac, Edge supports the same feature under the same right-click menu.

Edge lets you swap voices and increase playback speed from 0.5x to 3x inside the Read Aloud settings panel. Windows 11 includes higher-quality "natural" voices in System Settings under Time and Language > Speech. This feature is part of [Microsoft's Immersive Reader](https://support.microsoft.com/en-us/topic/use-immersive-reader-in-microsoft-edge-78a7a17d-52e1-47ee-b0ac-eff8539015e1), available across Edge on Windows and macOS.

If Edge highlights each word as it reads, that's intentional. You can click any sentence to jump to that point.

## How to read a PDF aloud in Chrome

Chrome has no built-in read-aloud for PDFs, so you'll need one of two approaches.

**Option 1: Install Natural Reader.** The free [Natural Reader extension](https://www.naturalreaders.com/extensions/) adds a floating play button to Chrome. Open your PDF in Chrome's built-in viewer, click the Natural Reader icon in the toolbar, and it starts reading. The free tier covers most everyday documents with several voice options.

**Option 2: Copy and paste into a TTS site.** Open your PDF in Chrome, select the text (Ctrl + A selects all), copy it, then paste into a text-to-speech site. This works with any browser and needs no extension. The downside is that complex layouts, such as multi-column documents, often paste in the wrong reading order.

## How to read a PDF aloud on Mac

macOS includes speech tools that work with PDFs in Preview, the default Mac reader.

Select the text you want to hear in Preview, then go to Edit > Speech > Start Speaking. To read the whole document without selecting anything, use VoiceOver instead. Turn it on under System Settings > Accessibility > VoiceOver, open your PDF, and press VO + A (Control + Option + A) to read the current area. VoiceOver moves through the document automatically.

For shorter reads, the fastest shortcut is to select text and press Option + Esc. On recent macOS versions, you can also set up System Settings > Accessibility > Spoken Content > Speak Selection to trigger on a key combo you define.

## How to read a PDF aloud on iPhone

Apple's Speak Screen feature works across all apps, including PDF viewers.

1. Go to Settings > Accessibility > Spoken Content.
2. Turn on Speak Screen.
3. Open your PDF in the Files app, Safari, or any PDF reader.
4. Swipe down from the top of the screen with two fingers.

A controller bar appears at the top and reading begins. Use the tortoise and hare buttons to change speed, and the skip buttons to move between sections. You can pause by tapping the controller.

If you want more control, turn on Speak Selection in the same menu. This lets you tap and hold text to select it, then tap Speak from the popup.

## How to read a PDF aloud on Android

Android's approach varies by manufacturer, but the [Select to Speak](https://support.google.com/accessibility/android/answer/7349565) accessibility feature is available on most devices running Android 5 or later.

Enable it under Settings > Accessibility > Select to Speak. Once on, you'll see an accessibility shortcut button. Tap it, then tap or drag across the PDF text you want to hear.

For longer documents, Google Play Books works well. Add a PDF to your Play Books library (via the Play Books app > Upload button), then open it and tap the headphones icon to start reading. Play Books keeps your position between sessions and supports chapter-level navigation.

## Why some PDFs won't read aloud

If read-aloud produces nothing, reads random characters, or speaks symbols and junk, the PDF is almost certainly image-based. This happens with scanned documents, photocopies, and PDFs created from screenshots. The file stores every page as a raster image, and there's no text layer for a TTS engine to find.

The fix is OCR (optical character recognition). [Google Drive includes free OCR](https://support.google.com/drive/answer/176692): upload the PDF to Drive, right-click it, and choose Open with Google Docs. Google extracts the text from each page and places it in a Docs file. From there, you can paste the text into Edge or a TTS site, or let Edge read the Docs page directly.

For the PDF purists who want to keep the original layout, paid tools like Adobe Acrobat can embed a text layer while preserving the visual appearance. Free alternatives exist but often produce less accurate results on complex layouts.

Note: our [PDF to JPG tool](/pdf-to-jpg) lets you export each page as an image if you need to send individual pages to a desktop OCR program that only accepts image formats.

## What to do with large or slow PDFs

Very large PDFs, especially ones full of scanned pages or photos, can take a long time to load in a browser before read-aloud starts. If you're dealing with a file that's several hundred megabytes or larger, try the [Compress PDF tool](/compress-pdf) first to reduce the file size.

Keep in mind that compression works well on image-heavy files but will make text-only PDFs larger, not smaller, because the tool rasterizes pages. A 6-page image deck can drop from 913 KB to around 175 KB at the highest compression setting. A text document, by contrast, would grow significantly. Use compression only on scanned documents or photo-heavy files.

Once the file is smaller, Edge and most extensions load it faster, and read-aloud playback tends to start more quickly.

## Which method to choose

For Windows users, Edge is the clear first choice: already installed, zero configuration, and handles most PDFs reliably. Mac users get equivalent convenience through Preview or VoiceOver. On mobile, Speak Screen (iPhone) and Select to Speak (Android) cover short reads, while Play Books handles longer documents.

If your PDF is scanned and contains no real text layer, start with Google Drive's OCR before trying any read-aloud tool. That single step fixes most "won't read" problems.
