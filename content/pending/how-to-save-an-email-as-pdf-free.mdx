You can save any email as a PDF for free without installing anything. The method is the same across Gmail, Outlook, Yahoo, and most other email services: use the browser or app's built-in print function and direct the output to a PDF file instead of a printer. Here's how to do it on every major platform.

## How to save a Gmail email as PDF

1. Open the email in Gmail (web browser).
2. Click the **three-dot menu** at the top right of the message (next to the reply arrow).
3. Choose **Print**.
4. In the print dialog, click the **Destination** dropdown and select **Save as PDF**.
5. Click **Save**, choose a folder, and you're done.

If you're on a Chromebook or any device using the Chrome browser, you'll see the same Save as PDF option in the Destination list. [Google's own help page confirms this is built in](https://support.google.com/mail/answer/8465) and requires no extension.

## How to save an Outlook email as PDF on Windows

1. Open the email in Outlook.
2. Go to **File**, then click **Print** (or press Ctrl+P).
3. Under Printer, select **Microsoft Print to PDF**.
4. Click **Print**.
5. A Save As dialog will appear. Name the file and choose where to save it.

Microsoft Print to PDF is built into Windows 10 and 11. If you don't see it in the printer list, you can add it through Windows Settings under Printers and Scanners.

One thing to know: this method captures the message body only. Attachments are not embedded in the output PDF. If you need to include them, download the attachments separately and use the [Merge PDF tool](/merge-pdf) to combine everything into one document afterward.

## How to save an Outlook email as PDF on Mac

1. Open the email in Outlook for Mac.
2. Go to **File**, then **Print** (or press Cmd+P).
3. At the bottom left of the print dialog, click the **PDF** dropdown.
4. Choose **Save as PDF**.
5. Name the file and click **Save**.

The same steps apply to Apple Mail on Mac, so you can use this to save any email your Mail app can open.

## How to save an email as PDF on iPhone

The trick here isn't obvious, but it works in any email app including Gmail and Mail.

1. Open the email.
2. Tap the **share icon** (the square with an arrow pointing up).
3. Tap **Print**.
4. On the print preview screen, **pinch outward** on the small document thumbnail. This expands it into a full-screen PDF preview.
5. Tap the **share icon** again (now at the top right of the PDF preview).
6. Choose **Save to Files** and pick a folder.

[Apple's documentation covers this pinch-to-PDF trick for iOS](https://support.apple.com/en-us/111774). It works without any extra app and saves a clean PDF of the email body to your Files app.

## How to save an email as PDF on Android

In the Gmail app on Android:

1. Open the email.
2. Tap the **three-dot menu** at the top right.
3. Tap **Print**.
4. In the print dialog, tap the printer dropdown and select **Save as PDF**.
5. Tap the **PDF icon** (a blue download button) to save the file.

The file saves to your Downloads folder by default. Other Android email apps may label it differently (Share, More, or a printer icon), but the flow is the same: find the print option, redirect it to Save as PDF.

## How to save a Yahoo Mail or other web-based email as PDF

The steps are identical to Gmail in a browser:

1. Open the email.
2. Press **Ctrl+P** on Windows or **Cmd+P** on Mac to open the print dialog.
3. Set the Destination or printer to **Save as PDF**.
4. Click **Save**.

This keyboard shortcut works in any web browser, regardless of which email service you're using.

## What's included (and what isn't) in a saved email PDF

The print-to-PDF method captures:

- The email header (From, To, Subject, Date)
- The full message body, including any formatting and inline images
- Quoted replies if they're expanded in the thread view

It does NOT capture:

- File attachments (those are separate downloads)
- Email metadata like message IDs or routing headers
- Other emails in a thread if they're collapsed

If you need attachments and the email together, save them separately and merge them with the [Merge PDF tool](/merge-pdf). It runs in your browser and handles the combining without re-uploading or quality loss.

## How to combine multiple emails into one PDF

There's no built-in way to print a whole email thread or multiple emails into a single PDF in most clients. The workaround:

1. Save each email as its own PDF using the steps above.
2. Open the [Merge PDF tool](/merge-pdf).
3. Drop in all the separate PDF files and reorder them if needed.
4. Click Merge and download the combined file.

This is useful for archiving a conversation, compiling correspondence for a legal or HR file, or bundling a multi-email receipt thread into one document.

## What to do if the saved PDF is too large

Emails with a lot of inline images, company logos, or marketing graphics can produce surprisingly large PDFs. If the file is too big to attach to an email or upload somewhere, the [Compress PDF tool](/compress-pdf) can reduce the size. It works best on image-heavy files, which is exactly what an email PDF tends to be. Keep in mind that compressing a PDF made from text alone won't help and may actually make it larger, since the tool rasterizes pages to JPEG internally.
