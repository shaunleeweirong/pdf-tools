You can highlight text in a PDF for free right now, without downloading anything, if you have Chrome or Edge installed. Open your PDF in the browser, select some text, and a small annotation bar appears. That's it for most people.

The rest of this guide covers the options for each platform, what to do if highlighting is greyed out, and how to handle scanned PDFs where standard highlighting won't work.

## Highlight a PDF in Chrome or Microsoft Edge (Windows, Mac, Chromebook)

Both Chrome and Edge have built-in PDF annotation tools. You don't need to install anything extra.

**In Chrome:**

1. Open Chrome and drag your PDF file into a new tab (or go to File > Open).
2. Select text by clicking and dragging over it.
3. A small toolbar pops up with a Highlight option. Click it.
4. To change colors or add notes, right-click the highlighted text.
5. To save: press Ctrl+P (Cmd+P on Mac), choose "Save as PDF" as the destination, and click Save.

Chrome saves the highlighted version as a new file with the annotations baked in.

**In Microsoft Edge:**

Edge has a more capable annotation panel. Click the pen icon in the PDF toolbar to open markup mode, then select your highlight color and drag over text. Edge supports yellow, green, pink, and blue highlights. Save with Ctrl+S or use print-to-PDF for a flattened copy.

[Microsoft's documentation on PDF markup in Edge](https://support.microsoft.com/en-us/microsoft-edge/annotate-pdfs-in-microsoft-edge-f1b83e77-e0e8-4a30-8b7c-3c7c8c87b4f8) covers the full toolbar.

## Highlight a PDF on Mac using Preview

[Preview](https://support.apple.com/guide/preview/annotate-a-pdf-prvw11580/mac) is Apple's free built-in PDF viewer and it handles highlighting better than most dedicated apps.

1. Double-click any PDF to open it in Preview (it's the default on Mac).
2. Click the Markup toolbar button (the pencil icon in the top-right) or press Cmd+Shift+H.
3. Click the Highlight Text button (the "A" with a colored bar underneath) or press Shift+Cmd+H.
4. Drag over the text you want to highlight.
5. To change colors: right-click a highlight and choose a color from the menu.

Your highlights save automatically. Preview keeps them as annotation objects, so you can move or delete them later.

## Highlight a PDF on Windows for free without Edge

If you prefer not to use Edge, the next best no-cost option is [Adobe Acrobat Reader](https://get.adobe.com/reader/). The free Reader (not Acrobat Pro) supports text highlighting in multiple colors, sticky notes, and underlines.

1. Download and install Acrobat Reader (free, no subscription needed for basic annotation).
2. Open your PDF.
3. Press Ctrl+Shift+H or click the highlighter in the toolbar.
4. Drag over text to highlight. Right-click a highlight to change its color.
5. Save with Ctrl+S.

The distinction between Reader and Pro matters here: Reader is free and handles highlighting fine. Pro is a paid subscription that adds OCR, editing, and form creation. Don't pay for Pro just to highlight.

## Highlight a PDF online without signing up

If you're on a shared computer or just want a quick one-off annotation, the Chrome and Edge methods above count as "online" since nothing installs. But if you specifically need an in-browser tool:

- **PDF.js Express** (by the same team behind Mozilla's PDF viewer) offers basic annotation in-browser with no account.
- Most other online highlighters (Smallpdf, iLovePDF, etc.) require an account for saving annotated files.

The browser-native options are genuinely the best zero-signup path.

## Why can't I highlight text in my PDF?

This is the most common frustration with PDF annotation. There are two main causes.

**1. The PDF is a scanned image**

Scanned documents look like PDFs but are really photos of pages. There's no actual text for the highlighter to select. You can test this quickly: try to click and drag to select a single word. If a selection box appears but doesn't pick out individual words, you're dealing with a scan.

The fix is OCR (optical character recognition), which converts the image into real text. [Google Drive has a free OCR option](https://support.google.com/drive/answer/176692): upload the PDF, right-click it, choose "Open with Google Docs", and Drive will extract the text. You can then export it back to PDF. It's not perfect, especially on complex layouts, but it works for most text-heavy scans.

**2. The PDF is locked against annotation**

Some documents are protected with permissions that prevent highlighting, even if you know the open password. This is a separate layer of [PDF permission security](https://en.wikipedia.org/wiki/PDF#Security_and_signatures), distinct from the password needed to open the file.

If the PDF lets you view and select text but the annotation tools are greyed out, this is likely the reason. A quick workaround that often works: open the file in Chrome, press Ctrl+P (Cmd+P on Mac), and print it to PDF. The exported copy is a new document without the original permission flags, so you can annotate it normally. ## How to add a note or annotation instead of a highlight

Sometimes you want to comment on text rather than just color it. Both Chrome and Edge let you add text notes by right-clicking any text and choosing "Add note" or similar. In Preview, use the Note tool in the Markup toolbar.

If you need to add a text box directly on the PDF page (rather than a floating note), our [Edit PDF tool](/edit-pdf) lets you type directly onto any page in your browser. It's useful when you want the annotation to sit next to specific content, or when the PDF viewer's note tool doesn't position where you need it.

## Which method should I use?

If you have a Mac: use Preview. It's the most capable free option.

If you're on Windows: open the PDF in Edge for quick highlighting. Install Acrobat Reader if you annotate PDFs regularly.

If you're on a Chromebook or any device with Chrome: the built-in Chrome annotation is enough for most use cases.

Only go to an online tool if you need a feature the browser doesn't cover. For locked PDFs, unlock them first. For scanned PDFs, run OCR first (free via Google Drive). Everything else is just selecting text and clicking a button.
