Merging PDFs in Microsoft Edge comes down to one fact: Edge itself can't do it. The browser's built-in PDF viewer is good for reading, highlighting, and printing, but combining multiple PDFs into one file requires a free online tool you can open in any Edge tab.

## Does Edge have a built-in PDF merge feature?

No. Microsoft Edge's PDF reader has grown into a solid viewer over the years. You can read PDFs, add comments, highlight text, draw, fill in forms, and print. What it doesn't have is any way to take two or more separate PDFs and stitch them into a single file.

The [Microsoft Edge PDF documentation](https://learn.microsoft.com/en-us/deployedge/microsoft-edge-pdf) covers the full set of built-in features. Merging isn't among them.

That's not unusual. Browsers are designed to display documents, not assemble them. Chrome and Firefox have the same gap.

## The fastest free method: an online tool in an Edge tab

The cleanest approach is to open a free browser-based tool right inside Edge. No download, no account required. Here's how to do it with the [Merge PDF tool](/merge-pdf):

1. Open the [Merge PDF](/merge-pdf) page in Microsoft Edge.
2. Click "Choose files" or drag your PDFs directly onto the drop zone.
3. Drag the file cards to set the order you want in the merged document.
4. Click "Merge PDF."
5. Download the combined file.

The whole process takes under a minute for most documents.

One thing worth knowing: merging doesn't inflate the output. In measured tests, three files totalling 971.9 KB merged to 970.5 KB, a drop of 0.1%. If you're worried a merge will push a combined document over a size limit, that's not how it works.

## What about the "Print to PDF" workaround?

You'll find guides suggesting you open each PDF in Edge, use File > Print, choose "Microsoft Print to PDF" as the printer, and somehow append the results. The idea is that you'll end up with a combined file.

In practice, this is awkward. The standard Windows print dialog has no append option. You're really just printing one file at a time to separate PDFs. Some third-party virtual printers add append support, but those require a separate install, which defeats the point.

For most people, the online-tool approach above is faster and produces a proper merged file in one step.

## Edge extensions for PDF merging

The [Microsoft Edge Add-ons store](https://microsoftedge.microsoft.com/addons/Microsoft-Edge-Extensions-Home) has several PDF merge extensions. A few are genuinely free; many cap how many files you can process without signing up or paying.

Before installing any extension, check its reviews and what permissions it requests. An extension that uploads your PDFs to a remote server is a different situation from one that works locally. If privacy matters, an extension that sends files to a third-party cloud is worth a second look.

## What to do if your PDF has form fields

If one of the PDFs you want to merge contains a form with data filled in, flatten it first. Merging a PDF with active form fields removes those fields from the output. In tests, a document with one named text field ("applicant.name", value "Jane") came out of the merge with zero fields, though page content survived.

To preserve the filled-in values, flatten the form before merging. The [Flatten PDF tool](/flatten-pdf) bakes the values into the page so they can't be lost in a subsequent operation. Then run the merge.

This matters most for job applications, contracts, government forms, or any document where someone filled in data that needs to be readable in the final combined file.

## Merging PDFs with different page sizes

Your files don't all need to be the same page size to be merged. An A4 document and a letter-size document can go into the same merged file. Each page keeps its own dimensions; PDF readers adjust per page when displaying the result. If everything needs to match a single size, you'd need to resize pages before merging, but for most everyday cases the mixed sizes work fine.

## Pulling specific pages before merging

Sometimes you don't want all the pages from a given file, just a few. In that case, use the [Extract Pages tool](/extract-pages) first to pull out the pages you need, then bring those into the merge. It adds a step, but each tool does one job cleanly.

If you need to rearrange or remove pages after a merge, the [Organize PDF tool](/organize-pdf) lets you do that visually before saving the result.

## A note on the merged file's content

Merging preserves the text, images, and visual content of every page. What it doesn't carry over is anything stored at the document level rather than the page level: interactive form fields (addressed above), bookmarks from the original files, and document-level metadata. For most use cases, that's fine. If you need bookmarks in the merged file, those would need to be added separately.
