## How to rearrange pages in a PDF for free

You can rearrange PDF pages for free in your browser without installing anything or creating an account. Open the [Organize PDF tool](/organize-pdf), drop your file in, drag the page thumbnails into the order you need, then download. Most jobs take under a minute.

This works on Windows, Mac, Chromebook, and any device with a modern browser. Your file stays on your device the whole time.

## Step-by-step: reorder pages with the Organize PDF tool

1. Go to the [Organize PDF tool](/organize-pdf).
2. Click "Select PDF" or drag your file directly onto the page.

4. Drag and drop any thumbnail to move that page to a new position. You can move multiple pages.

## Why would you need to reorder pages?

A few situations come up regularly:

**Scanned a document backwards.** Some flatbed scanners, especially older models, produce pages in reverse order depending on how you load the paper. Flipping the order takes seconds.

**Merged files and got the wrong sequence.** You used [Merge PDF](/merge-pdf) to combine three documents but realized the appendix should come before the references. Reorder and re-download.

**Received a scrambled report.** Certain software exports PDFs with pages in an unexpected order. One quick drag session fixes it.

**Putting together a portfolio or presentation.** You've built the piece from several source files and want a deliberate page flow that wasn't baked into any of them.

**Moving a cover page.** A contractor sent a document where the cover page landed in the middle. Two drags and it's where it should be.

## Does reordering change quality or file size?

No. Reordering pages works by changing the page sequence stored inside the PDF structure, not by re-rendering any of the content. Text, images, fonts, and formatting are all left untouched.

[The PDF specification](https://pdfa.org/resource/pdf-specification-index/) (ISO 32000) stores pages as independent objects inside the file, with a separate page tree that records their order. Reordering rewrites that page tree without touching the page content streams. That's why a good reorder tool is fast and lossless, and why the output file size is essentially the same as the input.

If you find that a reorder operation significantly changes the file size, the tool is re-rendering pages (rasterizing them), which would also hurt text quality. A tool that outputs a noticeably different file size is a sign to try a different one.

## How to rearrange PDF pages on Mac for free

If you're on a Mac, you already have a built-in option that doesn't require any download. [Apple's Preview app](https://support.apple.com/en-gb/guide/preview/prvw11793/mac) handles basic page reordering:

1. Open your PDF in Preview.
2. Choose **View > Thumbnails** from the menu bar to show the sidebar.
3. Click and drag any page thumbnail up or down in the sidebar to move it.
4. Use **Command + S** to save.

Preview works well for short documents. For longer files, the drag-and-drop experience in the browser-based [Organize PDF tool](/organize-pdf) is easier because it shows larger thumbnails and lets you see the page content more clearly. It also works on Windows and Chromebook, where Preview isn't available.

## How to reverse the page order of a PDF

Reversing is a specific kind of reorder. Open the [Organize PDF tool](/organize-pdf), load your file, then drag each page from its current position to the opposite end. For a 4-page document: move page 4 to position 1, page 3 to position 2, and so on. For a longer document, this takes a bit more time, but for most practical uses (scanning batches, short reports) it's quick enough to do manually.

If you have a very long document where reversing all pages by hand is impractical, some command-line tools like [pdftk](https://www.pdflabs.com/tools/pdftk-the-pdf-toolkit/) support batch reversal. For most everyday needs, the browser tool handles it.

## A note on privacy

Most online PDF tools upload your file to a server for processing, then delete it after a time window. That's acceptable for public-facing documents. For sensitive files like medical records, legal contracts, or financial reports, it's better to use a tool where your file never leaves your device.

The Organize PDF tool runs entirely client-side using [WebAssembly](https://developer.mozilla.org/en-US/docs/WebAssembly) in your browser. Nothing is transmitted. You can even turn off your internet connection after the page loads and the tool will still work.
