You can password protect a PDF on your iPhone for free in two ways: the Files app has a built-in lock feature on iOS 16 and later, or you can use the [Protect PDF tool](/protect-pdf) in Safari to add AES-256 encryption without installing anything. Both options are free and take under a minute.

## Method 1: Lock a PDF in the Files app (iOS 16 and later)

Apple added native PDF locking to the Files app starting with iOS 16. It's the fastest option if you want to protect a file already saved on your device.

1. Open the **Files** app and browse to the PDF you want to protect.
2. Long-press the file icon until the context menu appears.
3. Tap **Lock PDF** from the menu.
4. Enter a password, confirm it, then tap **Done**.
5. A small padlock badge appears on the file icon to confirm the lock is active.

When anyone else tries to open the file, they'll see a password prompt before the PDF loads.

**Limitations worth knowing before you start:**

- PDFs stored in **iCloud Drive** cannot be locked this way. Move the file to **On My iPhone** storage first (long-press the file, tap **Move**, choose On My iPhone).
- There's no way to remove the lock from inside the Files app. If you need to share an editable copy, you'll need a third-party tool to remove the password.
- The feature requires iOS 16 or later. If your iPhone runs iOS 15, skip to Method 2.

## Method 2: Add AES-256 encryption in Safari (works on any iOS version)

For stronger, documented encryption that opens reliably in every PDF reader, use the [Protect PDF tool](/protect-pdf) in your browser. The file is processed entirely inside Safari. Nothing is sent to a server, which means your document stays on your device throughout.

1. Open **Safari** and go to the [Protect PDF tool](/protect-pdf).
2. Tap **Choose file** and select the PDF from Files, Photos, or another app.
3. Type a password. Make it something memorable. If you lose it, no one can recover it for you.
4. Tap **Protect PDF** and wait a few seconds for the tool to encrypt the file.
5. Tap the download button. iOS will ask where to save the protected PDF. Choose your Files app or any compatible app.

The tool uses [AES-256](https://en.wikipedia.org/wiki/Advanced_Encryption_Standard), the same encryption standard used by banks and government agencies. The [PDF encryption standard (ISO 32000)](https://pdfa.org/resource/iso-32000-2/) defines exactly how readers verify the password, so the resulting file opens correctly in Adobe Reader, Preview on Mac, Chrome, and any other PDF app.

**File size after encryption:** adding a password adds roughly 1 KB. A 913 KB image-heavy PDF becomes 914 KB after protection, so it won't affect whether the file fits an email attachment limit.

**Go with the Files app** if the PDF is already on your phone, you're on iOS 16 or later, and you just need a quick lock for personal use.

**Go with the Protect PDF tool** if you're sending the file to someone else, need a documented encryption method, or want to be able to remove the password later with the [Unlock PDF tool](/unlock-pdf).

## Does adding a password change the file size?

Barely. AES-256 encryption adds roughly 1 KB of overhead regardless of the original file's size. A 23.5 KB text report becomes 24.6 KB after protection. A 913 KB photo-heavy PDF becomes 914 KB. You won't push a file over an email limit by adding a password.

## Will the locked PDF open on Android or Windows?

Yes. PDF password protection is an open standard defined in [ISO 32000](https://pdfa.org/resource/iso-32000-2/), the same specification that every major PDF reader implements. When someone opens the file on Android, Windows, or Mac, their PDF app will show a password prompt automatically. They enter the correct password, and the file opens normally.

The one edge case: very old PDF readers (pre-2008) may not support AES-256 and will show an error. In practice this is rare, and upgrading to any modern reader fixes it.

## How to remove the password later

If you protected the file with the [Protect PDF tool](/protect-pdf), you can remove the password anytime. Open the [Unlock PDF tool](/unlock-pdf) in Safari, select the protected file, enter the password, and tap to remove protection. Download the resulting file. It's the same PDF with encryption removed.

If you used the Files app lock, the only way to remove the password on your iPhone is through a third-party app or browser tool that supports the locking format Apple uses.

## A note on lost passwords

No tool (on iPhone or anywhere else) can recover a PDF password. That's the whole point of encryption: without the key, the file is unreadable. Before locking an important document, save the password somewhere safe. A password manager like [Apple Passwords](https://support.apple.com/en-us/104994) (built into iOS 18 and later) or [Bitwarden](https://bitwarden.com) (free and open-source) keeps passwords accessible without writing them on a sticky note.

If you've lost the password to a PDF and still have the original unlocked version, you can re-protect it from scratch with the [Protect PDF tool](/protect-pdf) using a new password.
