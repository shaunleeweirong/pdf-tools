Converting a PDF to JPG on Mac is easy once you know which method fits what you need. Mac includes a free option in Preview, but it only handles one page at a time. If your PDF has multiple pages, or you'd rather not send your file to a third-party server, you have a couple of solid alternatives that are also free.

## Does Mac have a built-in PDF to JPG converter?

Yes. [Preview](https://support.apple.com/guide/preview/welcome/mac) is pre-installed on every Mac and can export a PDF page as a JPEG without any extra software. Here's how to use it:

1. Open your PDF in Preview (double-click it, or right-click > Open With > Preview).
2. Go to **File > Export**.
3. In the **Format** drop-down, choose **JPEG**.
4. Set the **Quality** slider to High or Best.
5. Click **Save**.

One important setting to check before you save: Preview defaults to **72 DPI**, which matches a typical screen but looks soft when printed or shared at high zoom. In the Export dialog, there's a **Resolution** field. Raise it to **150 DPI** for screen sharing or **300 DPI** for print, and the output will be noticeably sharper. File size goes up, but the quality difference is worth it for most uses.

The main limit with Preview: it exports one page at a time. Open page one, export, open page two, export. For a two-page PDF that's fine. For anything longer, it gets repetitive quickly.

### Use Automator on your Mac

[Automator](https://support.apple.com/guide/automator/welcome/mac) is a free workflow tool built into macOS that can batch-convert an entire PDF in one step. It takes a few minutes to set up the first time, but afterward you can run it from a right-click menu.

To set it up:

1. Open Automator (Finder > Applications > Automator).
2. Create a new **Quick Action**.
3. Set "Workflow receives current" to **PDF files** in **Finder**.
4. Search for the action **Render PDF Pages as Images** and drag it into the workflow.
5. Set the format to **JPEG** and choose your resolution (300 is a safe default).
6. Add a **Move Finder Items** action to put the output where you want it.
7. Save the Quick Action with a name like "PDF Pages to JPEG."

After that, right-click any PDF in Finder, go to **Quick Actions**, and select your action. Automator renders every page and saves each one as a separate JPEG in the folder you chose.

## Why does my PDF look blurry after converting to JPG on Mac?

This is the most common complaint about Preview's export. The default **72 DPI** setting produces images that look fine at 100% zoom on a typical display but appear soft at anything larger, and look quite blurry when printed.

The fix is straightforward: in the Export dialog, find the **Resolution** field and type in a higher number before you click Save. For sharing via email or social media, **150 DPI** gives a clean result at a manageable file size. For printing, **300 DPI** is the standard for sharp output.

The [JPEG format](https://en.wikipedia.org/wiki/JPEG) doesn't enforce a specific resolution. The DPI value in Preview directly controls how many pixels each inch of the PDF page gets rendered at, so a higher number means more pixels and a sharper image.

## JPG or PNG: which format should you pick?

**JPG** produces smaller files because it uses lossy compression. It's the better choice for PDFs that contain photographs, mixed layouts, or anything you're sharing via email, messaging, or social media where file size matters.

**PNG** preserves every pixel without compression artifacts. It's worth choosing when your PDF contains charts, diagrams, line art, or text-heavy slides where sharpness and color accuracy matter more than file size.

Our [PDF to JPG tool](/pdf-to-jpg) outputs JPEG. If you need PNG instead, you can open the JPG in Preview and re-export as PNG with no quality loss, since Preview saves PNG losslessly.

## Does converting a PDF to JPG change the content?

The conversion renders each PDF page as a flat raster image, the same way a scanner captures a printed page. Everything visible in the original PDF shows up in the JPG: text, images, diagrams, and annotations.

The key change is that the output is an image, not a document. Text in the JPG is not selectable, not searchable, and can't be copied and pasted. If you need to extract or edit the text from the resulting image, you'd need an OCR (optical character recognition) tool to read it back out.

If you're using the JPGs in a presentation, webpage, or design file, the conversion works well and the visual result matches the original. If text accessibility matters, consider whether the JPEG format is really the right output for your use case, or whether a different approach (like extracting specific pages as a PDF) would serve you better.
