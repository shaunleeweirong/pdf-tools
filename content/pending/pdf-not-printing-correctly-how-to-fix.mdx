When a PDF isn't printing correctly, the problem usually comes from one of four places: the file itself, your PDF viewer, the print dialog settings, or your printer driver. Most issues have a fast fix once you know where to look.

## Why is my PDF printing blank pages?

Blank output is almost always a rendering problem. When a PDF uses transparency effects, gradients, or interactive layers, some printer drivers can't process them and print nothing instead of reporting an error.

The fastest fix: in [Adobe Reader](https://helpx.adobe.com/acrobat/desktop/troubleshoot/print-scan-issues/printing-errors.html), open the print dialog, click **Advanced**, and check **Print as Image**. This converts each page to a flat image before it reaches the printer driver, bypassing whatever the driver couldn't handle.

If you don't have Adobe Reader, try printing from Chrome. Chrome's built-in PDF renderer handles transparency well, and its print dialog includes a basic "Print as image" option under **More settings**.

## My PDF is printing the wrong size or content is getting cut off

This is almost always a paper size mismatch. A4 and US Letter look nearly identical on screen but differ by about 6mm in each dimension. When the PDF was designed for A4 and your printer has Letter loaded (or the other way around), edges clip.

To fix it:
1. Open the print dialog.
2. Find **Page Sizing and Handling** (Acrobat) or **Page Setup** (Preview on Mac).
3. Change the setting from **Actual Size** to **Fit** or **Shrink Oversized Pages**.
4. Confirm the paper size shown matches what's in your printer tray.

Avoid leaving it on Actual Size if there's any chance of a size mismatch. Fit scales the whole page proportionally so nothing gets clipped.

## Text is missing, garbled, or replaced with boxes

This is a font problem. PDFs store text with font definitions. If a font isn't embedded in the file and isn't installed on your computer, your viewer substitutes a fallback, which prints as boxes, wrong glyphs, or missing words entirely.

What to try, in order:
- **Enable Print as Image.** This rasterizes the page from what's visible on screen, so it prints what you see regardless of whether fonts are available.
- **Try a different viewer.** Chrome, macOS Preview, and Adobe Reader each handle missing fonts differently. One may substitute better than another.
- **Ask for a re-export with embedded fonts.** In most design and word-processing apps, embedded fonts is a checkbox in the PDF export settings. A file with all fonts embedded prints the same everywhere.

## Pages are printing in the wrong orientation

If portrait pages print sideways, the orientation in your print dialog doesn't match the page orientation saved in the PDF.

First, check your print dialog for an **Auto-Rotate and Center** option and turn it on. Most viewers include this, and it handles the mismatch automatically.

If the pages are genuinely saved at the wrong rotation, fix it at the source. The [Rotate PDF tool](/rotate-pdf) lets you set each page to the correct angle and download the corrected file before printing.

## PDF colors look different on paper than on screen

Screens display color in RGB (red, green, blue light). Printers use CMYK (cyan, magenta, yellow, black ink). The two color spaces have different gamuts, and some colors that look vivid on screen, especially bright blues and greens, can't be reproduced in CMYK ink. That's a physical limitation of the printing process, not a software error.

For home and office printing, this usually isn't worth worrying about. Standard desktop printers accept RGB input and convert it automatically, often with reasonable results.

If you need accurate color output, check whether the PDF was exported in CMYK mode. Re-exporting in RGB often looks better on inkjet and laser printers designed for office use. For professional print work, the [PDF format's ISO 32000 standard](https://en.wikipedia.org/wiki/PDF) specifies how color spaces are embedded, and commercial print shops usually prefer CMYK PDFs profiled for their specific press.

## How to diagnose and fix a PDF that won't print right

Work through these steps in order:

1. **Try a different viewer.** Open the same file in Chrome, macOS Preview, or Adobe Reader. If it prints correctly from one but not another, the problem is the viewer.
2. **Enable Print as Image.** This bypasses the majority of rendering problems in a single step.
3. **Adjust page sizing.** Switch to Fit or Shrink Oversized Pages in the print dialog.
4. **Flatten the file.** If the PDF has form fields or annotations, use the [Flatten PDF tool](/flatten-pdf) to make those elements non-editable before printing. Some printers fail to render interactive elements, and flattening removes that as a variable.
5. **Update your printer driver.** Go to your printer manufacturer's website and download the latest driver for your model. Outdated drivers cause rendering failures that look like PDF problems but aren't.
6. **Redownload the file.** A partial or interrupted download produces a corrupt PDF that displays on screen but fails at print time. Grab a fresh copy and try again.

## When the PDF file itself is corrupt

A damaged PDF can look normal on screen but fail when sent to a printer. Signs include printing that stops partway through, only some pages coming out, or an error from the printer with no obvious cause.

If redownloading doesn't help, open the file in Chrome and print using Chrome's print dialog. Chrome's PDF engine is forgiving of structural errors. If it prints successfully, use Chrome's **Save as PDF** option (available in the print destination list) to create a clean copy, then print from that.

If no viewer can print the file, contact whoever sent it and ask for a new export from the original source document.
