## How to reverse page order in a PDF for free

You can reverse PDF page order right now with the [Organize PDF tool](/organize-pdf). Drop your file, drag the page thumbnails into reverse order, and download the result. Your file stays in your browser throughout, which means nothing gets sent to a server.

That covers most situations. Below you'll find how this works on each platform, why you'd need it, and what happens to your file when pages are reversed.

## Why would you need to reverse a PDF's page order?

A few situations come up often:

- You scanned a paper document through an automatic sheet feeder that loaded pages back-to-front, so the last page of the document ended up first in the PDF.
- A printer or copier produced a PDF where pages are reversed relative to what you intended.
- You assembled a report from multiple sources in the wrong order and want to fix it before sending.
- A booklet or saddle-stitch layout needs pages in a specific reverse sequence for the binding to work.

In each case the fix is the same: change the sequence of pages inside the [PDF file](https://en.wikipedia.org/wiki/PDF), leaving the content of each page untouched.

## What reversing page order actually does

Reversing page order changes the sequence in which pages appear in the document. Page 10 becomes page 1, page 9 becomes page 2, and so on. The content of each page stays exactly as it was: the text remains text, images remain images, and the file size is essentially unchanged.

This is not the same as rotating pages (which changes which edge of the page is "up") or mirroring/flipping (which creates a horizontal reflection). If you want to rotate pages, the [Rotate PDF tool](/rotate-pdf) does that separately.

## How to reverse PDF pages in your browser (no software needed)

The [Organize PDF tool](/organize-pdf) runs entirely in your browser using client-side processing, so your file never leaves your device.

1. Open the [Organize PDF tool](/organize-pdf).
2. Drop your PDF onto the upload area.
3. Page thumbnails load in the tool. Drag the last thumbnail to the first slot, the second-to-last to the second slot, and continue.
4. Click **Save** or **Download** to get the reordered file.

For short documents (5 to 10 pages) this takes under a minute. Longer documents require more dragging, so the desktop methods below may be quicker if you're working with 30 or more pages.

## How to reverse PDF pages on Mac with Preview

Mac comes with Preview, which handles PDF page reordering without any extra software.

**Method 1: Thumbnails panel (saves a new file)**

1. Open your PDF in Preview.
2. Go to **View** then **Thumbnails** to show the sidebar.
3. Click the last page thumbnail and drag it to the first position. Continue working backward through the document.
4. Once pages are in the right order, go to **File** then **Export as PDF** and save under a new name.

This works well for documents with a handful of pages. For 20 or more pages, it becomes tedious.

**Method 2: Print dialog (printing only, doesn't change the file)**

If you only need to print with reversed page order and don't need the file itself reversed:

1. Press **Cmd+P** to open Print.
2. Click **Show Details** if the full options aren't visible.
3. Choose **Paper Handling** from the dropdown menu.
4. Set **Page Order** to **Reverse**.
5. Print normally.

The printed output comes out in reverse order, but the saved PDF file is unchanged.

## How to reverse PDF pages on Windows for free

Windows doesn't include a built-in tool for reordering PDF pages. You have two solid free options:

**Browser-based (nothing to install):** Open the [Organize PDF tool](/organize-pdf) in Chrome or Edge, drop your file, drag the pages, and download. This works on any version of Windows.

**PDFsam Basic (free, open-source desktop app):** [PDFsam Basic](https://pdfsam.org/) is a cross-platform application (Windows, Mac, Linux) that runs entirely offline. To reverse a PDF in PDFsam, the most reliable approach is to extract all pages with the Split module, then merge them in reverse order using the Merge module. It takes a couple of extra steps but works for any size document.

PDFsam processes everything locally, so it's a good choice when working with sensitive documents that shouldn't go through any web service.

## How to reverse PDF pages on a Chromebook

Chrome OS has no built-in PDF page editor. The [Organize PDF tool](/organize-pdf) is the simplest option since it runs inside the Chrome browser. Follow the same steps as the browser method above. The Files app and Google Drive don't offer page reordering natively.

## What about merging after reversing?

If your workflow involves splitting a document, reversing one section, and then combining everything back, the [Merge PDF tool](/merge-pdf) keeps the page order exactly as you deliver the files. You decide the sequence; the tool doesn't alter it.

One caveat worth knowing: merging PDFs strips interactive form fields from the output. If any of the files you're combining have fillable form fields, run the [Flatten PDF](/flatten-pdf) tool on them first to lock the field values into the page as regular content. After flattening, the values stay visible through any merge or page reorder operation.

## Checking your result

After reversing, open the downloaded file and flip through the first few pages to confirm the order is correct. Some PDF viewers cache the previous version, so if it looks wrong, close and reopen the file or open it in a different viewer.

If you made a mistake with the page order, just run the tool again on the original file. The tool creates a new download each time and never touches the file you started with.

## When reversing the whole document isn't what you want

Some situations call for reversing only a section of a PDF, not the entire thing. The free approach:

1. Use the [Organize PDF tool](/organize-pdf) to drag just the pages you want reversed to a different position.
2. Alternatively, use a split tool to extract the pages you want to reverse as a separate file, reverse that file, then merge the segments back in order with the [Merge PDF tool](/merge-pdf).

Neither approach requires an Acrobat subscription. Both keep your files in your browser.
