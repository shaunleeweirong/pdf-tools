Rotating a PDF on Mac is free and takes under a minute. The built-in Preview app handles most cases without downloading anything extra. For files you want processed locally without any app at all, an in-browser rotate tool works entirely in your browser.

## How to rotate a PDF using Preview on Mac

Preview ships on every Mac and can rotate PDF pages in a few clicks. [Apple's official guide to Preview](https://support.apple.com/guide/preview/crop-or-rotate-a-pdf-prvw11567/mac) covers the basics, but here's the full step-by-step:

1. Right-click your PDF and choose **Open With > Preview**.
2. Open the thumbnail sidebar: **View > Thumbnails** (or press Cmd+Option+2).
3. Click the page thumbnail you want to rotate. To rotate multiple pages, hold Command and click each one.
4. Go to **Tools > Rotate Left** for counterclockwise, or **Tools > Rotate Right** for clockwise. Each click turns 90 degrees. Click twice for 180 degrees.
5. Save the file: **File > Save** (Cmd+S).

That last step matters. Preview uses Auto Save in some contexts, but with PDFs it's safest to press Cmd+S yourself before closing. If macOS asks whether to save on close, choose Save.

### How to rotate just one page in a PDF on Mac

Rotating a single page works exactly the same way. Open the thumbnail panel, click only the thumbnail for that page (don't select any others), and then rotate. Preview applies the change to selected thumbnails only, so the rest of your document stays oriented as-is.

This is useful when a scan came out sideways on page 3 but the rest of the document is fine. You fix one page without touching anything else.

### Does rotating in Preview change quality or file size?

No. The [PDF specification (ISO 32000)](https://pdfa.org/resource/iso-32000/) defines a `/Rotate` entry in each page's dictionary. Rotating sets that number to 90, 180, or 270 without touching any page content or re-encoding any images.

In measured tests, a 913.4 KB image deck came back at exactly 913.4 KB after rotating all six pages 90 degrees clockwise. A 23.5 KB text report came back at 23.5 KB (a 0.02% increase, just rounding). File size doesn't change.

A tool that returns a noticeably larger file after a rotate is re-rasterizing the pages, which turns crisp vector text into JPEG images. Preview and the [Rotate PDF tool](/rotate-pdf) both avoid this.

## How to rotate a PDF in your browser (no sign-up needed)

If you'd rather skip the desktop app, the [Rotate PDF tool](/rotate-pdf) runs entirely in your browser. Files are processed locally using JavaScript, so nothing is uploaded to any server.

1. Open the [Rotate PDF tool](/rotate-pdf).
2. Click **Choose file** or drag your PDF in.
3. Pick **90°**, **180°**, or **270°** clockwise.
4. Click **Rotate** and download the result.

This is the fastest option for a quick one-off fix. If you also need to reorder pages, the [Organize PDF tool](/organize-pdf) lets you drag pages into any order and rotate them at the same time, all in one step.

## How to batch rotate multiple PDFs on Mac with Automator

If you have a folder of scanned documents that all came out sideways, Automator handles them all at once. Automator is free and built into macOS.

1. Open **Automator** (search Spotlight, or find it in /Applications/Utilities/).
2. Create a new **Workflow**.
3. In the action library on the left, search for **Rotate PDF Pages** and drag it into the workflow.
4. Set the direction (clockwise or counterclockwise) and angle (90, 180, or 270 degrees).
5. Add a **Move Finder Items** action below it and pick a destination folder for the rotated files.
6. Press the Run button and drag your PDFs into the dialog.

Automator processes each file and saves the rotated versions into the folder you chose. This is handy for accountants, researchers, or anyone who regularly scans paper documents and ends up with a batch of sideways files.

## Saving the rotation permanently

The most common frustration is a rotation that seems to disappear. Here's what goes wrong and how to prevent it:

**Preview not saving:** Press Cmd+S right after rotating. Don't close the window first. If macOS shows a "Save a new version?" prompt on close, choose Save, not Don't Save.

**Cloud syncing:** If you opened the PDF from iCloud Drive, Dropbox, or Google Drive, the sync may show the old version for a few seconds after you save. Give it a moment, then reopen the file to confirm the rotation stuck.

**Original file untouched:** If you used the [Rotate PDF tool](/rotate-pdf), remember to download the result and replace your original. The tool gives you a new file; it doesn't overwrite what's on your Mac.

After saving, reopen the PDF and scroll through it to check every page is oriented correctly. If you rotated the wrong page, Cmd+Z undoes the rotation in Preview as long as you haven't closed the window yet.
