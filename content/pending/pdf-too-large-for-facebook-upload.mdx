If you tried to send a PDF over Facebook Messenger and hit a file size error, or you're wondering why there's no obvious way to post a PDF on your timeline, this guide covers what actually works.

## What is Facebook's file size limit for PDFs?

[Facebook Messenger raised its file attachment limit to 100 MB in 2024](https://www.socialmediatoday.com/news/messenger-increases-file-sharing-limit-to-100mb/745216/), up from the previous 25 MB cap. PDFs count as regular file attachments, so any PDF under 100 MB sends without a problem.

Facebook Groups support file uploads too. When you're writing a post inside a group, look for the file icon or the "More" option in the composer, then choose "Add File." The same 100 MB limit applies.

One surface that doesn't support PDF uploads at all is your personal Facebook timeline or a Facebook Page. You can't attach a PDF to a timeline post the way you'd attach one to a Messenger chat. The workaround there is a link, not a file.

## Why is your PDF too large for Facebook?

If your file is hitting the 100 MB limit, the cause is almost always one of these:

- **Scanned pages at high resolution.** A scanner set to 300 DPI produces a large raster image per page. Multiply that by 20 or 30 pages and the file adds up fast.
- **Embedded photos or diagrams.** Presentations, portfolios, or reports with lots of full-bleed images can run large.
- **Redundant data.** Some PDF creators embed revision history, duplicate fonts, or oversized thumbnails that add bulk without adding visible content.

Text-only PDFs, such as a word-processed letter or a simple form, are usually small by default. If a text document is suspiciously large, the culprit is often an embedded logo at high resolution or a background image on every page.

## How to compress a PDF for Facebook Messenger

For scanned documents and image-heavy PDFs, the [Compress PDF tool](/compress-pdf) can cut the file to a fraction of its original size. It runs directly in your browser, so the file never leaves your device.

Steps:

1. Open the [Compress PDF tool](/compress-pdf).
2. Drop your PDF onto the upload area.
3. Choose a compression level. "Medium" is the right starting point for most files.
4. Download the result and check the size before sending.

One thing to know before you compress: the tool converts every page to a JPEG image. That's exactly what you want for a scanned document, where the pages are already images, but it makes text-based PDFs much larger. In our own measurements, a 23.5 KB text report grew to 1.4 MB after compression at Medium quality. If you compress a text PDF and then try to send it, the error will be worse than before.

**How to tell which type you have:** open the PDF and try clicking and dragging to select a word. If text highlights, your document stores text as vector glyphs and compression will hurt it. If nothing selects and your cursor stays as an arrow, the pages are images and compression will help.

## When to skip compression (and what to do instead)

For text-based PDFs over 100 MB, the fix isn't compression. Your real options:

**Share via a cloud link.** Upload the PDF to Google Drive, Dropbox, or OneDrive and copy the sharing link. Paste it into a Messenger chat or a Facebook post. Recipients get a clickable preview card; they download or view the document directly without any size restriction on your end.

**Split the document.** The [Split PDF tool](/split-pdf) lets you divide a large PDF into page ranges. Two 60 MB halves send fine over Messenger when one 120 MB whole wouldn't. This works especially well for long reports where different sections are relevant to different people anyway.

**Remove pages you don't need.** If only part of the document is relevant, the [Delete Pages tool](/delete-pages) removes the rest before you send. A 40-page technical report might shrink to five relevant pages, dropping the file size proportionally.

**Convert to images.** If you only need someone to see a page or two rather than use the document, the [PDF to JPG tool](/pdf-to-jpg) converts each page into a separate image file. You can then send the image in a Messenger chat as a photo (which Facebook handles natively and well) or post it on your timeline as a picture.

## How to send a PDF in Facebook Messenger

1. Open the Messenger app or go to messenger.com.
2. Open or start a conversation.
3. On mobile, tap the "+" icon to find the file attachment option. On desktop, look for the paperclip icon next to the message box.
4. Select the PDF from your files.
5. Tap or click Send.

The recipient sees a document card they can tap to preview or download. Messenger supports PDFs on both iOS and Android.

## How to share a PDF in a Facebook Group

1. Go to the group and click into the "Write something" box.
2. Look for the file icon at the bottom of the composer, or tap "More" on mobile.
3. Choose "Add File" and pick your PDF.
4. Add a caption if you want some context for members, then post.

The PDF appears as a file attachment in the feed. It also gets saved to the group's Files tab automatically, so members can find it later without scrolling back through posts. This is useful for shared resources like lesson materials, club handbooks, or reference documents.

## How to post a PDF on your Facebook timeline

Facebook doesn't provide a native PDF post type for timelines or Pages, but you have a couple of practical options:

**Option 1 (link post):** Upload the PDF to Google Drive. Set the sharing permission to "Anyone with the link can view." Copy the link and paste it into a new Facebook post. Facebook pulls a title and preview image from the document automatically.

**Option 2 (image post):** If the document is short or you just want to share its visual content, use the [PDF to JPG tool](/pdf-to-jpg) to turn each page into a JPEG. Post the images as a Facebook photo album or carousel. This gets more engagement on the feed than a link card, since images load inline while links require a click.

## A note on compressing twice

You might think running compression a second time would squeeze more out. It doesn't. A second pass at the same compression level on an already-compressed PDF nearly doubles the file size rather than reducing it further. If the first compression level didn't shrink the file enough, go back to the original and try a higher compression setting instead of running the result through a second time.

Pick the right level the first time, check the size, and send.
