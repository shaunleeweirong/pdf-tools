## How to rotate a PDF on iPhone for free

Rotating a PDF on iPhone is free and takes under a minute. You can do it in two ways: using the [Rotate PDF tool](/rotate-pdf) directly in Safari, or using iOS 16's built-in PDF editing in the Files app. Both options fix pages that are sideways or upside down, and both save the rotation permanently in the file.

If you're not sure which to use, start with the browser method. It works on any iPhone running iOS 14 or later and doesn't require any download or account.

## Method 1: Use the Rotate PDF tool in Safari (no app needed)

This works on any iPhone with an internet connection. You upload the file, choose which pages to rotate, and download the corrected PDF.

1. Open **Safari** on your iPhone and go to the [Rotate PDF tool](/rotate-pdf).
2. Tap **Choose file**. Your iPhone will ask where to find the PDF: Files, iCloud Drive, Photos, or any connected app.
3. The tool shows thumbnail previews of all pages once the file loads.
4. Tap the rotation arrow below any page thumbnail. One tap rotates 90 degrees clockwise; tap again for 180; again for 270.
5. To rotate every page at once, tap the **Rotate all** button at the top rather than clicking each thumbnail individually.
6. Tap **Download** and choose where to save the file on your iPhone.

Open the downloaded file to confirm the orientation looks right before discarding the original.

Rotation only changes a single metadata flag inside the [PDF file format](https://en.wikipedia.org/wiki/PDF), so the output is the same size as the input. You won't need to compress the file afterwards just because you rotated it.

## Method 2: Use the Files app on iOS 16 or later (built-in, no internet)

Apple added basic PDF editing to the Files app in [iOS 16](https://www.apple.com/ios/ios-16/). If your iPhone is updated, this works without any tools or internet connection, which is useful when you're offline.

1. Open the **Files** app and find your PDF.
2. Tap the file to open it.
3. With the PDF open, tap the **page thumbnails strip** on the left side of the screen. Swipe right from the left edge if it doesn't appear automatically.
4. Long-press the thumbnail for the page you want to rotate.
5. Tap **Rotate Left** or **Rotate Right** from the menu that appears.
6. Tap **Done** to save the change.

The limitation here is that you rotate pages one at a time. For a PDF with several sideways pages, the browser tool's batch rotation is faster. The Files app method is best for a quick single-page fix on a device that isn't connected to the internet.

## Does rotating a PDF on iPhone save the rotation permanently?

Yes, when you use the Rotate PDF tool or the Files app's edit mode, the change is written into the PDF file itself. Open the downloaded file on another app or another device and it will appear in the correct orientation.

The confusion often comes from PDF viewers that offer a "rotate view" option. Some reader apps let you flip the display for your current session only, similar to pinching to zoom. That kind of rotation disappears when you close the app. The giveaway: if the tool doesn't produce a new file to download, it's probably only rotating the view.

To be sure the rotation stuck, save or download the file, close the viewer completely, and reopen it.

## How to rotate just one page in a PDF on iPhone

This comes up often with multi-page documents where most pages are portrait but one or two scanned pages came in sideways.

In the Rotate PDF tool, you see a thumbnail for every page after uploading. Tap the rotation arrow under only the pages that need fixing. The other pages remain untouched. When you download the file, only the pages you rotated have changed.

In the iOS Files app, long-press an individual thumbnail and rotate it. Other pages are unaffected.

## Why your PDF looks sideways on iPhone

The most common reason is how the file was created:

**Scanned documents.** When you use a phone to scan a paper document, the scanner app records the phone's orientation at the time you took the photo. If the phone was held sideways, the resulting page is saved landscape, even if the paper was portrait. This is the top complaint on support forums about PDFs looking wrong.

**Wide tables and spreadsheets.** Reports exported from Excel or Google Sheets with wide columns are often saved in landscape format by design. The file isn't broken; the content just fits better sideways.

**Wrong print settings when creating the PDF.** When someone exports a Word document or a webpage to PDF with the wrong paper orientation selected, every page comes out rotated. This happens more often than you'd think with documents created on a Windows machine and then opened on an iPhone.

In all three cases, rotating the pages and saving the corrected version fixes it.

## Does rotating a PDF make it larger?

No. Rotation in the PDF format works by setting a page rotation flag in degrees (0, 90, 180, or 270) in the page dictionary. The tool updates that value for each selected page and rebuilds the file. Nothing is re-rendered, no new images are generated, and the content streams are untouched. The output file is the same size as the input to within a few bytes.

This is worth knowing if you're about to email or upload the file and were worried about size. Rotation alone won't push a PDF over an attachment limit. If the file is already too large, the [Compress PDF tool](/compress-pdf) can reduce it after rotating, but only if the PDF contains images or scanned pages (compressing a text PDF makes it larger, not smaller).

## After rotating: organize and share

Once the orientation is right, you might also want to reorder the pages. The [Organize PDF tool](/organize-pdf) lets you drag thumbnails into a different order, remove pages, or extract specific pages for a separate file, all from your iPhone browser.

If you're combining multiple corrected files, the [Merge PDF tool](/merge-pdf) accepts any number of PDFs and preserves the page orientations you've set.
