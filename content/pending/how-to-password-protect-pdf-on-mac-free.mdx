You can password protect a PDF on Mac for free in minutes, either with the Preview app that ships with every Mac or with a browser tool that runs locally without uploading your file. Both methods require no subscription and no Acrobat.

## How to password protect a PDF on Mac using Preview

Preview is the fastest option if the PDF is already on your Mac. It's built into macOS, it's free, and it doesn't require anything extra.

1. Open the PDF in Preview. Double-click the file, or right-click and choose **Open With > Preview**.
2. Go to **File > Export as PDF**. (This is different from a regular Save. The encryption option only appears in this specific dialog.)
3. Click **Show Details** if the security section isn't visible at the bottom.
4. Check the **Encrypt** box.
5. Type a password and confirm it in the Verify field.
6. Click **Save**.

The file Preview saves is now encrypted. Anyone who opens it will see a password prompt before the content loads. Your original unprotected file stays untouched because Export as PDF creates a new copy.

### What if the Encrypt checkbox doesn't appear?

The Encrypt option only shows up in **File > Export as PDF**, not in Save or Save As. If you don't see it, close the dialog and try again from the correct menu path.

### Open password vs. Permissions password

Preview's security dialog has two tabs. The **Open Password** tab is the one most people want: it requires a password to view the file at all. The **Permissions Password** tab is different, it lets anyone open the document but restricts what they can do (copying text, printing, editing). You can set one, both, or neither. If your goal is to stop unauthorized access, use the Open Password tab.

## How to password protect a PDF on Mac without installing anything

If you want something simpler than Preview's export dialog, or you need [AES-256 encryption](https://en.wikipedia.org/wiki/Advanced_Encryption_Standard) specifically, the [Protect PDF](/protect-pdf) tool handles it in your browser.

1. Open the [Protect PDF](/protect-pdf) page in Safari, Chrome, or Firefox.
2. Drop your PDF onto the tool or click to select it.
3. Type a password.
4. Click **Protect** and download the result.

No sign-up, no file upload to a server. The encryption runs locally in your browser using the same code your computer would use, and the file never leaves your device. The tool uses AES-256, the encryption standard required by many compliance frameworks and government systems.

This approach is also useful when you need to protect several PDFs quickly without going through Preview's export dialog each time.

## What encryption level does Mac Preview use?

Preview on modern Macs uses 128-bit [AES encryption](https://csrc.nist.gov/projects/cryptographic-standards-and-guidelines/archived-crypto-projects/aes-development) for password-protected PDFs. That's the same algorithm used for most encrypted documents, and it's secure against brute-force attacks for any password of reasonable length.

The difference between 128-bit and 256-bit AES is not meaningful for everyday document protection. Both are part of the [PDF specification (ISO 32000)](https://opensource.adobe.com/dc-acrobat-sdk-docs/pdfstandards/PDF32000_2008.pdf) for document security. If your workflow specifically requires AES-256 (some legal, financial, or medical compliance requirements call for it by name), use the browser tool above rather than Preview.

## Does password protection change the file size?

Only by about 1 KB, no matter how large the PDF is. In testing, encrypting a 913 KB image deck increased the file by 0.1%. A 23.5 KB text document increased by 4.8%, which still amounts to about 1 KB in absolute terms. Adding a password won't push a PDF over an email attachment limit.

## How to remove a password from a PDF on Mac

If you have the password and decide you no longer need it:

**Using Preview:**
1. Open the password-protected PDF and type the password when prompted.
2. Go to **File > Export as PDF**.
3. Leave the Encrypt checkbox unchecked.
4. Save the file. The new copy has no password.

**Using the browser tool:**
Open the [Unlock PDF](/unlock-pdf) page, drop in your file, enter the current password, and download the copy without encryption.

Removing a password is only possible if you know the current password. If you've lost it, there's no way to get the content back from an encrypted PDF, which is exactly why encryption works.

## Tips for choosing a password

A strong PDF password doesn't need to be random characters you'll forget. A phrase works better: three or four words together ("maple tree doorbell rain") is far harder to guess than a short random string, and easier to remember. Store it in a password manager if you'll need to share access with others later.

Avoid using the same password you use for other accounts. A PDF password protects only that file, but if it matches a login somewhere, a person who gets access to the file can try the password elsewhere.

## Which method should you use?

Use Preview when the PDF is already open on your Mac and you want the quickest path. Use the browser tool when you want AES-256 encryption, when you're protecting multiple files, or when you'd rather not open the Export as PDF dialog every time.

Both methods are genuinely free with no catch. The browser tool is also useful on shared or work Macs where you don't want the protected file to pass through any server.
