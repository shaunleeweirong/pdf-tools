You can open a PDF without Adobe for free using the browser already on your device. Chrome, Firefox, Edge, and Safari all have PDF viewers built in, no extensions or accounts required. On Mac, Preview handles PDFs by default. On Windows, Microsoft Edge is ready to go without any setup.

That covers viewing. If you also need to fill a form, sign a document, or edit text, there are free browser-based tools for those too. All of them work without installing Adobe or anything else.

## Use your browser: the fastest option

Any PDF link you click online opens in your browser automatically. For a file already on your device, drag it into an open browser window and it appears right there.

[Google Chrome](https://support.google.com/chrome/answer/6172631), [Mozilla Firefox](https://support.mozilla.org/en-US/kb/view-pdf-files-firefox-or-choose-another-viewer), and Microsoft Edge all include a PDF viewer that handles zooming, text search, scrolling, and printing. No plugin, no extension, no account. You just open the file.

If your browser downloads the PDF instead of displaying it, check your browser settings. In Chrome, go to Settings > Privacy and Security > Site Settings > Content > PDF documents, and turn off "Download PDFs." The built-in viewer will take over from there.

## How to open a PDF on Windows without Adobe

Windows ships with Microsoft Edge already installed, and Edge has a capable PDF viewer built in. Right-click any PDF file, choose "Open with," and select Microsoft Edge. If Edge is your system's default for PDFs, double-clicking the file is all it takes.

Edge's viewer goes beyond basic reading. You can highlight text, draw freehand, add sticky notes, and fill in simple form fields. For everyday document viewing, it handles everything Adobe Reader used to provide for free, without requiring a login or subscription.

If you prefer a different app, Chrome and Firefox are free downloads and work the same way. SumatraPDF is a lightweight, open-source option if you want a dedicated reader that stays out of the way.

Step by step on Windows:

1. Right-click the PDF file.
2. Select "Open with."
3. Choose Microsoft Edge (or Chrome or Firefox).
4. The file opens in the browser's viewer.

To make a browser the permanent default, go to Settings > Apps > Default apps, search for PDF, and change the associated app.

## How to open a PDF on Mac without Adobe

On a Mac, Preview is the default PDF viewer and it's a genuinely good one. Double-click any PDF and it opens in Preview. If something else opens it, right-click the file and choose Open With > Preview.

To set Preview as the default for all PDFs, right-click a PDF in Finder, choose Get Info, expand the "Open with" section, select Preview from the menu, and click "Change All."

Preview supports annotations, highlighting, basic form filling, page reordering, and digital signatures. For most personal and work tasks, it handles everything people used to install Adobe Reader to do.

Safari also opens PDFs inline when you tap a link, so you may not even need to open a separate app for PDFs you find on the web.

## How to open a PDF on iPhone or Android

On iPhone, tap any PDF link in Safari and it opens in the browser. PDFs in the Files app open with a single tap. You can annotate and mark them up using the native markup tools in Files or Mail, no extra app required.

On Android, Chrome opens PDFs directly. Google Drive is another built-in option: tap any PDF stored in Drive and the viewer opens immediately. Both handle zooming, scrolling, and text search.

PDF attachments in Gmail and Outlook open in the email app's own viewer on either platform. You don't need an Adobe app installed for any of this.

## What the PDF standard actually says about viewers

A PDF file doesn't belong to Adobe. The format is an [open international standard, ISO 32000](https://www.iso.org/standard/75839.html), maintained by the International Organization for Standardization. Any software can implement a PDF viewer against the spec, which is exactly what browser vendors have done.

Adobe's Reader was once the only practical option because few browsers could render PDFs natively. That changed over the past decade, and today every major browser ships with its own renderer. Adobe's tools are still good, but they're no longer the only path to opening a PDF file.

For sensitive documents, local processing matters. A tool that reads the file in your browser and never sends it to a server is safer than one that uploads to the cloud for processing. The tools on this site work entirely in your browser for exactly that reason.
