Saving a web page as a PDF is free in any modern browser using the built-in print function. There's nothing to install, no account to create, and the method works the same whether you're on Windows, Mac, iPhone, or Android.

## How to save a web page as PDF in Chrome (Windows and Mac)

Chrome's print dialog is the fastest option on a desktop computer:

1. Open the web page you want to save.
2. Press **Ctrl+P** on Windows or **Cmd+P** on Mac to open the print dialog.
3. Click the "Destination" dropdown and select **Save as PDF**.
4. Click **More settings**, then turn on **Background graphics** if you want the page's colors and images included.
5. Click **Save**, choose a folder, and the file is ready.

The "Background graphics" toggle is off by default because it saves ink when printing on paper. Turning it on makes the saved PDF much closer to what you see on screen. [Google's Chrome Help page](https://support.google.com/chrome/answer/1069646) has additional details on print settings if you need to adjust margins or paper size.

For most pages, Chrome produces a clean, readable PDF in a few seconds. If the page has a sidebar or header that eats into the content area, try switching the page orientation from portrait to horizontal in the print dialog.

## How to save a web page as PDF in Firefox or Edge

Firefox and Edge follow the same shortcut. Press Ctrl+P (Windows) or Cmd+P (Mac), then select "Save to PDF" or "Microsoft Print to PDF" from the destination list.

Firefox also includes a reader-mode button on many article pages. Look for a small book-shaped icon in the address bar. Clicking it strips out navigation menus, ads, and sidebars, leaving only the article text. If you print from reader mode, the saved PDF will be a clean, clutter-free document. [Mozilla's support page on printing](https://support.mozilla.org/en-US/kb/print-web-pages-firefox) covers reader mode and other print options in detail.

Edge's Immersive Reader (the book icon in the address bar on article pages) does the same thing, and saves an equally tidy PDF.

## How to save a web page as PDF on iPhone

Safari on iPhone has the most reliable built-in method:

1. Open the page in **Safari**.
2. Tap the **Share** button at the bottom of the screen (a square with an upward arrow).
3. Tap **Print** in the share sheet.
4. On the print preview, **pinch outward** on the preview image. This opens the page as a full-screen PDF.
5. Tap the **Share** button again and choose **Save to Files**.

One small trick: the pinch gesture in step 4 is what converts the print preview into a savable PDF. Without it, tapping Share from the regular share sheet just shares a link, not a file.

Chrome for iPhone does not have a native save-to-PDF button in the same location. The easiest workaround is to copy the URL, paste it into Safari, and save from there. Safari's method is fast and the result looks good for most pages.

## How to save a web page as PDF on Android

Chrome on Android handles this natively:

1. Open the page in **Chrome**.
2. Tap the **three-dot menu** in the top-right corner.
3. Tap **Share**, then tap **Print**. On some Android versions, **Print** appears directly in the three-dot menu rather than in the share sheet.
4. In the print preview, change the destination to **Save as PDF**.
5. Tap the download icon and choose where to save the file.

The exact location of the Print option varies by Android version and phone manufacturer, but the destination is always "Save as PDF" once you reach the print dialog.

## What to do when formatting looks broken or content is missing

Webpages are laid out for screens, not for paper, so some visual differences in a saved PDF are normal. Here are the most common problems and how to fix them:

**Background colors or images are missing.** In Chrome, open "More settings" in the print dialog and turn on "Background graphics."

**Content is cut off at the bottom of pages.** Long paragraphs and images that straddle a page boundary sometimes get cropped. Try horizontal page orientation or a larger paper size (such as A3 or Legal) in the print settings.

**Only part of the page was saved.** This happens with pages that load content as you scroll (infinite-scroll feeds, image galleries, lazy-loaded sections). Scroll all the way to the bottom, wait a few seconds for any remaining content to load, then press Ctrl+P. If the page still cuts off, try Firefox or Edge since they sometimes handle dynamic content differently.

**Ads and navigation menus fill up the PDF.** Firefox's reader mode or Edge's Immersive Reader removes them before you print. Safari on iPhone has the same option under the "aA" icon in the address bar. Saving from reader mode gives you just the article text and any inline images.

The [Consumer Financial Protection Bureau's PDF-saving guide](https://www.consumerfinance.gov/consumer-tools/save-as-pdf-instructions/) is a good reference if you are saving forms or official documents from government sites, where exact formatting matters.

## How to save only part of a page

The print dialog includes a pages field. If the preview shows that you only need pages 2 through 4 of a long article, type "2-4" in the page range box and Chrome will save only those pages. If you have already saved the full PDF and want to pull out certain pages later, the [Split PDF tool](/split-pdf) lets you extract a page range from any PDF file.

## How to reduce the file size of a saved page PDF

If the web page had a lot of photographs, charts, or high-resolution images, the saved PDF can come out larger than you'd expect. The [Compress PDF tool](/compress-pdf) can bring the size down.

One thing to keep in mind: the compressor works by converting each page to a JPEG image. That works well when the page content is already photographic, since the original images compress efficiently. For a text-heavy article or a page with mostly plain text, the tool will actually make the file larger, because crisp vector text takes more space when rendered as a JPEG. If the page you saved was mostly text, the PDF is probably already small enough and does not need compression.

For images or scanned pages as PDF, compressing at Medium quality typically cuts the file to about a third of its original size, which clears most upload and email size limits.

## How to combine several saved page PDFs

If you saved multiple articles or reference pages and want them bundled as one file, the [Merge PDF tool](/merge-pdf) handles this in your browser. Drag in the files in the order you want them, then download the result. Merging does not change the total file size by any meaningful amount. It also works without uploading anything to an outside server, so the content stays on your device.
