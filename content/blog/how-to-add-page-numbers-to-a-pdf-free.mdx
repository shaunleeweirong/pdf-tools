You can add page numbers to a PDF for free without installing anything. Our [Add Page Numbers tool](/add-page-numbers) runs entirely in your browser, so your file never gets uploaded to a server.

## Do I need Adobe Acrobat to add page numbers to a PDF?

No. Adobe Acrobat Pro is the most well-known way to number PDF pages, but it requires a paid subscription. Free browser-based tools handle the same job without it. The [PDF format](https://en.wikipedia.org/wiki/PDF) is an open standard (ISO 32000), and many free tools can modify PDFs directly.

If you just need numbers on your pages, a free online tool is all you need. There's no reason to pay for software or create an account.

## How to add page numbers to a PDF (step by step)

1. Open the [Add Page Numbers tool](/add-page-numbers).
2. Upload your PDF by clicking "Choose file" or dragging it onto the page.
3. Pick where you want the numbers to appear: top or bottom, left, center, or right.
4. Set a starting number if you don't want to begin at 1 (useful for documents that continue from a previous file).
5. Click "Add page numbers" and wait a few seconds.
6. Download your updated PDF.

The whole process takes under a minute for most files.

## Can I choose where the page numbers appear?

Yes. You can place numbers at the top or bottom of the page, aligned to the left, center, or right. Most documents use bottom center or bottom right. For formal reports, bottom center tends to look cleanest. For books or multi-chapter PDFs, the traditional style is bottom right on odd pages and bottom left on even pages, though most free tools apply a single position to all pages.

## What page number formats are available?

Basic free tools add plain numerals: 1, 2, 3. Some tools also support:

- **"Page X of Y"** format, so readers see the total page count
- Roman numerals (i, ii, iii) for front matter like a table of contents
- Custom prefixes such as "Appendix A-1"

Our tool uses plain numerals by default. If you need "Page X of Y" or a custom prefix, [PDF24's free page numbering tool](https://tools.pdf24.org/en/add-page-numbers) has those options.

## Can I start numbering from a specific page?

Yes. If your document has a cover page or table of contents that you don't want numbered, you can skip those and start numbering from any page you choose. Set the "start page" to the first page you want numbered, and the "start number" to whatever value fits your document.

For example, if pages 1 to 3 are a cover and introduction, set the start page to 4 and the start number to 1. The result: your content pages show 1, 2, 3... while the cover stays clean.

## Will adding page numbers change anything else in my PDF?

No. Page numbers are added as a header/footer layer on top of each page, leaving the rest of the document unchanged. Text, images, links, and form fields stay exactly where they were.

The one exception is a PDF with very tight margins where content runs close to the edge. In that case, the numbers might overlap body text. Move the number position to a different corner if that happens.

## Is it safe to add page numbers to my PDF online?

Our tool processes your file [locally in your browser](https://en.wikipedia.org/wiki/Client-side_computing). Your PDF never gets sent to a server, which matters if you're working with contracts, medical records, or anything else you'd rather keep private.

Some other free tools do upload your file to their servers. That isn't necessarily a problem, but check the privacy policy of any tool you use for sensitive documents.

## Does it work on a phone?

Yes. The tool works in any modern mobile browser on iPhone, Android, or iPad. Upload your PDF, set your options, and download. No app install needed.

For very large PDFs (over 50 MB), a desktop browser is more reliable since mobile browsers have stricter memory limits.

## Frequently asked questions

### How long does it take to add page numbers to a PDF?

For most PDFs under 10 MB, the process completes in a few seconds. Larger files with many pages or high-resolution images take a bit longer.

### Can I add page numbers to a scanned PDF?

Yes. Page numbers sit as an overlay on top of each page, so it doesn't matter whether the PDF contains editable text or is a flat scanned image.

### How do I add page numbers to a PDF on a Mac?

Use the [Add Page Numbers tool](/add-page-numbers) in any browser on your Mac, including Safari. Preview (the built-in Mac PDF app) doesn't have a built-in page-numbering feature, so a browser-based tool is the easiest option.

### Can I add page numbers to only some pages?

Yes. Most tools let you set a page range. You might number only pages 4 onward (skipping a cover and table of contents), or restrict numbers to a specific chapter.

### What if my PDF already has page numbers baked in?

Adding new numbers on top of existing ones will create double numbers. Use the [Crop PDF tool](/crop-pdf) to trim the area where the old numbers appear before adding new ones, or remove and re-create the relevant pages with the [Delete Pages tool](/delete-pages).

### Can I remove page numbers I added with this tool?

If you still have your original PDF, just use it instead. The page numbers are added in a single pass to a new file, so your source file is unchanged. Removing numbers that were baked into the original document from the start requires a dedicated PDF editor.

### What's the difference between page labels and visible page numbers?

Page labels are metadata inside the PDF that readers and PDF viewers use to display numbers in their page count. Visible page numbers are text stamped onto the page itself. This tool adds visible numbers. If a PDF viewer already shows its own page count in the interface, those come from page labels, not from stamped text. Both can coexist in the same file without conflict.
