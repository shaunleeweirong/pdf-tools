To remove a password from a PDF you can already open, use a free unlock tool: drop the file in, type the password you know, and download an unlocked copy. It takes a few seconds, needs no Adobe Acrobat and no sign-up, and, with an in-browser tool, the file is never uploaded, which matters when the PDF is a bank statement, payslip, or contract.

## How to remove a PDF password without Acrobat

1. Open the [free Unlock PDF tool](/unlock-pdf).
2. Drop your password-protected PDF into the box.
3. Enter the password you already use to open the file.
4. Click **Unlock PDF** and download the copy. It opens without asking for anything.

That's it. The unlocked file is a normal PDF you can email, print, or store without typing the password every time.

## Do I need to know the password?

Yes. An unlock tool removes a password you already have. It is **not** a password cracker and cannot open a file you are locked out of. If you have forgotten the password to your own document, your best routes are the app or person that created it, or a password manager where you might have saved it. Removing protection from a file you are not allowed to open is not something these tools do, and the tool will simply refuse: we verified that supplying the wrong password fails cleanly rather than producing a damaged file.

## The two kinds of PDF password

This trips people up, and knowing the difference explains most confusing behaviour.

- A **user password** (sometimes called an open password) is required to view the document at all. The file contents are genuinely encrypted, and without the password there is nothing readable inside.
- An **owner password** (a permissions password) leaves the document readable but marks it as restricted: no printing, no copying text, no editing. Those restrictions are a flag that well-behaved software chooses to respect, not a lock. They are much weaker than they look.

Our [Protect PDF tool](/protect-pdf) sets both to the same value using [AES](https://en.wikipedia.org/wiki/Advanced_Encryption_Standard) 256-bit encryption, so the document is properly encrypted rather than merely flagged.

Two things worth taking from that. Encryption overhead is roughly a fixed kilobyte, not a percentage, so it reads as +4.8% on a small file and +0.1% on a large one. And the round trip is effectively lossless in size terms: unlocking returns the file to within a few hundred bytes of where it started, because nothing about the page content is touched.

## Is it safe to remove a PDF password online?

The real risk with "online" tools is that most of them **upload your file to a server** to process it. You are handing both a sensitive document and its password to someone else's machine, and you have no way to know what happens next.

The safer approach is a tool that runs entirely in your browser, so the document and the password never leave your device. That is how [Unlock PDF](/unlock-pdf) works here: the decryption is done by [qpdf](https://qpdf.sourceforge.io/) compiled to WebAssembly and running in your tab. Nothing is uploaded, so there is no copy sitting on a server to leak.

You do not have to take that on trust. Open your browser's developer tools, switch to the network tab, and unlock a file while watching it. You will see no request carrying your document.

## Another free way: the "Print to PDF" trick

If you would rather not use a tool at all, most browsers can do it:

1. Open the password-protected PDF in Chrome or Edge and enter the password.
2. Choose **Print**, then set the destination to **Save as PDF**.
3. Save. The new file is a flat copy with no password.

The trade-off is real. Printing to PDF re-renders every page, so it can drop interactive form fields, flatten annotations, break internal links, and slightly shift the layout. Text usually stays selectable, but anything the document could *do* stops working. For an exact copy of the original, the unlock tool is cleaner.

## When you should keep the password

Removing protection is easy, which is a good reason to pause before doing it by habit. If the PDF is a payslip, a tax return, or a medical letter and it is going to sit in a shared folder or a synced Downloads directory, the password is doing useful work. Unlock a working copy if you need one, and keep the protected original.
