To remove a password from a PDF you can already open, use a free unlock tool: drop the file in, type the password you know, and download an unlocked copy. It takes a few seconds, needs no Adobe Acrobat and no sign-up, and — with an in-browser tool — the file is never uploaded, which matters when the PDF is a bank statement, payslip, or contract.

## How to remove a PDF password without Acrobat

1. Open the [free Unlock PDF tool](/unlock-pdf).
2. Drop your password-protected PDF into the box.
3. Enter the password you already use to open the file.
4. Click **Unlock PDF** and download the copy — it opens without asking for a password.

That's it. The unlocked file is a normal PDF you can email, print, or store without typing the password every time.

## Do I need to know the password?

Yes. An unlock tool removes a password you already have — it is **not** a password cracker and cannot open a file you're locked out of. If you've forgotten the password to your own document, your best routes are the app or person that created it, or a password manager where you might have saved it. Removing protection from a file you aren't allowed to open isn't something these tools do.

## Is it safe to remove a PDF password online?

The real risk with "online" tools is that most of them **upload your file to a server** to process it — not ideal for anything sensitive. The safer approach is a tool that runs entirely in your browser, so the document and its password never leave your device. That's how [Unlock PDF](/unlock-pdf) works here: nothing is uploaded, so there's no copy sitting on someone else's server.

## Another free way: the "Print to PDF" trick

If you'd rather not use a tool at all, most browsers can do it:

1. Open the password-protected PDF in Chrome or Edge and enter the password.
2. Choose **Print**, then set the destination to **Save as PDF**.
3. Save. The new file is a flat copy with no password.

The trade-off: printing to PDF can drop interactive form fields and slightly change the layout, and it re-renders the pages. For an exact copy of the original, the unlock tool is cleaner.
