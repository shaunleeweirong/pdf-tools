To compress a PDF to 100KB, open a free in-browser compression tool, drop your file in, and download the smaller version. For a text-based PDF — a typed CV, a filled form, a plain letter — one step almost always gets you there. For image-heavy PDFs (scanned pages, photographed IDs, brochures), you may need to combine compression with page extraction to hit the target.

## Why do portals set a 100KB limit?

Government application portals, university admission systems, visa submission forms, and job application websites often enforce a strict 100KB ceiling. The reasons are practical:

- **Older server infrastructure** — many portals were designed when broadband was slower and storage expensive; the limits were never updated.
- **Batch processing speed** — a system handling thousands of daily submissions processes 80KB files far faster than 5MB ones.
- **Instant in-browser display** — documents under 100KB load in a web viewer with no visible wait time.

Common examples where this bites people: UPSC and SSC job applications, Aadhaar-linked government portals in India, bank KYC submissions, university document upload systems, and visa application portals worldwide. If you've ever seen "File size must not exceed 100 KB," you know the frustration — especially when a straightforward scan of one page comes in at 1.5MB.

1. Open the [Compress PDF tool](/compress-pdf).

3. Click **Compress PDF** and wait a moment while it processes.

If the first pass brings you close but not under 100KB, try running compression again on the already-compressed file. Each pass reduces file size a bit more; stop when the content is still clearly readable.

## Can every PDF actually reach 100KB?

It depends on what is inside the file.

**Text-based PDFs** (digitally typed documents, filled forms, CVs made in Word or Google Docs) compress very easily. They are often already under 200KB and reach 100KB in one step with no visible quality change.

**Scanned documents** (pages photographed with a phone or run through a scanner) are essentially image files wrapped in a PDF container. Compression reduces image quality — at some point the text becomes hard to read. Whether you can hit 100KB while keeping the document legible depends on the original scan resolution and how many pages there are.

**Multi-page image PDFs** are the hardest case. A 10-page scanned report at 300 DPI might start at 5MB; compressing it to 100KB would make the text unreadable. For those files, the better approach is to extract only the specific pages the portal actually needs (usually one or two), compress that smaller file, and submit only the relevant pages.

## Tips when compression alone isn't enough

Try these in order if one round of compression doesn't reach 100KB:

**Extract only the pages you need.** Most portals want a specific document — a single certificate, one page of your passport, or a one-page form. Use the [Split PDF tool](/split-pdf) to pull out just those pages, then compress the smaller result. Fewer pages means a much smaller file before compression even starts.

**Compress the already-compressed file.** Run the compressed output through compression again. The second pass squeezes out more size at a cost of a little more quality — usually acceptable for document submission.

**Start from a lower-resolution scan.** If you are scanning a document specifically to submit it, scan at 150 DPI rather than 300 DPI. The resulting PDF will be dramatically smaller before you even open a compression tool.

**Shoot in good light, not just at lower resolution.** A blurry or poorly lit scan at any resolution produces a larger file (the compression algorithm has to preserve more variation), while a crisp, evenly lit photo at 150 DPI produces a small, readable result.

**Check whether the portal limit is actually enforced.** Some portals display an old limit that is no longer strictly checked. Try uploading a file slightly above 100KB (say, 120–150KB) and see if the submission goes through before spending time chasing the last few kilobytes.

## What about scanned IDs and passport copies?

Passport copies, national ID cards, and Aadhaar cards are common targets for strict size limits — and among the hardest to compress because the text must remain legible. The most reliable approach is to start small:

1. Photograph or scan the document at 150 DPI with good, even lighting.
2. Run one pass of compression on the resulting PDF.

Starting from a smaller source file is far more effective than aggressively compressing a high-resolution original. If you already have a high-resolution scan, extract just the relevant face of the ID (one page) before compressing — that alone often brings the file under 200KB, after which compression easily reaches 100KB.

## Frequently asked questions

### How do I check the size of a PDF?

On Windows: right-click the file → Properties → look at "Size." On Mac: right-click the file → Get Info. On a phone: find the file in your Files app and tap for file details. In most email clients, the attachment size is shown next to the filename.

### Does compressing to 100KB make the text blurry?

For text-based PDFs (digital documents), no — text in a PDF is stored as vector data, not as an image, so compression doesn't affect its sharpness at all. For scanned PDFs, compression reduces the quality of the underlying images, which can make text slightly less crisp at very high compression levels. Use the minimum compression that gets you under the limit.

### Is it safe to compress a sensitive PDF online?

With the [Compress PDF tool](/compress-pdf) — yes. Processing happens entirely in your browser tab; your file is never uploaded to a server. That means no server-side copy is created, stored, or at risk of a data breach.

### Can I compress a PDF on my phone?

Yes. The in-browser tool works on any modern smartphone browser — Chrome on Android, Safari on iPhone, Firefox on either — with no app download needed. Open the page, tap to select your file, and download the compressed result.

### Why did my PDF get larger after I compressed it?

Some PDFs are already efficiently compressed (common in files created by modern apps like Adobe Acrobat or Google Docs). Running them through another compression tool can sometimes re-encode them slightly less efficiently, causing a marginal size increase. If that happens, the original file is already as small as it is going to get — use it as-is.

### Can I compress multiple PDFs at once?

The in-browser tool processes one file at a time. If you need to compress a batch of PDFs, run them through one at a time — because processing is fast (usually under five seconds per file) this is usually quicker than finding a batch tool.
