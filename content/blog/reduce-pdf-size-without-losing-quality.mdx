## Does compressing a PDF reduce quality?

It depends on what is inside the PDF and which compression mode you use.

**Text-based PDFs**, digitally typed documents, forms, CVs, spreadsheets exported to PDF, store text as vector data, not as images. Vector data is not affected by compression at all. Compressing a text PDF removes redundant internal data structures (unused font data, duplicate object references, metadata overhead) rather than touching the visible content. Quality is preserved completely.

**Image-heavy PDFs**, scanned pages, brochures, photos, presentations, store content as raster images. Compression re-encodes those images at a slightly lower resolution or quality factor. At moderate settings (the default on most tools), the difference is imperceptible on a standard screen at 100% zoom and invisible in print at normal reading distance. At aggressive settings, you may notice slight softness in fine details.

The short answer: for the vast majority of everyday documents, compressing reduces size significantly and quality noticeably not at all.

## What is lossless vs lossy PDF compression?

**Lossless compression** removes redundant data that does not affect the visible content, duplicate objects, unused resources, metadata bloat. The output is bit-for-bit identical in appearance. Most text PDFs benefit mainly from lossless compression.

**Lossy compression** re-encodes the embedded images at a lower quality setting or resolution. The visual output is very close to the original but not identical. The trade-off is a much larger file-size reduction. Lossy is what shrinks a 15 MB scanned contract down to 2 MB.

Most good PDF compressors apply both together: lossless passes first (fast, free quality), then controlled lossy image re-encoding at a quality level that preserves readability. The [Compress PDF tool](/compress-pdf) takes this approach, it targets a balance between maximum size reduction and maintained visual quality.

## Why doesn't my PDF compress much?

If your file barely shrinks, one of these is likely the reason:

**The PDF is already optimised.** Modern tools like Adobe Acrobat, Google Docs, and macOS create PDFs that are already efficiently compressed. There is little redundant data to remove.

**It is a text-only document.** Text in PDFs is compact vector data. A 50-page typed report might be 500 KB to begin with; compressing it saves only a few kilobytes.

**It was already compressed once.** A PDF that went through compression before will respond less to a second pass. Diminishing returns apply.

In all these cases, the file is probably as small as it is going to get without reducing the content itself (fewer pages, lower-resolution source images, fewer embedded fonts).

## Text-heavy vs image-heavy PDFs: why results differ

Text in a PDF is stored as a series of character codes and font instructions, extremely efficient, already tiny. A 10-page letter in 12-point Times New Roman might be 80 KB.

Images in a PDF are raster data, each pixel stored individually. A single scanned page at 300 DPI is several megabytes before any compression. When a scanned document runs to 20 pages, the PDF can easily reach 40-50 MB.

Compression targets the images. It has almost nothing to work on in a text-only PDF, and a great deal to work on in a scanned document. That is why the same tool produces a 5% reduction on one file and an 80% reduction on another.

If your PDF contains both text and images (a report with embedded charts, a form with a scanned signature), expect somewhere in the middle.

## How to reduce PDF size on Mac without losing quality

**Using the free in-browser tool:** The [Compress PDF tool](/compress-pdf) works on Mac in Safari, Chrome, and Firefox exactly as on any other platform, no software to install.

**Using Preview (built-in, free):**
1. Open the PDF in Preview.
2. Choose **File → Export**.
3. In the **Quartz Filter** pop-up, select **Reduce File Size**.
4. Click **Save**.

Preview's Reduce File Size filter applies an aggressive compression pass that sometimes overshoots, text PDFs can come out looking washed out. It works better on image-heavy files. If the Preview result looks too degraded, use the browser-based tool instead, which applies a gentler default setting.

**Using Automator (batch compression on Mac):**
If you need to compress many files, open Automator, create a new workflow, add the **PDFs → Apply Quartz Filter to PDF Documents** action, select the Reduce File Size filter, and run it on a folder. Faster than processing one by one.

## Frequently asked questions

### Does compressing a PDF make text blurry?

No. Text in a PDF is vector data, it is not affected by image compression. Blurriness only occurs with scanned documents where the page content is stored as a raster image rather than as text characters.

### Is there a free PDF compressor that doesn't upload my file?

Yes. The [Compress PDF tool](/compress-pdf) processes your file entirely inside your browser tab. Nothing is sent to a server. It is free with no account required.

### How do I know if quality was affected?

Open the compressed file and zoom in to 100% on a page with fine detail (small text, a chart, a photo). Compare it to the original at the same zoom level. For most files at standard compression settings, there is no visible difference.

### Can I reduce a scanned PDF size without losing readability?

Yes, up to a point. Standard compression typically reduces a scanned PDF's size by 50-70% while keeping text readable. Very aggressive compression can make fine print hard to read. If readability matters (a legal document, a medical record), use the compressed file once and check before discarding the original.

### Why did my compressed PDF get larger?

This happens when the original was already optimally compressed, typically PDFs created by recent versions of Adobe Acrobat, Google Docs, or macOS. Running it through compression software re-encodes it with a slightly different internal structure, occasionally adding a few bytes. The original file was already as small as possible; use it as-is.

### What is the best PDF compressor for large scanned documents?

Any tool that uses JPEG re-encoding at a controlled quality level works well. The [Compress PDF tool](/compress-pdf) targets a balance between readable quality and maximum size reduction, well suited to scanned contracts, reports, and multi-page forms.

### Does reducing PDF size affect printing quality?

Compression affects the embedded image data. At standard compression levels, the re-encoded images print at a resolution higher than most home and office printers can reproduce, so printed output looks identical to the original. Only very aggressive compression, targeting very small file sizes, would produce a noticeable quality difference in print.
