## Actual Teams file limits

- SharePoint-backed (channel Files tab): 250 GB per file
- OneDrive-backed (chat attachments): 250 GB per file
- Teams Free: 5 GB total storage per user
- Org IT admins can set custom lower limits via SharePoint admin center
- Education assignments: separate upload path, limits vary by institution
