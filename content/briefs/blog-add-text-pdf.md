# Research brief: how to add text to a pdf free

**targetQuery**: how to add text to a pdf free
**Secondary keywords**: add text to pdf online free, type on pdf without adobe, pdf text editor free no signup, add text box to pdf free
**Search intent**: informational / transactional hybrid — reader wants to get a task done right now
**Surface**: blog post
**Recommended length**: 900+ words

## The real questions people ask

From PAA, Quora, and autocomplete:

1. How do I add text to a PDF without Adobe Acrobat?
2. Can I add text to a PDF free online without creating an account?
3. Why can't I click to type in my PDF? (the viewer vs. editor confusion)
4. What's the difference between adding text to a scanned PDF vs. a regular PDF?
5. What if my PDF already has form fields — should I use a different tool?
6. Should I flatten the PDF after adding text?
7. Does this work on Windows / Mac / iPhone / Android?
8. Will the original content change when I add text?

## Competitor gaps

- Adobe's own resources push Acrobat Pro (paid) or their online tool (requires sign-in)
- Smallpdf and iLovePDF push freemium plans
- Competitor posts gloss over the scanned vs. native PDF distinction
- Almost no one explains the three different use cases clearly (overlay vs. form fill vs. editing existing text)
- Privacy angle (files stay in browser) is ignored

## Our angle

- Completely free, no account, no watermark
- In-browser, files never leave the device
- Clear explanation of which tool to use for which scenario

## Internal link targets

- /edit-pdf (primary)
- /fill-form (for fillable PDFs)
- /flatten-pdf (to lock in changes)

## Recommended format

How-to post with distinct H2 sections for each question. Numbered steps for the two main workflows. FAQ in frontmatter.
