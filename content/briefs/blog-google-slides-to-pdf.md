## Key findings from research

- Built-in method: File > Download > PDF Document (.pdf) — fastest, one slide per page, no notes
- Notes method: File > Print Settings and Preview > "1 slide with notes" > Download as PDF
- Handout method: same Print preview > 2/3/4/6/9 slides per page (cannot mix with notes)
- Mobile (iOS/Android): three-dot menu > Share & export > Save As > PDF Document
- Mobile limitation: no Print Settings and Preview on mobile; handouts/notes require desktop
- Google Drive method: right-click a .gslides file > Download > PDF
- Image quality issue: Google rasterizes slides at export; high-DPI monitors may notice softness on text slides
- File size: presentation PDFs are usually small, but image-heavy decks can hit email limits
