## Key causes of blank pages

- **Duplex scanning** on single-sided originals: scanner captures the blank back of each sheet. Common with ADF scanners set to "both sides."
- **Word / Google Docs exports**: trailing paragraph below last content paragraph triggers a new page in the exported PDF.
- **Merging PDFs**: some tools insert blank pages to preserve odd/even page layout when source files don't end on even pages.
- **Spreadsheet print-to-PDF**: empty worksheet tabs included in print range produce blank pages.
