## Competitor gaps

- Most competitors cover the basic steps but don't warn clearly about the
  text-PDF-vs-scanned-PDF distinction (OCR vs. native text extraction).
- Few explain that the original file is not modified.
- Formatting limitations are mentioned but rarely quantified or explained clearly.
- The "pages as images" use case (pdf-to-jpg as alternative) is almost never covered.

## Key facts to include

- Google Drive's built-in converter: right-click PDF > Open with > Google Docs
- Creates a NEW document; original PDF is unchanged
- Text-based PDFs: native text is extracted directly, reasonable accuracy
- Scanned PDFs: Google uses OCR, layout is not preserved
- Formatting loss is expected for tables, columns, custom fonts, complex layouts
- No extra software or paid subscription needed
- No claim about our own tool performance (not applicable to this topic)
