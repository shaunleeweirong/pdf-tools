## The "get it done" angle

Reader has a PDF in a language they can't read (or needs to share one). They want to translate it right now, free, without downloading anything. Answer: Google Translate Documents tab (free, 133 languages, no sign-up, ~1 min). DeepL is better for European languages but has a monthly page cap on the free tier. Scanned PDFs need OCR first (Google Drive method handles this automatically).

## Key facts (verified)

- Google Translate supports 133+ languages, no account needed, ~10 MB PDF limit
- DeepL supports 31 languages (as of 2026), better fluency for European pairs, free tier limited
- PDF fixed-position format means text length changes in translation cause layout disruption
- Scanned PDFs store text as images: standard translators return blank or fail. OCR first.
- Google Drive > Open with Google Docs applies OCR automatically, then Tools > Translate document works
- Our compressor rasterizes pages (see tool-measurements.md) so translate from original PDF, not compressed copy
