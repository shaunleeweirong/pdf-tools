## Key angles

1. **Sign first, then flatten** for submission/sending. Flattening before signing destroys the signature field.
2. **Flatten before merging** if the PDF has form fields (links to do-i-need-to-flatten-pdf-before-merging for more depth).
3. Court and e-filing systems (U.S. courts, USCIS, DocuSign uploads) require flattened PDFs.
4. When NOT to flatten: if another party still needs to sign, if you need to make corrections, if recipient needs fillable fields.
