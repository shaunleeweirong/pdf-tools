## Methods to cover

1. **Download as PDF (desktop)** - File > Download > PDF Document (.pdf) - fastest path
2. **Print to PDF (desktop)** - more control over paper size, margins, scaling
3. **Android** - three-dot menu > Share & Export > Save As > PDF Document
4. **iPhone/iPad** - More icon > Share and Export > Send a copy > choose PDF

## Key tool-measurement guardrails for this post

- Do NOT recommend compressing a text-based Google Doc PDF - it will grow dramatically (23.5 KB to 1.4 MB)
- Only recommend compress-pdf for exports that have lots of images/photos
- Merge-pdf does not inflate file size (970.5 KB out vs 971.9 KB in across three files)
