## Key facts

- TIFF (Tagged Image File Format) uses lossless compression; preserves every pixel. Standard in photography, document scanning, archiving.
- TIFF files are large: a single 300 dpi A4 page can be 5 to 25 MB.
- Mac Preview can open and export TIFF to PDF natively (File > Export as PDF). Lossless.
- Windows 10/11 includes Microsoft Print to PDF. Open TIFF in Windows Photos > Ctrl+P > Microsoft Print to PDF. Lossless.
- Multi-page TIFFs (common from document scanners) are handled by both built-in methods.
- Converting TIFF to JPG first and then to PDF introduces lossy JPEG compression.
- Our jpg-to-pdf tool accepts JPEG and PNG (not TIFF directly). Users who save a TIFF as JPG can then use it.
- Our merge-pdf tool can combine separately-created PDFs.
