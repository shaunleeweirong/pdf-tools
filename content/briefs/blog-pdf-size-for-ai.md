## Key facts (verified)

- **Claude.ai**: ~30 MB per file, max 1,000 pages. Visual analysis (charts/images) only on first 100 pages. Up to 20 files per chat.
- **ChatGPT**: 512 MB hard limit, but 2-million-token cap on text means large PDFs can fail well below that. Free: ~3 uploads/day; Plus: 80 per 3 hours.
- **Our compressor (measured)**: 913.4 KB image deck → 315.3 KB at Medium (-65.5%); → 175.6 KB at High (-80.8%). Works for scans/photo decks.
- **CRITICAL**: Text-only PDFs get MUCH LARGER. 23.5 KB text report → 1.4 MB at Medium. Never compress a text PDF.
- **Don't compress twice**: 315.3 KB → 598.9 KB on a second Medium pass. Always start from original if first pass isn't enough.
- **Split/extract**: No measured size data, but functionally reduces page count, which is the right fix when page count (not size) is the problem.
- **Password-protected PDFs**: AI tools cannot read them at all. Remove the password first.

## Competitor gaps
