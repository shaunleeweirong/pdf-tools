## Search intent

Reader has 2+ Word documents and needs a single PDF. Common scenarios: job application (cover letter + resume), client deliverable with multiple chapters, school submission requiring one file. They want free, no software to install, and don't want to pay for Adobe Acrobat.

3. Will the formatting be preserved when merging?

5. What if I don't have a Microsoft 365 subscription?
6. Can I do it in my browser without uploading files to a server?

## Competitor analysis

- Adobe's hub pages push Acrobat Pro (paid, $20+/mo) or Acrobat online (requires sign-up, file upload)
- Smallpdf/iLovePDF: upload Word files directly to their servers and convert; sign-up required after a few uses; files stored on their servers
- Wondershare/WorkinTool: push desktop software downloads
- Most guides ignore the privacy concern about uploading sensitive Word docs

**Gap we beat:** The two-step free method (export each Word doc to PDF first, then merge PDFs with our in-browser tool) is faster, works offline for the Word export step, is fully private (PDFs never leave the browser during merge), and requires no sign-up or software.

## Key facts (from tool-measurements.md)

- Merge does NOT inflate output size (971.9 KB in, 970.5 KB out - combined file is essentially the sum of parts)

- Merge runs in-browser via our tool (files never sent to a server)
