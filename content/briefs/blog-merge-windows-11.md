## Search findings

- Windows 11 has no built-in PDF merge tool (confirmed by multiple sources)
- Microsoft Print to PDF is a virtual printer that converts documents to PDF but cannot combine existing PDFs
- Microsoft Edge opens PDFs but has no merge function
- Main options: browser-based tools, Microsoft Store apps, downloadable software (PDFsam, 7-PDF, PDFgear, PDF Arranger)
- Privacy angle is a real differentiator: many online tools upload files to a server
