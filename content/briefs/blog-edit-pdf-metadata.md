## Key facts

- PDF metadata types: Title, Author, Subject, Keywords (the four main ones our tool edits)
- Also exists: Creator (app that made it), Producer (app that exported), Creation Date, Modification Date
- Metadata is in the XMP (Extensible Metadata Platform) section, separate from page content
- XMP is now an ISO standard (ISO 16684)
- Changing metadata does NOT change what you see on the pages
- File size before and after is nearly identical
