## Key findings from research

**PDF24 how it actually works:**
- Free ad-supported online suite with 40+ tools
- Online tools upload files to servers, auto-deleted after ~1 hour (per their FAQ)
- PDF24 Creator desktop app processes locally but Windows-only
- Mac/Linux users must use web (upload) version

**Common reasons users want alternatives:**
- Privacy: files go to a third-party server, even if temporarily
- Ads on the free web interface
- Platform: Windows-only for the offline desktop option
- Simplicity: large tool list can feel cluttered

**Our angle / competitive gap:**
- Browser-based using WebAssembly, no upload ever
- Works on Mac, Windows, Linux, ChromeOS, iOS, Android
- No account, no ads
- Covers the most-used tasks: merge, split, compress, rotate, convert, protect, fill forms

**Competitor content gaps:**
- Most "PDF24 alternatives" posts list 10+ tools with minimal detail
- Few explain the technical difference between upload-based vs. in-browser tools
- Few include honest limitations (our compress hurts text PDFs, no OCR yet)

## Facts from tool-measurements.md (use these, no invented numbers)

- Compress: 913.4 KB image deck → 315.3 KB at Medium, 175.6 KB at High
- Compress: 23.5 KB text report → 1.4 MB at Medium (DON'T use compress for text PDFs)
- Compress second pass: 315.3 KB → 598.9 KB (worse)
- Merge: 971.9 KB total input → 970.5 KB output (no inflation)
- Merge strips interactive form fields (flatten first)
- Protect: AES-256 via qpdf-wasm, adds ~1 KB overhead
- Rotate: sets orientation flag, file size unchanged
