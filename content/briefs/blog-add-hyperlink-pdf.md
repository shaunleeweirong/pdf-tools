## Key distinction to explain (competitor gap)

Most articles skip this entirely: there are two different things people mean by "hyperlink in a PDF":

1. **A visible URL typed on the page** (text that looks like a link but is not clickable)
2. **A PDF link annotation** (an invisible rectangle tied to a URL; clicking it opens the browser)

Method 1 can be done with any text editor. Method 2 requires a PDF editor that writes link annotations into the file structure. Readers need to know which one they want.

## Methods to cover (all genuinely free)

1. **Go back to the source** (best): If you created the PDF from Word, Google Docs, or LibreOffice, add the hyperlink there and re-export. Ctrl+K in all three. The resulting PDF has proper annotations.
2. **Sejda online** (for existing PDFs): free, browser-based, no upload limit on basic use; has an explicit Link tool
3. **PDFescape** (for existing PDFs): free tier, PDFs under 100 pages / 10 MB; established tool
4. **LibreOffice Draw** (desktop, free, all platforms): open existing PDF, Insert > Hyperlink, export back to PDF
5. **macOS Preview** (Mac-only built-in): Markup toolbar > Link annotation (limited but free and instant)
